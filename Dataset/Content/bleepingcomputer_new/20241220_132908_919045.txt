
	   


Adobe has published their monthly Patch Tuesday updates for the month of August 2019 that resolves 119 security vulnerabilities in eight programs. These updates include fixes for information disclosure, privilege escalation, arbitrary code execution, remote code execution, and memory leaks.

Due to the large amount of vulnerabilities and their severity, it is strongly advised to update affected programs as soon as possible.

Adobe Security Updates Summary:

APSB19-31 Security update available for Adobe After Effects CC

Adobe released a security update for Adobe After Effects CC that could allow an attacker to perform code execution through DLL hijacking.
