
	   


Microsoft released the May 2019 Office Update today, which consists of 9 security updates and 25 non-security updates. As some of the Microsoft Office security updates resolve critical vulnerabilities, it is strongly advised to install them as soon as possible.

Out of the nine Office security updates issued today by Microsoft, seven fix remote code execution vulnerabilities within Office 2016, Word 2016, Office 2013, Office 2010, Office Online Server, SharePoint Enterprise Server 2016, and SharePoint Foundation 2013.

Remote code execution vulnerabilities are Critical as they could allow potential attackers to execute arbitrary code and commands on an exploited computer.
