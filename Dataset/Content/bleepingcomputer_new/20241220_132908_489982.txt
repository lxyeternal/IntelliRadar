
	   


VMware released security updates to fix multiple vulnerabilities in VMware ESXi, Workstation, and Fusion, with one of them being a critical bug in default configurations of Workstation and Fusion having 3D graphics enabled.

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) also issued an alert today warning that an "attacker could exploit some of these vulnerabilities to take control of an affected system," and encouraging users and administrators to update as soon as possible.

Critical vulnerability with a 9.3 CVSSv3 base score

The critical security issue tracked as CVE-2020-3962 is a use-after-free flaw in the SVGA device that could allow local attackers to execute arbitrary code on the hypervisor from a virtual machine after successful exploitation.

To block attacks designed to abuse this vulnerability, VMware Workstation (Pro and Player) and VMware Fusion (Pro) users are advised to immediately upgrade to version 15.5.5, while VMware ESXi customers should update to ESXi_7.0.0-1.20.16321839, ESXi670-202004101-SG, or ESXi650-202005401-SG.

VMware also provided a workaround for users who can't immediately update their installations which requires disabling 3D graphics acceleration by shutting down the virtual machine, going to VM > Settings> Hardware > Display and unchecking "Accelerate 3D graphics."



Important and moderate severity flaws

VMware fixed nine other security vulnerabilities (CVE-2020-3963, CVE-2020-3964, CVE-2020-3965, CVE-2020-3966, CVE-2020-3967, CVE-2020-3968, CVE-2020-3969, CVE-2020-3970, CVE-2020-3971) impacting ESXi, Workstation, and Fusion, with CVSSv3 base scores ranging from 4.0 to 8.1.

After successfully exploiting these flaws, attackers with local access to a virtual machine (with admin privileges in some cases) could execute code on the hypervisor from the VM, trigger a denial-of-service (DoS) condition, read privileged info in the hypervisor's memory or in physical memory.

In some cases, "[a]dditional conditions beyond the attacker's control must be present for exploitation to be possible" according to VMware's advisory.

VMware provides links to security updates downloads that address all the issues affecting VMware ESXi, Workstation, and Fusion products.

In April, VMware fixed a critical vulnerability in the vCenter Server virtual infrastructure management platform that could have allowed attackers to potentially take control of affected virtual appliances or Windows systems.

VMware issued another security update in March to address a critical vulnerability in VMware Workstation Pro enabling attackers to launch DoS attacks or execute commands on the Windows host.
