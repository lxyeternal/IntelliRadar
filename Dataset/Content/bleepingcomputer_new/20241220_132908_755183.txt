
	   
Today apple released updates for iTunes, iOS, Safari, OS X El Capitan, tvOS, and watchOS. As these products contain shared code, many of the vulnerabilities that were patched for one product are the same in another product. It is advised that everyone install these security updates immediately as there were numerous vulnerabilities that allow for remote code execution or executable elevation privileges.
