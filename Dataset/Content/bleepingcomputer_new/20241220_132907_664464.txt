
	   


As we get closer to Microsoft being ready to publicly reveal their Chromium-based Microsoft Edge Insider browser, an Edge Insider Addons store has been found that contains 84 extensions that will be available for the new browser.

This new store was discovered by Windows sleuth WalkingCat, who posted it to Twitter.


Microsoft Edge Insider Addons https://t.co/GWSE6aM1uU
— WalkingCat (@h0x0d) March 14, 2019

This store is located at https://www.microsoft.com/en-us/microsoft-edge/insider-addons/category/EdgeExtensions and currently contains 81 extensions that can be used with the Edge Insider build. These extensions include AdBlock, DashLane, LastPass, Grammarly, Tampermonkey, and more.

Pick a name and stick to it!

If there is one thing that drives me nuts about Firefox is their confusion whether to call them addons or extensions. It must also confuse the developers as well because on the same Firefox user interface pages we see them referenced using both names.


Extension Addon Identity Crisis

Microsoft Edge Addon / Extension Confusion

Microsoft, do not go down this path. You are only confusing your users and making a simple naming scheme more complex.
