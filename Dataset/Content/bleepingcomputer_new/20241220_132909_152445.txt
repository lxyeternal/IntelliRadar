
	   


Cisco today has released several security updates to address three critical authentication bypass, buffer overflow, and authorization bypass vulnerabilities found to affect Cisco Data Center Network Manager (DCNM) and multiple Cisco SD-WAN software products.

The company also issued security updates to fix another eight high and medium severity vulnerability found in to affect several other Cisco DCNM Software versions.

According to Cisco's Product Security Incident Response Team (PSIRT) none of these security issues are currently exploited in the wild.

Auth bypass via DCNM's REST API

The authentication bypass vulnerability tracked as CVE-2020-3382 received a CVSS base score of 9.8/10 and it was found in the REST API of Cisco DCNM.

Cisco DCNM is a network management solution for next-generation data centers that provides a web-based management console for high-level monitoring and control of Cisco Nexus, Cisco MDS, and Cisco Unified Computing System products.

If successfully exploited by unauthenticated attackers, CVE-2020-3382 could allow them to bypass authentication and remotely execute arbitrary actions on vulnerable devices with administrative privileges, through the REST API.

"The vulnerability exists because different installations share a static encryption key," Cisco explains. "An attacker could exploit this vulnerability by using the static key to craft a valid session token."

CVE-2020-3382 affects all deployment modes of all Cisco DCNM appliances installed using .ova or .iso installers and Cisco DCNM software 11.0(1), 11.1(1), 11.2(1), and 11.3(1) releases.

Cisco also confirmed that the vulnerability does not affect Cisco DCNM instances installed on customer-provided OSs using Windows or Linux DCNM installers.

According to Cisco, the only way to address this vulnerability is to update the Cisco DCNM software to releases 11.4(1) and later since there are no workarounds that could be applied to mitigate this issue.

Critical issues impacting SD-WAN software

As mentioned in the beginning, Cisco also fixed two critical vulnerabilities affecting Cisco SD-WAN vManage Software and Cisco SD-WAN Solution Software (including IOS XE SD-WAN Software, SD-WAN vBond Orchestrator Software, SD-WAN vEdge Cloud Routers, SD-WAN vEdge Routers, SD-WAN vManage Software, and SD-WAN vSmart Controller Software).

The first is impacted by an authorization bypass flaw (CVE-2020-3374) with a CVSS score of 9.9 in the web-based management interface that may "allow an authenticated, remote attacker to bypass authorization, enabling them to access sensitive information, modify the system configuration, or impact the availability of the affected system."

"A successful exploit could allow the attacker to gain privileges beyond what would normally be authorized for their configured user authorization level," Cisco explains. "The attacker may be able to access sensitive information, modify the system configuration, or impact the availability of the affected system."

The second is a buffer overflow bug (CVE-2020-3375) due to insufficient input validation that could allow an unauthenticated, remote attacker "to gain access to information that they are not authorized to access, make changes to the system that they are not authorized to make, and execute commands on an affected system with privileges of the root user."

Cisco has published software releases that address both these security flaws, with the fixed software version listed within the two security advisories (1, 2).
