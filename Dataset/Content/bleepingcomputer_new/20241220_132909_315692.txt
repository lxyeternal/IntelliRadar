
	   


Malware authors hid malicious code inside a software development kit (SDK) that developers embedded in their Android apps, unwittingly exposing their users to a mobile malware strain that Check Point identifies as ExpensiveWall.

According to a report offered to Bleeping Computer before publication earlier today, Check Point says it found the malware hiding in over 100 apps uploaded on the official Google Play Store.

Based on Google app download statistics, the malicious apps were downloaded between 5.9 million and 21.1 million times. The most downloaded of these was an application named Lovely Wallpaper, downloaded between 1 and 5 million times.

An analysis of the apps uploaded on the Google Play Store revealed the applications included malicious code — courtesy of an SDK named "gtc" — to perform a series of operations in a precise order.

The first step is similar to the first step that all Android malware performs — to collect data on the infected device and report this information to a remote C&C server.

Second, ExpensiveWall would ping back to a remote server and receive commands that it would execute inside a WebView component.

These commands tell the WebView component — a barebones browser — to access a site and subscribe the user to premium SMS services.

The malware mimics taps on any multi-step procedures and also hides confirmation SMS messages.

In most cases, device owners will only realize they've been infected with malware the next time their mobile bill comes in. Nonetheless, researchers also found instances where the malware prompts the user with a button that says "Continue," and once the user clicks the button, the malware sends a premium SMS on his behalf.

Google has removed all apps infected with ExpensiveWall

Google has removed all the apps Check Point researchers reported. Researchers also say they've identified three distinct campaigns that distributed the ExpensiveWall malware.

The first was detected by McAfee security researchers earlier in the year, in January, the second was recently detected and stopped by Check Point, and a current third wave of apps does not actively use the malicious code hidden in the SDK.
