
	   


Microsoft announced the final version of its security configuration baseline settings for Windows 10, version 2004 and Windows Server, version 2004, downloadable today using the Microsoft Security Compliance Toolkit.

As announced on June 3 when a draft of the security baseline for Windows 10 20H1 was published, Microsoft included several changes to the Windows 10, version 2004 recommended security settings among which new account password length security policies, new Defender features, and enhanced LDAP Authentication protection stand out.

The Windows 10 security baseline enables enterprise security admins to use Microsoft-recommended Group Policy Object (GPO) baselines to improve the overall security posture of Windows 10 systems in their environment and decrease their attack surface.

New account password length policies

According to Microsoft, new 'Relax minimum password length limits' and 'Minimum password length audit' security settings will be available in Windows 10 (Server) 2004 under Account Policies\Password Policy:

• Minimum password length audit: This security setting determines the minimum password length for which password length audit warning events are issued. This setting may be configured from 1 to 128.
• Relax minimum password length legacy limits: This setting controls whether the minimum password length setting can be increased beyond the legacy limit of 14.

The first policy will allow admins to require users to use passwords between 14 and 128 characters until their org's environments are properly secured by implementing a multi-factor authentication (MFA) strategy, while the second one will enable admins to discover compatibility problems among existing processes and systems.

"This setting will not be added to the baseline as the minimum password length should be audited before broad enforcement due to the risk of application compatibility issues," Munck said. "However, we urge organizations to consider these two settings."

Since using long passwords or passphrases is not directly related to better security, admins are also recommended to also enable the Azure AD Password Protection feature that automatically rejects commonly used or compromised passwords to drastically diminish the risks raised by password spray attacks.

Microsoft also released new secure default settings dubbed 'Security Defaults' to Azure Active Directory earlier this year, which are a set of basic Microsoft-recommended identity security mechanisms that include pre-configured security settings designed to protect against common attacks such as password spray, replay, and phishing.

By enabling Security Defaults, all admins and users are required to register for multi-factor authentication (MFA), they are challenged with MFA for critical roles and tasks, and authentication from legacy auth clients is disabled if they do not support MFA.

New Defender features and LDAP Authentication protection

In Windows 10 2004, Microsoft Defender Antivirus provides a new setting known as 'Enable file hash computation feature' designed to allow admins to force the anti-malware solution to "compute file hashes for every executable file that is scanned if it wasn’t previously computed" to "improve blocking for custom indicators in Microsoft Defender Advanced Threat Protection (Microsoft Defender ATP)."

Redmond however warns that in some situations — for instance when users frequently update or install apps — this new feature can come with a performance cost.

"If you chose to enable this setting, we recommend throttling the deployment to ensure you measure the impact on your users’ machines," Microsoft says.

Windows Server 2004 also adds the Extended Protection for LDAP Authentication custom MS Security Guide setting (for AD Domain Controllers only) to help make LDAP authentication over SSL/TLS more secure.

As the ADV190023 security advisory published by Microsoft in March 2020 explains, the company added group policies and options for admins "to harden the configurations for LDAP channel binding on Active Directory domain controllers" via the Windows updates.

New Windows 10 2004 policy settings

The final release of the Windows 10 Version 2004 and Windows Server Version 2004 security baseline is available for download from here, and it includes scripts to apply settings to the local GPO, GPO backups and reports, and Policy Analyzer rules files.

"Using the toolkit, administrators can compare their current GPOs with Microsoft-recommended GPO baselines or other baselines, edit them, store them in GPO backup file format, and apply them via a domain controller or inject them directly into testbed hosts to test their effects," Microsoft explains.
