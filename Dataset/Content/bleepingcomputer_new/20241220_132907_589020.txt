According to ESET's Juraj Jánošík, starting with January 29 the campaign suddenly revived, delivering "tens of thousands of malicious emails" per hour that bundle email attachments containing zipped JavaScript (.js) files.

This led to the JavaScript-fueled campaign becoming the number threat in Japan and the "fourth most detected threat worldwide."

“Love you” campaign activity

When compared to the previous "Love Letter" campaign, the actors specifically-tailored the contents of the emails delivered to their targets using topics relevant to potential Japanese victims.

The malspam operation now uses the names of popular Japanese entertainers followed by smileys as the malicious emails' subjects and camouflage the zipped malicious JavaScript files as images named using the "PIC0-[9-digit-number]2019-jpg.zip" format.


Spam emails examples

As ESET discovered, the JavaScript files in the attachments will download the first malware payload when opened and launched from the command-and-control server, "an EXE file detected by ESET products as Win32/TrojanDownloader.Agent.EJN."

The first stage payload will be downloaded from URLs ending in "bl*wj*b.exe" or krabler.exe to the local "C:\Users\[username]\AppData\Local\" folder and saved using the "Temp[random].exe" file name pattern.

Once on the compromised machine, just as it did during the mid-January campaign, the malware will get access to a cocktail of second stage payloads, that mixes in the GandCrab 5.1 ransomware, a cryptominer (a Monero XMRig binary if nothing changed from the previous campaign), and the Phorpiex worm with spam and backdoor capabilities.


GandCrab 5.1 Ransom Note

Additionally, the first stage payload can also download a system settings changer tool or a downloader designed to grab more payloads if the system locale is set to China, Vietnam, South Korea, Japan, Turkey, Germany, Australia or the UK, which hints at the current campaign also inadvertently hitting targets from these countries.

ESET's research team discovered that the malware payloads is downloaded from a server with a Ukrainian IP also used as a C&C server the last time the operation was making the rounds.

Since malspam is still alive and kicking, users should always be aware that emails received from unknown sources, especially those that also come with suspicious looking attachments, could deliver malware to their computers.

BleepingComputer advises users to always scan attachments using a service like VirusTotal and to contact the sender to verify their source.
