
	   
Security researcher Tobias Boelter has discovered a bug in the encrypted communications system used by WhatsApp that allows a determined third-party actor, possibly Facebook, to intercept encrypted messages.

Boelter's published his findings on his blog in April 2016, and despite the issue's alarming result, Facebook told the researcher that this was not a big deal. The exact answer was:


We were previously aware of the issue and might change it in the future, but for now it's not something we're actively working on changing.


After months during which the researcher's work was completely ignored, today the issue came into the public's eye after many news outlets ran alarmistic headlines naming the bug a "backdoor" (more on this later).

How the WhatsApp bug behaves

In order to understand how the bug works, you need to understand how WhatsApp encryption works.

When user Alice wants to send a message to Bob, she encrypts her message with Bob's public key (portrayed as blue-colored text in the image below) and sends it to the WhatsApp server, to relay to Bob.



Boelter says that the WhatsApp server can hold this message and immediately announce that Bob has changed his public key and that Alice should use a new public key (shown in green).



Alice's WhatsApp client will re-encrypt the previously sent message, and resend it to the WhatsApp server (text shown in green).



This behavior allows the WhatsApp server to read the previously encrypted message, while also sending the original message to Bob, encrypted with the original blue public key (step 8 in the image below).



According to Boelter, the problem here is step 7, which is when the WhatsApp client tells Alice that Bob has changed his public key. This update should happen between step 5 and 6, and NEVER after.

Experts contest notion of WhatsApp "backdoor"

Following today's intense coverage of Boelter's findings, several security experts and infosec journalists are now contesting how the mainstream media has portrayed this vulnerability as a backdoor.

Frederic Jacobs, one of the cryptographic gurus working for Open Whisper Systems (Signal app); David Wind, a bug hunter and cryptographer; Martin Kleppmann, a former LinkedIn engineer; Zack Whittaker, ZDNet infosec reporter; Nadim Kobeissi, a cryptographer and security expert; Matthew Green, an assistant professor and cryptographer at Johns Hopkins University; Lorenzo Franceschi-Bicchierai, an infosec reporter for Vice News; and The Grugq, a security researcher, all says this is just an implementation bug.

All admitted that this was a bad bug to have in an application that claims to offer encrypted communications, but this is not something that could be reliably exploited to intercept messages. In fact, the technique can only be used to intercept one message, before the victim is alerted that the other person's public key has changed.

Boelter said this issue doesn't affect the Signal app. The Signal app is built on the Signal protocol, used by Facebook for WhatsApp encryption, and developed by Open Whisper Systems.
