
	   

Windows Defender Security Center

The Windows 10 Creators Update scheduled for launch later this year will include an upgrade of the default Windows Defender antivirus, which will feature a new settings panel named the Windows Defender Security Center.

According to Windows Defender program manager Shekhar Saxena, this new security center aggregates all security and privacy settings into one place, allowing easier management for non-technical users.

The new Windows Defender Security Center will feature five new different sections.

The first is "Virus & threat protection," which will unite all antivirus protection controls in one place.

Windows Defender Security Center - Virus & threat protection

The second is "Firewall & network protection," a section centered around the Windows built-in firewall. Additionally, information on local networks is also included, which is the same type of info users currently find in the "Network and sharing center" control panel option.


Windows Defender Security Center - Firewall & network protection

The third is "App & browser control," a section that allows users to control the status of the SmartScreen service, which shows warnings and alerts when users navigate to dangerous sites via Microsoft Edge or Internet Explorer.


Windows Defender Security Center - App & browser control

The fourth is "Device performance & health," a section that lets users check their PC's health report and even "refresh" their OS by resetting it to default settings.

The health report includes any issue the PC might be having with OS update operations, drives, battery life, or the hard drive's capacity. Users don't consider these details "security"-related, but often they provide valuable information that something might be astray.


Windows Defender Security Center - Device performance & health

Last but not least, there's also a section named "Family options," which as you'd expect, gives users control over Windows' parental controls, device activity reports, and controls for limiting access to purchasing games and apps online.


Windows Defender Security Center - Family options

The Windows Defender Security Center doesn't add any new features to Windows Defender itself, but simply gathers various preexisting Windows security and privacy settings under the Defender brand.

In November 2016, Russian antivirus maker Kaspersky Lab has filed official complaints at regulatory bodies in various countries across the EU and in Russia, asking authorities to force Microsoft to cease its efforts to sabotage third-party antivirus products in the detriment of its own security solution, Windows Defender.

The Windows Creator Update is scheduled for release in April this year. Users can test the Windows Defender Security Center via recent versions Windows Insider builds. Microsoft has also released a video detailing the new Windows Defender Security Center settings.
