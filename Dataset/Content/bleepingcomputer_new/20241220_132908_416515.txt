
	   


Kaspersky antivirus solutions injected in the web pages visited by its users an identification number unique for each system. This started in late 2015 and could be used to track a user's browsing interests.

Versions of the antivirus product, paid and free, up to 2019, displayed this behavior that allows tracking regardless of the web browser used, even when users started private sessions.

JavaScript source at fault

Signaled by c't magazine editor Ronald Eikenberg, the problem was that a JavaScript from a Kaspersky server loaded from an address that included a unique ID for every user.

Scripts on a website can read the HTML source and glean the Kaspersky identifier, which Eikenberg determined to remain unchanged on the system.


"In other words, any website can read the user's Kaspersky ID and use it for tracking. If the same Universally Unique Identifier comes back, or appears on another website of the same operator, they can see that the same computer is being used."


The purpose of the script is perfectly legitimate. One of its uses is to warn users which search results are dangerous to follow by applying a corresponding checkmark next to them. Kaspersky is not the only antivirus to do this.

Easy user tracking

Kaspersky acknowledged the issue and that it could be leveraged by third parties to "potentially compromise user privacy by using unique product id."

The company released a patch in early June. According to an advisory from July 11, an attacker could take advantage of this through a script deployed on a server they control.

Before reporting the problem to Kaspersky, Eikenberg tested the potential of his discovery by spending about half an hour creating a website that automatically copied the visitors' Kaspersky IDs.

Eikenberg argues that if he could find this issue, which is now identified as CVE-2019-8286, it is possible that marketers, malicious actors, and companies specializing in profiling website visitors have discovered this user data leak years ago and exploited it; there is no evidence to support this, though.

Fix does not eliminate tracking completely

He repeated the experiment with a patched Kaspersky product and noticed that the ID is still there, but it is the same for all users of a specific Kaspersky edition, so it can no longer be used to track individual users.

However, the tracking problem still persists at a broader level since websites can see if visitors have Kaspersky antivirus installed and how old the version is.


"That is actually valuable information to an attacker. They may use that information to distribute malware tailored to the protection software, or to redirect the browser to a suitable scamming page," the researcher wrote in a post today.


In a scenario imagined by Eikenberg, an attacker could use this to show victims a message informing them that their specific version of a Kaspersky product was about to expire and that they could extend the license with an online purchase."So, yes, “Kaspersky allows spying” is a hyped-up statement. There was a bug that could possibly have allowed some very unlikely tracking from third parties to a very limited extent, but it’s fixed now."

One solution to permanently eliminate this sort of risk is to disable the product's traffic processing function by going to the Network menu and unchecking the option for injecting script into web traffic.

Kaspersky offered the same solution to multiple users that were not comfortable with the antivirus injecting JavaScript in the pages they visited. 



Users should be aware that disabling this option impacts the functionality of other components in the product, such as secure data entry, safe money, incognito browsing, antibanner, and parental control.

image credit: Ronald Eikenberg for heise.de

Update [August 19, 16:00 EST]: Kaspersky shed a little more light on this issue, arguing the against its potential for abuse.

While marketers could have jumped at the opportunity to target visitors of their websites based on the unique identifier from a Kaspersky product, the company says, they have better tools at hand that offer significantly more info on the visitor.

Collecting the IDs to hurl malware only at Kaspersky users is an unlikely scenario, the antivirus maker believes, because the anti-phishing protection in its products would prevent users from landing on dangerous pages.

A third, and closer to a real-life scenario is to gather the details for phishing payment information; this would require more effort as easier alternatives are already available, Kaspersky says in a blog post on August 19.


"So, yes, “Kaspersky allows spying” is a hyped-up statement. There was a bug that could possibly have allowed some very unlikely tracking from third parties to a very limited extent, but it’s fixed now."
