
	   
This was a big week for ransomware news primarily because the Necurs Botnet returned with a new campaign for the Locky ransomware.  When Necurs mysteriously disappeared in early June, Locky pretty much disappeared as well. To fill this void, the Crysis and CryptXXX ransomware infections started gaining dominance. Now that Locky is back we will see three large ransomware campaigns underway, which is obviously not good news.

In summary, this week we have 5 new ransomware infections, the return of Locky, a change in the CryptXXX extension, and a couple of decryptors. Contributors and those who provided new ransomware info this week include: @fwosar, @demonslay335, @JaromirHorejsi, @JAMESWT_MHT, @siri_urz, @malwrhunterteam, @bartblaze, @DanielGallagher, @malwareforme, @nyxbone, @Seifreed, @proofpoint, @BleepinComputer. If you are interested in ransomware, I suggest you follow all of them on Twitter.

June 20th 2016

Necurs Botnet returns with new Locky Ransomware Campaign

In early June, the Necurs Botnet went offline and with it went the large scale Locky and Dridex campaigns that were being distributed by it.  As of June 20th, ProofPoint discovered that a new mulit-million email Locky campaign was started and was being pushed by the return of Necurs.

Included in this new campaign is an updated version of Locky that includes more robust anti-vm features that make it difficult to install the ransomware in a virtual machine. At the cost of not being able to target business servers that utilize virtual machines, this technology makes it more difficult for security researchers to analyze the ransomware.

A new variant of the Apocalypse Ransomware was released that utilizes the VMProtect software protection product. Using VMProtect, the ransomware developers hoped to make it more difficult for security researchers to reverse engineer their ransomware. 

Fabian Wosar, of Emsisoft, was able to get past the VMProtect protection and create a decryptor for the latest variant of the Apocalypse Ransomware's encrypted files.  This new variant uses the .encrypted and .locked extensions and will create a ransom note called [filename].How_To_Get_Back.txt for each file that is encrypted.



New ransomware discovered called Kozy.jozy that targets Russian Victims

A new ransomware called Kozy.jozy was discovered by JaromirHorejsi and analyzed by Mosh that encrypts your data with RSA encryption and changes your Windows desktop background to the ransom note.  This ransom note prompts you to email selectedkozy.jozy@yahoo.com for payment instructions. 

When encrypting your data, Kozy.jozy will pick one of 20 RSA keys to use to encrypt your data. Each of these RSA keys have a corresponding extension that added to encrypted files. This extension then tells the ransomware developer the RSA key that needs to be used to decrypt the files. An example extension is 31392E30362E32303136_01_LSBJ1.



June 21st 2016

New Ransomware called CryptoRoger that appends .crptrgr to Encrypted Files

A new ransomware called CryptoRoger has been discovered today by MalwareBytes security researcher S!Ri. This ransomware will encrypt a victim's files using AES encryption and then appends the .crptrgr extension to encrypted filenames.



CryptXXX Ransomware moves from the Crypz extension to a Random One

A new version of the CryptXXX/UltraCrypter ransomware was released today that switched from the .crypz extension to random one consisting of 5 characters. This new version now encrypts files on a computer using a random 5 hexadecimal character extension.



June 22nd 2016

Zimbra Ransomware written in Python targets Zimbra Mail Store

A new ransomware was discovered that is written in Python and targets the Zimbra enterprise collaboration software. Reported by one of our visitors, this ransomware targets the Zimbra email message store folder and encrypts all of the files located within it. It then creates a ransom note in /root/how.txt that demands 3 bitcoins to get the files back.

Decrypted: New Apocalypse Ransomware variant discovered that uses the SecureCrypted Extension

A new version of the Apocalypse Ransomware was discovered by security researcher's Daniel Gallagher and Michael Gillespie that adds the .SecureCrypted extension to encrypted files.  The ransomware will then terminate explorer.exe, taskmgr.exe, and regedit.exe and display a ransom note locker that covers the entire screen. This ransom note states that the victim should email recoveryhelp@bk.ru for payment instructions. 



Fabian Wosar, of Emsisoft, is updating his Apocalypse Decryptor to handle this variant and should be available by the end of the day.

June 23rd 2016

A new ransomware was discovered that asks you to email Towerweb@yandex.com

A new ransomware was discovered by security researcher Jack that ransoms your data for $100 USD in bitcoins. Once encrypted, the ransom note states that once payment is made, the victim must email towerweb@yandex.com in order to receive the decryptor..



New KratosCrypt Ransomware, based on Hidden Tear, Discovered

Michael Gillespie discovered a new hidden tear ransomware variant called KratosCrypt.  This ransomware encrypts a victim's data using AES encryption and then demands .03 bitcoins, or ~$20 USD , to get your files back. When encrypting a victim's data it will add the .kratos extension to encrypted files and then show a ransom note, which is downloaded from http://pastebin.com/raw/RNQ53mua. This ransom note is named README_ALL.html and contains instructions to email kratosdimetrici@gmail.com after making a payment to get the decryptor.

Victim's can use Michael's Hidden Tear Brute Forcer to generate the decryption key and then use his Hidden Tear Decryptor to decrypt their files for free.
