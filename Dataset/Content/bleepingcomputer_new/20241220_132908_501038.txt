Modifying the master boot record (MBR), which contains details about available partitions and helps load the operating system, allows the malicious payload to start immediately when the computer boots, even before the operating system is started.

It is suspected that this weaponized version of the manifesto is being distributed as a vigilante attack against those who want to download the original document and to halt its spread.

Researchers at network protection company Blue Hexagon discovered a file that pretends to be the original 74-page manifesto of the Christchurch shooter, but has been altered to include a malicious payload.

Hidden inside the modified document is a VBA script downloads a binary payload. The code is obfuscated, which makes it more difficult to determine its intention.



The downloaded executable is called "Haka.exe" and replaces the MBR information with a message that is shown after the computer restarts. Once they open the rigged document, victims cannot escape the process as the executable also forces the computer to reboot.



After reboot, a simple message is shown, reading "This is not us!" apparently as a counter-manifesto that adopted the tactic of old-school, non-destructive malware, to become visible.



Other changes in modified version

The file, available in .DOC and .DOCM formats, was seen distributed on the same file-sharing services as the original document.

However, there are differences that users can spot before infecting their computer. One is the name of the author, which in the modified version of the manifesto is "Maori" - the name for the indigenous people in New Zealand.

Also included is an additional third page that contains an image of Maori tattoo representing Manna, which means many things including honor and respect.



The document is also shorter than the original. It "only contains a subset of the pages, not the entire document," Blue Hexagon told BleepingComputer.

Finally, the original manifesto is password protected against changes, while the forged document does not feature such protection.

The researchers say that the "This is not us!" campaign started last week after the New Zealand government announced that possessing the Christchurch shooter's manifesto is illegal in the country - an action that echoes the decision major mobile carriers took to temporarily ban websites that distributed gruesome content from the incident. They feel this document is being distributed as a vigilante attempt to stop the distribution of the manifesto.

This cannot stop the manifesto's dissemination across the web, though. The ban and the fact that White House counselor Kellyanne Conway encouraged people to read the document "in its entirety" is likely to stir the curiosity of many, who may end up with the modified variant instead.

Make your computer boot normally again

"Haka.exe" does not make any changes that can't be reverted. It looks like its purpose is just to make a statement. Restoring your computer to normal boot is not only possible, but it is also easy.

It is just a matter of running the 'bootrec.exe' tool in the Command Prompt and launching the command '/fixmbr.' the command should be like this:

bootrec.exe /fixmbr

Launching the Command Prompt is possible even if the operating system can no longer boot. Windows 10 should detect the problem on its own and offer the Automatic Repair option.

Choose Advanced Options and then Troubleshoot on the next screen. This should show a set of choices, with Command Prompt among them.

The alternative is to use a recovery media (disc or USB drive) which should work on older versions of Windows, too. Boot from the media and follow the instructions to get to Microsoft's command line tool
