
	   


Security researchers have discovered a never-before-seen remote access trojan (RAT) that utilizes Tor proxies to redirect traffic from infected hosts to servers hidden on the Tor network.

First detected by Cisco Talos experts, this new RAT is named Athena, but researchers refer to it as AthenaGo, as not to confuse it with the Athena DDoS malware discovered a few years back.

AthenaGo RAT written in the Go programming language

Compared to other RATs, Cisco researchers say that AthenaGo has a few features that stand out on its own. First and foremost, Athena Go is the first RAT written in the Go programming language, albeit not the first malware.

The only downside, as Cisco researchers explained in a technical analysis of AthenaGo, is that Go binaries include a little bit more details that helps out researchers in detecting the malware's capabilities much easier.

AthenaGo deployed against Portuguese targets

Cisco says that AthenaGo is currently distributed via spam emails and it's only targeting users in Portugal, as the theme of the spam lure is a Word file posing as a document received from Portugal's main postal service.

As with most macro malware these days, opening this file and allowing the macro script to execute results in the macro downloading and installing the AthenaGo RAT.

According to Cisco, both the AthenaGo binary and the malicious Word files appear to have been signed with the same username, meaning it's likely that one person is behind the AthenaGo's creation and distribution.

Following the initial infection, the AthenaGo RAT goes through a series of procedures by reporting to its C&C server, and later requesting a series of commands it has to execute on each infected PC.

Cisco says that AthenaGo only supports six commands, but they are all more than enough to do extensive damage, as they cover all basic operations.

    ListDir - This command returns a directory listing from the infected system.
	    ListProcesses - This command returns a list of processes running on the infected system.
	    KillProcess - This command causes the malware to execute the taskkill command against a target process running on the infected system.
	    DownloadFile - This command causes the malware to download a file and save it into a target location specified in the command parameters.
	    DLRUN - This command causes the malware to download a file, save it to %TEMP% and execute the downloaded file.
	    RunCMD - This command uses Go's os/exec package to execute system commands on the infected system.
AthenaGo uses Tor proxies to connect to its Tor-based C&C server

All the communications to the C&C server are carried out via the tor2web.org service, which is a proxy system that redirects traffic from the public Internet to the Tor network without requiring users to have the Tor package installed locally.

This means AthenaGo doesn't need to download and install Tor on each infected PC, like previous malware variants that relied on Tor to hide their C&C servers.

The reasoning behind using Tor to hide C&C servers is to safeguard them from law enforcement takedowns. By using Tor proxies such as Tor2Web, AthenaGo's creator(s) has negated this benefit, as Tor2Web and similar Tor proxies are usually fast in blacklisting malicious URLs.

This means they'll have a short window to operate until Tor2Web bans the URL. Nevertheless, this approach has its benefits because security firms must always keep an all-watching eye on AthenaGo variants and identify the C&C server URL in order to request its blacklisting.

Tor2Web is very popular with ransomware groups

"This approach [of using Tor2Web] has shown to be increasingly attractive to cybercriminals," Cisco also noted.

Until now, Tor2Web proxies have been extremely popular with ransomware authors, who prefer to show Tor2Web URLs alongside .onion links.

Tor link:
athenabeicoxjr2l[.]onion
Tor2Web link:
athenabeicoxjr2l[.]onion[.]to
OnionLink (another Tor proxy service):
athenabeicoxjr2l[.]onion[.]link

If users can't install the Tor Browser, the Tor2Web links can be used as alternatives URLs and relay the victim to the ransom payment site.
