
	   


A family of banking trojans for Android has spread beyond Russia, a region it normally targeted, and operates in an aggressive way to replace the default SMS app and deploy phishing screens on compromised devices.

Dubbed Riltok, the strain has been known since March 2018 and operated mainly in Russia, where 90% of its victims are located.

Spreading outside Russia

Towards the end of the year, the cybercriminals behind it created a version destined for English speakers. In January 2019 occurred Riltok variants for Italian and French victims.

The malware is distributed through SMS phishing (smishing). Potential victims get a message with a link to a website impersonating a free ad service that is popular in the region. Riltok poses as an updated version of a mobile app.

Distribution among victims in European countries is done through compromised devices that send a message to people in the contact list about a payment being made to them. The text is from the victim's number so chances are the recipient opens the link, which impersonates a popular payment service, such as Avito, Youla, Gumtree, Leboncoin, or Subito.


“%USERNAME%, ti ho inviato il soldi sul subito subito-a[.]pw/6*****5” (It.)

“% USERNAME%, ti ho inviato il pagamento subitop[.]pw/4*****7” (It.)

“%USERNAME%, je vous ai envoyé un prepaiement m-leboncoin[.]top/7*****3” (Fr.)

“%USERNAME%, j’ai fait l’avance (suivi d’un lien): leboncoin-le[.]com/8*****9” (Fr.)


Installation is possible only if Android is set to accept apps from unknown sources.  In these cases, the malware tricks the user into granting it permissions to use special features in AccessibilityService.

This is achieved through a fake warning, according to security researchers from Kaspersky analyzed how the banker works and monitor its distribution across the globe.



Riltok is aggressive in its request, showing the message continuously until the victim gives up and agrees or the device is disinfected.

Baiting and data slurping

Once up and running, the banker contacts its command and control (C2) server for configuration files and instructions.

Newer versions start by launching in the browser a phishing site that impersonates a free ad service. It asks for login credentials along with payment card data, which are delivered to the C2.

Infected devices are registered on the attacker's servers with an ID that is automatically generated based on the phone's International Mobile Equipment Identity (IMEI) code.

The malware collects data about the devices, including the phone number, country, mobile carrier, device model, root rights, and the Android version. Lists with the entire contacts database, installed apps, and all short text messages are also delivered to the C2.

After checking the banking apps installed on the victim host, Riltok can serve phishing pages impersonating them. With access to incoming SMS, the cybercriminals can get the temporary codes for logging into the banking service.

Verifying card data

Kaspersky says in a report today that the AccessibilityService allows the malware to monitor events. Depending on the app that generates the events, it can obtain banking details through fake screens and phishing pages in the web browser, as well as hide from the user the security notifications delivered by antivirus apps or security settings.

The researchers say that the functions embedded in this threat allow it to run basic validation checks for the card data it steals. Thus, it can verify the card validity period, and if the card number is correct, if the CVC has the right length, and if the details have been blacklisted.



While all these features are present in the Riltok variant for the Russian victims, the versions customized for other countries is not fully functional, as if it were a test run.


"For example, the default configuration file with injects is non-operational, and the malware contains no fake built-in windows requesting bank card details," says Kaspersky.


This also explains the smaller number of victims in other parts of the world.
