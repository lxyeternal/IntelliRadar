
	   
AVG has released a decryptor for the Bart Ransomware infection, which stores your files in password-protected zip files. Created by the same actors behind Dridex and Locky, Bart Ransomware will password protect a victim's data without communicating with a command & control server. This allows the ransomware to password protect a victim's files even if the computer is not connected to the Internet.

Using AVG's decryptor is fairly straight forward, but does require a victim to have the same file in its password-protected zip format and its original format.  These two files will then be compared by the AVG decryptor in order to assist in brute forcing the password for the zip file. So for example, to use the decryptor I could use the Window sample picture desert.jpg and its Bart zipped counterpart desert.jpg.bart.zip.

What I usually do is create a folder on the desktop and put the samples being used for the comparison in the same folder as shown below.


Prep Folder

Once you have two samples handy, you can download the Bart Decryptor and execute it.  Keep following the prompts till you get to the page requesting a original and zipped file as shown below.

At the above screen select the encrypted file and the original file and keep clicking on the Next button until you get to the part where the AVG Bart Decryptor will try and brute force the zipped file's password.  Once it is able to brute force the password, it will display it as shown below. Though the decryption tool states it can take days to find the correct password, in my test it only took 51 seconds.


Cracked Password

Now that the password has been found, keep clicking on the Next button to begin the decryption of the files on the hard drive. When it has finished unzipping your files, you can close the program.
