
	   


Microsoft released security updates via the Microsoft Store last week, and it's confusing many users who want to make sure their devices are protected.

When Microsoft releases security updates for Windows, they are almost always released via Windows Update or by standalone updates that can be downloaded from the Microsoft Catalog.

On June 30th, Microsoft released two out-of-band security updates for remote code execution vulnerabilities in the Windows Codecs Library. They stated that they affected both Windows 10 and Windows Server at the time.

Even more confusing, the advisories did not explain what Microsoft Store apps would be updated to resolve the vulnerabilities, leaving users in the dark as to whether they were affected and patched by an update.

Vulnerabilities in the HEVC Video Extensions

On July 1st, Microsoft updated the advisories [1, 2] to include a FAQ that explained that Windows Server was not affected and that the vulnerabilities are in the HEVC Video Extensions.

This package is available from the Microsoft Store as the packages named 'HEVC Video Extensions' or 'HEVC Video Extensions from Device Manufacturer.'


HEVC Video Extensions packages

Microsoft states that these are optional packages and that only those people who have them installed would receive the update.

The FAQ also mentions that the fixed version of the HEVC extensions is 1.0.31822.0, 1.0.31823.0 and that the following PowerShell command can be used to check the installed package version.

Get-AppxPackage -Name Microsoft.HEVCVideoExtension

Zero Day Initiative researcher AbdulAziz Hariri, who found these vulnerabilities, provided some additional details to BleepingComputer.

"The vulns are in the hevcdecoder_store.dll extension (HEVC codec package). This extension is not installed by default. The bugs in this codec are triggered through HEIC images  (HEIFextension package. which is installed by default). The HEVC package can be installed in multiple ways."

"As far as I know, the user installs them manually through the store or accepting them to be installed from media applications like photos etc.," Hariri told BleepingComputer.

While my computers do not have the HEVC extensions installed, I did have the HEIC Image Extensions installed. These were upgraded on June 30th as well.


HEIF Image extension updated

As the HEIF Image Extensions package relies on HEVC, we asked Hariri if it was related, but he was not sure if they were patched as well.

Organizations have Microsoft Store disabled

Going outside of normal Windows security update distribution channels makes it difficult for enterprises who have purposely disabled certain Windows features.

For those companies who have disabled the Microsoft Store or Microsoft Store automatic app updates, the vulnerable computers will not be able to receive the fixes without removing this policy.

A BornCity.com reader explained the concern about this in clear and easy to understand terms.

"We have deactivated the store and we want to keep it that way."

To add insult to injury, AskWoody has reported that some users are having problems installing the update via the Microsoft Store.

When attempting to do so, they receive "access denied" errors, as shown in the tweet below.



With the lack of initial information and the use of Microsoft Store to distribute security updates, this release of security updates has been confusing from the very beginning.
