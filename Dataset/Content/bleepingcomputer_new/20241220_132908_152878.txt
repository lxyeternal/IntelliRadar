
	   


The relatively new espionage group Seedworm proves to be highly adaptive by using GitHub to keep their malware and by carefully observing the developments on the infosec scene via social networking services.

This approach helped the gang evolve their tools on a constant basis and create new ones. The latest tool associated with this group is Powemuddy, a backdoor used in the initial stages of the attack to establish persistence on the target machine, which can also function as a downloader.

Another tool the gang uses is the Powermud backdoor, controlled via a proxy network that hides that makes it more difficult to find the location of the command and control (C2) server.

Analysts from Symantec's  DeepSight Managed Adversary and Threat Intelligence (MATI) team found that the actors behind Seedworm store their malware and tools of interest in a public repository on GitHub.

In a report on Monday, they say that it contained "scripts that very closely match those observed in Seedworm operations."

Apart from its own malware, the threat actor used the GitHub repo to keep publicly available tools, which they sometimes customize before using them for their cyber espionage tasks.

Attributing the GitHub account to Seedworm was possible because the analysis of the tools hosted there revealed that some of them had been used in attacks carried out by the group.

For example, the analysts found in the repo a PowerShell script that matched one running on a victim machine compromised by activity attributed to Seedworm.

Another tell were numerous commands for the Crackmapexec post-exploitation tool for penetration testing that matched victim host activity. The tool is used to asses the security of large Active Directory networks and to obtain Windows login credentials.


credit KitPloit

"Seedworm uses off-the-shelf, unmodified versions of these tools as well as custom-compiled variants which we have determined are only used by this group," the report from Symantec says.

MATI researchers were able to connect the GitHub account with more public online activity. They made a link to a Twitter profile that shared similarities with the GitHub persona.

Whoever was behind the Twitter account used the social network to stay up-to-date with the latest developments in the cybersecurity world.

"This Twitter account follows numerous security researchers, including those who have written about the group in the past as well as developers who write the open source tools they use," the researchers say.

Seedworm infects machine claimed by Fancy Bear

Also known by the name of MuddyWater, the adversary was first observed in 2017. It is particularly active, making 131 victims in 30 organizations between late September and mid-November 2018.



Symantec's MATI analysts found in September evidence of Seedworm related activity on a computer in an embassy in Brazil belonging to an oil-producing nation.

It turned out that the group was not alone on the system as the machine had already been compromised by another cyber espionage group, the infamous Fancy Bear.

This was interesting enough for the researchers to start poking around in search for more clues about Seedworm's activity.

Most of the victims were in Pakistan and Turkey, but Seedworm's attack space extends to Russia, Saudi Arabia, Afghanistan, Jordan and other places. It also compromised organizations in Europe and North America that are connected to the Middle East.

According to the researchers the top targets are from the telecommunications industry, followed by IT services in government agencies. Entities tied to the production of oil and gas come in third place, and  Symantec found 11 victims, all of them belonging to one Russian company that is active in the Middle East.
