
	   


A new Emotet Trojan variant has been observed in the wild with the added capabilities of using compromised connected devices as proxy command-and-control servers and of employing random URI directory paths to evade network-based detection rules.

The new Emotet version was detected by Trend Micro's research team while analyzing the malware's network traffic and discovering that it comes with "different POST-infection traffic" and that is also trying to conceal its real C2 servers using previously compromised devices as proxies.

Connected devices as an extra C2 communication layer

According to multiple reports from security researchers [1, 2, 3, 4], Emotet is not using IoT devices or routers as C2 proxies as originally reported.

If the router has legitimate ports forwarded to other devices, such as an IP camera, it may appear as if the router is an IP camera infected with Emotet.

Instead, this is just the router with ports forwarded to multiple discrete internal devices, with the Emotet port mapped to a Windows computer.

Marcus "MalwareTech" Hutchins, who discovered the original UPnP plugin for Emotet, told BleepingComputer that once the UPnP plugin forwards a port for the infected machine, the infection will test to make sure it is accessible from the Internet. If so, it will send the public IP address to Emotet's C2 server so that the compromised machine can be used as a C2 proxy.

"These discoveries also show that the malware is being used to compromise and collect vulnerable connected devices, which could become resources for other malicious purposes," states Trend Micro.

Emotet's masters need to conceal the real C2 servers used in their campaigns because their IP addresses are hardcoded in the malware which makes it very easy to analyze the botnet's infrastructure.


Some of the compromised devices used as proxy C2 servers

Randomly generated URIs for a stealthiness boost

The Emotet payload was delivered onto the targets' computers using malicious emails which come with zipped up Powload Trojan attachments which will download the Emotet executable after being launched.

Trend Micro's researchers monitored the new POST-infection Emotet traffic since March 15 and they found out that the new banking Trojan variant uses randomly generated URI directory paths in its POST requests to better blend in with the host's outgoing web traffic.

Before this was implemented, Emotet would use "an HTTP GET request to send victim information to the C&C server, and the data is stored in the Cookie header. The data was encrypted using an RSA key, AES, and then encoded in Base64 before being added to the Cookie value."

This new version sends the stolen info within the HTTP POST message body, "encrypted with an RSA key and AES, and encoded in Base 64" allowing it to "evade detection or delay further investigation if it is detected." 


Emotet traffic comparison

These newly added features increased the overall complexity of the malware's C2 traffic and are in line with previously observed Emotet behavior according to US-CERT's TA18-201A advisory:


Emotet is a polymorphic banking Trojan that can evade typical signature-based detection. It has several methods for maintaining persistence, including auto-start registry keys and services. It uses modular Dynamic Link Libraries (DLLs) to continuously evolve and update its capabilities. Furthermore, Emotet is Virtual Machine-aware and can generate false indicators if run in a virtual environment.


More to the point, Emotet (which is also known as Geodo or Heodo) is a continuously evolving modular Trojan [1, 2, 3, 4] created by the MUMMY SPIDER (aka Mealybug) threat group.

Mealybug used it to drop malware payloads on their targets via large scale malspam campaigns which lead to the theft of financial info such as cryptocurrency wallets or bank logins. The Trojan is also known to exfiltrate sensitive data like login credentials and Personally Identifiable Information (PII) data.

After Emotet was improved with modules designed to make it an efficient a carrier conduit for other banking Trojans or various other information-stealing modular bots such as Trickbot, the hacking group behind it mutated into a huge botnet they can rent to other threat groups.

Following this change in tactics, Emotet was seen dropping various strains of ransomware ranging from BitPaymer and LockerGoga to the infamous Ryuk [1, 2, 3] which was behind a 90% increase in ransom amounts during Q1 2019 according to Coveware’s researchers.

While Trend Micro did not provide Indicators of Compromise (IOCs) for this new Emotet variant, US-CERT provides a detailed list of "best practices to limit the effect of Emotet and similar malspam" at the end of its TA18-201A malware alert.

Update April 30 15:46 EDT: Article updated to remove mentions of IP cameras being compromised by Emotet following multiple reports from security experts and private conversations BleepingComputer had with security researchers Marcus "MalwareTech" Hutchins and JTHL.
