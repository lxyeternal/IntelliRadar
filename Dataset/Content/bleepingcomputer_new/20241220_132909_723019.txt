
	   


Site administrators still using the Rich Reviews plugin for WordPress are easy targets as hackers are currently exploiting an unpatched vulnerability for malvertising campaigns.

Although the plugin was removed for security reasons from the WordPress repository more than six months ago, it is estimated that 16,000 websites still have it running.

Familiar XSS payload

The plugin is vulnerable to unauthenticated plugin option updates and attackers are leveraging it to deliver stored cross-site scripting (XSS) payloads. The JavaScript is triggered by both website visitors and authenticated administrators.

One is a lack of access controls for changing the plugin's options, and the other is not sanitizing the values of the options.

The malvertising campaign delivers a nearly identical XSS payload as seen in operations of the same kind tracked since April. The company published at least three reports this year.

The purpose of the threat actor is to redirect users to dangerous destinations like tech support scams, malicious Android packages, fraudulent websites, or malware locations. Another goal seems to be displaying pop-ups that promote dubious pharmaceutical products.

A report on Tuesday informs there are three IP addresses associated with this campaign:

94.229.170.38
	183.90.250.26
	69.27.116.3
When de-obfuscated, the payload runs a script named 'place.js' that is hosted on the domain adsnet[.]work.



Defiant recommends website administrators that still have Rich Reviews active to find an alternative and remove the plugin from their site.

Developer promises to return

It appears that the authors of the plugin are aware of the vulnerability and are working to fix it. An admin impacted by the campaign complained last week about three of her websites being infected by a malicious script associated with this malvertising campaign.

Nuanced Media, the developer of the plugin replied by saying that they plan a comeback in the following two weeks. However, all sites that have Rich Reviews installed are potential targets unless they remove the product.



However, even if developers come up with a fix, it would not reach Rich Reviews users until the plugin makes it back into the WordPress repository.

Update [10.10.2019]: Rich Reviews is back into the WordPress repository but under a different developer. Starfish Reviews adopted the plugin and fixed the XSS vulnerability in version 1.8, released on October 7.

Yesterday, Starfish updated the product to 1.8.1, with a fix for users reporting that they lost access tot he plugin's admin page following the update. Some users are still reporting this issue and a new update with a fix will be available for them, too.

The active installation count for this plugin is over 10,000, with more than 1,400 downloads recorded in the past two days. Over 85% of the installations are for the vulnerable version 1.7, while the latest, secure release, reached 9.1%.

In a post published on Monday, Starfish explains the process of taking over the development of the plugin and how its small team revived it.
