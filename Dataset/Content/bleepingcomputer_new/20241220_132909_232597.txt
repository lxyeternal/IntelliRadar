
	   


Researchers discovered two vulnerabilities in Alaris Gateway Workstations that are used to deliver fluid medication. One of them is critical and an attacker could leverage it to take full control of the medical devices connecting to it.

A flaw in the firmware code of the device has been assigned the highest severity score, a perfect 10, so it can be exploited remotely and without authentication. The other issue received is less severe and affects the workstation's web-based management interface.

Alaris Gateway Workstation (AGW) is a product of Becton Dickinson and is used to communicate with infusion pumps and to power them during blood transfusions, anesthesia, and various therapy sessions like chemotherapy and dialysis.

Multiple such devices can be connected to a single AWG to deliver various medical drugs to a single individual.

Attacker can alter drug infusion rate

Researchers at CyberMDX discovered that AGW's firmware can be replaced remotely with a custom version. An attacker sitting on the same network as the target system would be able "update and manipulate a CAB file, which stores files in an archived library and utilizes a proper format for Windows CE," say the researchers.

With this type of access, the adversary would be able to alter the dosage of the drug dispensed by certain models of infusion pumps connected to an AWG, which are common in hospital wards and intensive care units.

While this vulnerability (tracked as CVE-2019-10959) is easy to exploit, an adversary would still need to be knowledgeable about the Windows CE environment, how communication protocols function in the affected product; an adversary would also need to know how to modify a CAB file, which AWG uses to store files in an archived library and utilizes a proper format for Windows CE.

A Becton Dickinson representative told BleepingComputer that the affected product is not used or sold in the U.S. He said that the security researchers reporting the two problems were "not able to replicate the manipulation of infusion parameters, and there have been no reported exploits of this vulnerability."


"Because the vulnerability is limited to a single BD infusion system offering (the Alaris™ Gateway Workstation) that is not sold in the U.S., it is important to note this disclosure does not apply to the majority of BD infusion systems."


CyberMDX disclosed their findings privately to Becton Dickinson, who confirmed the vulnerability. The two companies worked together to remediate the problem.

The researchers recommend the following actions to lower the risk of an attacker exploiting this vulnerability:


Customers block the SMB protocol
	Customers should segregate their VLAN network
	Customers should ensure only appropriate associates have access to the customer network


The second vulnerability discovered by CyberMDX is tracked as CVE-2019-10962 and has a high-severity score of 7.3. It lies in the web-based interface of AWG and exploitation rewards the attacker with access to the device monitoring, event logs, and configuration of the device.

Leveraging CVE-2019-10962 requires knowing only the IP address of a target AWG, which makes for an easy mission for someone already on the network.

ICS-CERT today released an advisory for the two vulnerabilities, including mitigation possibilities.

The steps recommended for closing the risk are to install the latest AWG firmware version, currently 1.3.2 (available since February 2019) or 1.6.1 (available since April 2018), network segregation, and ensure that only trusted parties have access to the network.

The vendor spokesperson told us that installing the latest firmware version corrects the vulnerability and that "those who don’t update their firmware, BD will provide a software patch within 60 days."
