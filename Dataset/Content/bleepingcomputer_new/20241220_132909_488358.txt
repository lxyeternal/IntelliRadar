Kibana is a browser-based platform that makes it easy to work with the large volumes of data stored in Elasticsearch indices. It is useful for data analysis and visualization in a variety of forms.

The Console plugin provides an easier way to interact (generate and send queries) with the REST API of Elasticsearch. It eliminates the need to use the terminal and provides direct access to the stored data.

The proof-of-concept (PoC) code is a one-liner with barely more than 110 characters and it has as destination path the password directory. When run, the credentials would be dumped in the Kibana log.

A local file inclusion security bug can be used with files that are already present on the server. Some apps may be vulnerable, though, and an adversary may be able to leverage them to create a reverse shell.

An easier way to exploit LFI successfully is to combine it with a bug that enables uploading arbitrary files.

Published by a member of the Slow Mist Technology team, the PoC is for CVE-2018-17246, which affects versions of Kibana before 6.4.3 and 5.6.13, discovered by Nethanel Coppenhagen of CyberArk Labs, who provides a detailed description of the bug.



"An attacker with access to the Kibana Console API could send a request that will attempt to execute JavaScript code. This could possibly lead to an attacker executing arbitrary commands with permissions of the Kibana process on the host system," reads the vulnerability summary.

The recommended action is to upgrade the Elastic Stack to the newer versions 6.4.3 or 5.6.13. If this is not possible, users can disable the Kibana Console plugin until the upgrade time. This can be done from the configuration file ('kibana.yml') by setting "console.enabled: false."
