
	   


Virtual disk files are locked containers that shield the items inside from online or local security defenses. The trick can help adversaries deliver malware invisibly to a target's computer.

Vulnerability analyst Will Dormann last week published research on VHD and VHDX files being treated like a black box by Windows and the operating system.

The VHD bubble

The details stirred the interest of security researchers who used real malware encapsulated in a VHD file to test the detection rate of multiple antivirus engines. Products that normally detected the malware samples became blind to them.

However, JTHL obtained these results just by scanning the VHD file, without mounting it. BleepingComputer observed that once the drive is active, the on-access scanning feature in Windows Defender would kick in and flag the malicious item.



Malicious VHDs bypass Gmail and Chrome security

In a testing of his own, security researcher Jan Poulsen noticed that antivirus products are not the only ones blinded by the container and found a way to run the malware without triggering the alarm.

He built a script that mounted the VHD automatically and executed the malware inside.


Yesterday i did a full attach and execute script. Et will mount the .vhd automatically and execute the malware inside. At no point is the malware detected
— ⛧ ʲªͷ ҎΩΰⱠᶊἕא (@Jan0fficial) September 6, 2019

The "points" he refers to in the tweet are attaching the poisonous VHD to a Gmail message, downloading the file with Google Chrome, and the antivirus built into the operating system, Windows Defender.

Gmail blocks some file types in attachments for security reasons. A list of banned extensions includes executables, which may spread harmful software. This restriction holds even when the files are compressed in an archive.

Neither Gmail nor Chrome can mount VHD containers, though, to check the files inside. Furthermore, the extension is not blacklisted as a potential risk, likely because they have not been considered as containers for delivering malware.

The same is valid for antivirus products, Will Dormann told BleepingComputer. VHD and VHDX are disk images, so they could have inside any filesystem supported by Windows.

This makes parsing the contents a more complicated task than in the case of archives, for which standard libraries exist to unpack them.

Silent malware deployment

Evading detection is easy but the tricky part is to keep antivirus defenses silent when deploying the malware, and Poulsen found a way to do it.

Instead of mounting the images manually, the researcher automated the process. He used the 'diskpart' command-line disk partitioning utility that comes with Windows.

For some reason, this does not work with 'diskmgmt,' which is a more popular choice. Both tools require admin privileges on the system.

A main script loads a file with the command to select the virtual drive from its location and attach it.



Poulsen added additional instructions for a five-second delay before running the malware, an Agent Tesla sample, in the VHD. Of course, once the threat is running, antivirus products can see the malicious activity and block it.

But the scope of the test was to check if malware enclosed in a VHD container can make it undetected until it executes on the victim host.

The admin permissions needed to run 'diskpart' are not necessarily a hurdle in the way of an adversary. A privilege escalation vulnerability could iron out this wrinkle.

Poulsen's proof-of-concept, although unpolished, shows that planting well-detected malware on a computer without triggering any alarm is not only possible but dead easy, too.
