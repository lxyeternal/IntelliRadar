
	   


Mozilla has released Firefox 67.0.4 to fix a security vulnerability that has been used in targeted attacks against cryptocurrency firms such as Coinbase. Users of Firefox should immediately install this update.

This week, Mozilla released Firefox 67.0.3 to fix a critical remote code execution vulnerability that was being used in targeted attacks. Since its release, it was discovered that the vulnerability and another unknown one was chained together as part of a phishing attack to drop and execute malicious payloads on victim's machines.

Today, Mozilla released Firefox 67.0.4 that fixes the second unknown vulnerability that was used during this chained attack.

This vulnerability is a sandbox escape vulnerability reported by Coinbase Security that allows attackers to escape from the browser's protective sandbox. Chaining this vulnerability with the previously one fixed in Firefox 67.0.3 allows  attackers to perform remote code execution on vulnerable computers.


Sandbox Escape vulnerability in Firefox

Due to the severity of this vulnerability and the fact that it was already used in targeted attacks, it is imperative that users upgrade to Firefox 67.0.4 immediately.

Users can manually check for new updates by going to the Firefox menu -> Help -> About Firefox. Firefox will then automatically check for a new update and install it.

You can also download the latest version from the Firefox download page.
