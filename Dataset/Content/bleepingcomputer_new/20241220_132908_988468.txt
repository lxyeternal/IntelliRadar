iOS third-party keyboard extensions are apps designed to run either entirely standalone, without requiring access to any external services, or with "full access" for additional features that need network access.

Full access granted without approval

"Apple has discovered a bug in iOS 13 and iPadOS that can result in keyboard extensions being granted full access even if you haven't approved this access," says the document spotted by TechCrunch.

To see if you have any third-party keyboard extensions installed on your iPhone, iPad, or iPod touch, you have to open the Settings app and then go to  General > Keyboard > Keyboards.

Passcode bypass issues and reintroduced security flaws

This is not the first iOS issue that surfaced during the last month, given that just five days before Apple release iOS 13, a passcode bypass was discovered by security researcher Jose Rodriguez that allowed one to view the contacts on a locked device.

This was not the first passcode bypass bug disclosed by Rodriguez; previously he has found and reported passcode bypasses in iOS 12.0.1 and 12.1.

One month earlier, iOS security researcher Pwn20wnd was able to develop and publish a public jailbreak for the latest stable iOS version after Apple mistakenly reintroduced a vulnerability patched in the iOS 12.3 release, an issue previously used to create an iOS 12.2 jailbreak.

The vulnerability is a use after free tracked as CVE-2019-8605, and it was originally discovered by Google Project Zero's Ned Williamson and patched by Apple on May 13.

One week later, Apple released iOS 12.4.1 to fix the security flaw that could have also been abused by malicious apps which could subsequently "execute arbitrary code with system privileges."

At the time, Apple acknowledged Google Project Zero's Ned Williamson contribution and also provided additional recognition for Pwn20wnd's assistance in finding and fixing the security flaw.
