
	   


Today, Adobe released security updates that fix numerous critical vulnerabilities in Adobe Acrobat and Reader. This was a massive update, with over 87 vulnerabilities being patched by Adobe.

Of these 87 vulnerability, 39 were Critical, which means that they allowed an attacker to perform code execution or privilege escalation on a vulnerable computer. A code execution vulnerability is when an attacker can run commands on the vulnerable computer, while a privilege escalation vulnerability allows an attacker to execute commands at higher privilege level.

When you chain these two types of vulnerabilities together, an attacker can gain full control of a vulnerable computer.
