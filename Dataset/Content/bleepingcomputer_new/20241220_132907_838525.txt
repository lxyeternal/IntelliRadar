
	   


A new human-operated ransomware strain is being deployed in highly targeted attacks targeting small to medium size organizations in the software and education industries since at least December 2019.

The ransomware, dubbed Tycoon by security researchers with BlackBerry Threat Intelligence and KPMG, is a multi-platform Java-based malware that can be used to encrypt both Windows and Linux devices.

Tycoon is manually deployed by its operators in the form of a "ZIP archive containing a Trojanized Java Runtime Environment (JRE) build" after they infiltrate their victims' networks using vulnerable and Internet-exposed RDP servers as a stepping stone.

"The overlap in some of the email addresses, as well as the text of the ransom note and the naming convention used for encrypted files, suggests a connection between Tycoon and Dharma/CrySIS ransomware," the Blackberry/KPMG researchers found.

Systems backdoored and anti-malware disabled

"The ransomware was deployed in a targeted attack against an organization, where the system administrators had been locked out of their systems following an attack on their domain controller and file servers," the researchers discovered when analyzing a ransomware attack that took place in April 2020.

"After conducting forensic investigations of the infected systems, it became apparent that the initial intrusion occurred via an Internet facing RDP jump-server."


Attack timeline (Blackberry/KPMG)

While finding hints on the attackers' activities after exploiting the RDP servers was not possible because they were already restored, examining the encrypted devices revealed that:


• Image File Execution Options (IFEO) injection was used to gain persistence and attach a backdoor to the Microsoft Windows On-Screen Keyboard (OSK) feature.
• Active Directory passwords were changed to deny access to the infected servers.
• The anti-malware solution was disabled using ProcessHacker.
• After preparing everything for the final stage, the attackers encrypted all file servers and network backups by deploying the Java ransomware module.


The ransomware uses the Java JIMAGE format to create custom malicious JRE builds executed with the help of a shell script.

Since this malicious JRE build contains both a Windows batch file and a Linux shell, the researchers feel that the Tycoon operators can use the ransomware to encrypt Linux servers.


Tycoon launch shell scripts (Blackberry/KPMG)

No decryptor for files encrypted by newer versions of Tycoon

Tycoon ransomware encrypts the victims' files using" an AES-256 algorithm in Galois/Counter (GCM) mode3 with a 16-byte long GCM authentication tag, which ensures data integrity."

"Because of the use of asymmetric RSA algorithm to encrypt the securely generated AES keys, the file decryption requires obtaining the attacker's private RSA key.

"Factoring a 1024-bit RSA key, although theoretically possible, has not been achieved yet and would require extraordinary computational power."


Tycoon ransomware ransom note

While there was some success decrypting Tycoon-encrypted files with the .redrum extension using a private RSA key obtained from a decryptor bought by one of the victims (Emsisoft provides a free decryptor here), decrypting files locked by newer Tycoon versions that use the .grinch and .thanos extensions is not yet possible.

"Tycoon has been in the wild for at least six months, but there seems to be a limited number of victims," the report concludes. "This suggests the malware may be highly targeted."

"It may also be a part of a wider campaign using several different ransomware solutions, depending on what is perceived as more successful in specific environments. 

More details regarding the ransomware's delivery, execution, behavior, and file encryption module can be found within Blackberry/KPMG's Tycoon report, together with a list of indicators of compromise (IOCs).

One of many manually deployed ransomware strains

Last month, Microsoft also shared some info on PonyFinal, another Java-based and human-operated ransomware used to perform network-wide encryption after exploiting the victim's systems management server and targeting endpoints with Java Runtime Environment (JRE) already installed.

However, "[i]n certain cases, the attackers deploy Java Runtime Environment (JRE), which the Java-based PonyFinal ransomware needs to run," Microsoft said. 

PonyFinal ransomware also encrypts files at a specific date and time, and it is deployed at the end of human-operated ransomware campaigns known to stay dormant and patiently wait for the most opportune time to strike.

According to Redmond's research, besides Tycoon and PonyFinal, the list of human-operated ransomware also includes RobbinHood, Maze, Vatet loader, REvil (Sodinokibi), NetWalker, Paradise, RagnarLocker, MedusaLocker, and LockBit.
