Windows Defender Application Control is a security offering by Microsoft where only trusted applications and drivers are allowed to run in Windows. This whitelist approach offers significant security improvements as only trusted applications can run while unknown applications, such as malware, will never be allowed to.

When a system-wide application control solution is enabled in Windows, such as Device Guard and WDAC, PowerShell will automatically go into constrained language mode, which limits its access to certain Windows APIs.

This vulnerability allows a local attacker to bypass WDAC enforcement by circumventing PowerShell Core Constrained Language Mode.


"A security feature bypass vulnerability exists in Windows Defender Application Control (WDAC) which could allow an attacker to bypass WDAC enforcement. An attacker who successfully exploited this vulnerability could circumvent PowerShell Core Constrained Language Mode on the machine.

To exploit the vulnerability, an attacker would first have access to the local machine where PowerShell is running in Constrained Language mode. By doing that an attacker could leverage script debugging to abuse signed modules in an unintended way.

The update addresses the vulnerability by correcting how PowerShell functions in Constrained Language Mode."


It is strongly advised that administrators update to the latest versions of PowerShell Core to resolve this vulnerability.

How to tell if you are affected by this vulnerability

This vulnerability affects all PowerShell Core 6.0, PowerShell Core 6.1 versions prior to 6.1.5, and PowerShell Core 6.2 versions prior to 6.2.2.

To check what version of PowerShell you are running and to determine if you are vulnerable, you can execute the pwsh -v command from a Command Prompt.


pwsh command

If you are running an affected version, you can go to the PowerShell Core Releases page and download either of the latest versions, which are 6.2.2 or 6.1.5.

If you know you have PowerShell Core installed, but the pwsh.exe command does not work, then you are using PowerShell Core 6.0 and need to update to a newer version.
