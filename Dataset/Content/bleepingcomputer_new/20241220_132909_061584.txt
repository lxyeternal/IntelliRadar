
	   


A newly discovered cryptomining threat targeting web servers, network drives, and removable drives comes filled to the brim with exploits and precautions against analysis tools and environments.

The end goal is to turn compromised machines into Monero mining rigs. To get there the malware pulls out of it bag several interesting tricks aimed at successfully infecting the target and to avoid analysis.

Big bag of tricks

Security researchers found exploits for different vulnerabilities. One of them is NSA's EternalBlue, three are for multiple ThinkPHP versions; another three are for getting remote code execution via CVE-2014-6287 (affects Rejetto HFS), CVE-2017-12615 (affects Apache Tomcat), and CVE-2017-8464 (affects Windows Shell), research from Trend Micro reports.

To evade the scrutiny of malware researchers, once BlackSquid gains access to a server it checks for signs of an analysis environment, such as a virtual machine, sandbox, or a debugger.

Once it compromises a machine, the cryptominer delays its routine until it makes sure that the system it lands on does not have a name common to known hardware emulators or sandbox tool or a disk drive model that would indicate an analysis environment.

"The malware also checks the breakpoint registers for hardware breakpoints, specifically for the flags. Hard-coded in, it skips the routine if that flag is at 0, while it seems to proceed with infection if the flag is at 1. As of this writing, the code is set at 0, implying that this aspect of the malware routine is still in development," explains Trend Micro.



If it detects an unsafe habitat, BlackSquid stops the infection routine and no malicious or suspicious indicators are revealed. For instance, trying to determine its nature in Any Run analysis platform terminates with the false conclusion that a threat is not present.

Jumping from one system to another is possible with the help of EternalBlue and the DoublePulsar backdoor developed by the NSA. This combination is not unusual for cryptomining threats.

Despite a patch being available since March 2017 and the number of directly affected systems being in the thousands these days, internal networks continue to be unprotected.

Statistics from Elad Erez, Director of Innovation Accelerator at Check Point, show that corporate networks harbored 601,000 systems vulnerable to EternalBlue on March 20. The data was pulled through a tool he developed specifically for organizations to test their infrastructure for EternalBlue risk.



According to Trend Micro, BlackSquid infects web servers through exploits for web applications. Using the GetTickCount API, it pokes around for live IP addresses and targets them with the exploits it incorporates and brute-force action.

As complex and well-built the malware appears, its author made a mistake that renders unusable the code of one of the ThinkPHP exploits. The error is a simple typo that has the letter "l" instead of the number "1."



Two XMRig cryptocurrency mining components are deployed as the final payload on compromised systems. Both of them are for 64-bit machines and are available as a resource in the malware files and as a download.

The component in the resources is responsible for determining what type of video card is installed on the system. If Nvidia or AMD hardware is present, the second component is downloaded and the mining begins.


If successful, this malware may enable an attacker to escalate unauthorized access and privileges, steal proprietary information, render hardware and software useless, or launch attacks on an organization (or even from an organization into another).


For the complexity it shows, BlackSquid may still be in development stage, Trend Micro says. They could be testing the different types of attacks and determine targets without spending too much effort. The Monero miner is the final payload in the compromises seen by the researchers but the attackers can switch it to a different threat.
