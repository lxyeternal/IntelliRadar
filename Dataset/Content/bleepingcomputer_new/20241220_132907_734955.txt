
	   


Mozilla Firefox will soon allow you to export your saved login credentials to a CSV text file that you can then import into a password manager or store as a backup.

Like many other browsers, Mozilla Firefox has a password manager that allows you to save login names and passwords for websites that you have an account. When you visit these sites, Firefox will automatically popular the login forms with the saved credentials.

In the Firefox 79 Nightly build, Mozilla has added the ability to export your saved credentials to a CSV text file.

Export Logins option

After clicking on Export Logins, Firefox will explain that the passwords will be stored in plain text and readable to anyone who has access to the file.


Export confirmation

As extra security, if a user continues with the export process, Windows at least will prompt the user to first enter their Windows account password.


Prompt to enter Windows account password

If the correct password is entered, users will be prompted for a location to save the 'logins.csv' file, which will be used to export your login names and passwords.


Exported login credentials

For those looking to move to a full-feature password manager, the ability to export your passwords is a useful feature.

Unfortunately, this makes it easy for anyone who has access to your Windows password to dump a full list of your saved credentials and print them out.

Therefore, be sure to only give your Windows password to someone you also trust to know your passwords.
