
	   


Intel today released fixes for high-severity issues that allow privilege escalation, denial of service (DoS), and information disclosure on multiple models of its NUC Kits and the RAID Web Console utility for Windows.

The bug count weighs heavy for NUC Kits - small-form-factor barebone computer boxes, for which the maker released seven firmware updates, while RAID Web Console 3 (RWC3) utility received only one patch.

Flaw in RAID software most severe

The privilege escalation glitch in the web-based RAID software was discovered internally by Intel researchers and is the gravest of all the issues Intel addressed in today's advisories.

This is due to insufficient session validation in the service API of the software version 4.186.

RWC3 is designed for monitoring, analyzing, and configuring functions for RAID products from Intel, so it is typically present on server stations. Admins are advised to prioritize installation of the patch.

Its user interface helps keep an eye on available server hardware configuration, showing the current status of controller cards, virtual and physical drives. Moreover, it can be used for maintenance tasks, such as updating the controller firmware.

BIOS updates for 39 NUC Kits

All vulnerabilities affecting NUC Kits may allow an attacker to increase their privileges on the system, cause a DoS condition, or obtain information that should otherwise remain protected.

Their nature ranges from buffer overflow and insufficient input validation to pointer corruption, out of bound read/write, and insufficient session validation. To exploit any of them, an attacker needs local access and a privileged user position, reads the advisory.

The list of the affected products includes no less than 39 different entries, all indexed in the table at the end of the article, along with links to the latest firmware updates.

Other notable Intel products receiving fixes include the following:


	PROSet/Wireless WiFi software: medium severity DoS
	
	
	Accelerated Storage Manager in Intel Rapid Storage Technology Enterprise: medium severity reflected XSS in the web interface
	
	
	SGX driver for Linux: medium severity DoS
	
	
	Turbo Boost Max Technology 3.0 driver: medium severity privilege escalation
