
	   


Security researchers have demystified the attack chain of the elusive InvisiMole cyberespionage group, revealing a complicated multi-stage format that relies on vulnerable legitimate tools, target-specific encryption of payloads, and stealthy communication.

InvisiMole gets access to the target network through Gamaredon, a threat actor linked to Russia that runs reconnaissance operations and identifies valuable systems.

Both attack groups have been operational for at least seven years and despite their collaboration, they are considered distinct threat actors due to the clear difference in attack tactics and techniques.

InvisiMole malware was publicly documented for the first time in 2018, being classified as complex spyware of undetermined origin that can track victims’ geographical location, spy via webcam, take screenshots, record audio, and steal documents.

Recently uncovered versions also use the Media Transfer Protocol (MTP) to steal photos from mobile phones connected to the infected computer.



ESET malware researcher Zuzana Hromcová at the ESET Virtual World security conference presented an overview of the multi-stage attack chain reconstructed after investigating a campaign that started in September 2019 and continues to be active.

By collaborating with the victims, the researchers were able to map four execution chains, used according to the privilege level on the compromised machine and the Windows version installed. The longest one requires six steps before deploying the final payload.

To keep the operation undetected, the threat actor used vulnerable executables of legitimate tools, such as the Total Video Player, SpeedFan utility,  or the wdigest.dll in Windows.

InvisiMole also used a technique leaked from the CIA Vault 7 documents leak that uses Control Panel to execute malware malicious items.



These precautions were not enough, though, as the threat actor also encrypted some of the payloads in the chain using the Data Protection API (DPAPI) in Windows to encrypt and decrypt the payloads in the attack chain.

DPAPI is used to secure sensitive data, like passwords stored by the web browser, and is tied to the login credentials for the machine. This means that data can be decrypted only on the host where it was originally encrypted, thus making ESET’s investigation much harder.

New TCP and DNS downloaders

Hromcová notes in a blog post today that only select computers on the network would be infected with InvisiMole. The triage is likely done by Gamaredon, which also drops the more sophisticated malware from InvisiMole.

Gamaredon uses spear phishing to gain access to a target and a .NET downloader that leads to dropping a vulnerable executable used in InvisiMole’s multi-stage attack.



According to ESET’s research, InvisiMole continues to rely on the two backdoors analyzed in 2018 (RC2CL and RC2FM) but has new additions, a simpler TCP downloader and a stealthier DNS downloader.

Both are used to fetch components from the command and control (C2) server after a fresh infection but the latter “is used in the long run, allowing the attackers to push updates.”

DNS downloader hides communication with the C2 using a custom implementation of DNS tunneling, allowing information to be exchanged covertly in DNS queries and replies.



Light-footed on the network

As far as spreading through the network is concerned, Hromcová says that InvisiMole leverages the BlueKeep vulnerability (CVE-2019-0708) in the RDP protocol and the EternalBlue exploit for the CVE-2017-0144 vulnerability in Microsoft’s Server Message Block (SMBv1).

A third method is to weaponize documents and software installers present on the victim’s network. This way, users can share or access the infected items without questioning their provenance.


“This lateral movement technique is especially powerful if the trojanized file happens to be a software installer placed on a central server – a common way to deploy software in larger organizations. That way, InvisiMole is organically distributed to many computers that use this server” - Zuzana Hromcová


According to the researcher, the campaign investigated was not a success for the attacker. Hromcová says that at one organization compromised by InvisiMole over 8,000 documents were ready to be exfiltrated when and dozens of computers infected when ESET intervened.

The security company prepared a comprehensive report on the newly discovered InvisiMole toolset. It provides indicators of compromise and in-depth technical details about how the threat actor manages to moves about the network and slip undetected.
