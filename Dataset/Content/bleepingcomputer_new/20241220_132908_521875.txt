
	   


Microsoft today released quality improvements and security updates to the Windows 10 servicing stack, a component designed to enable customers to receive and install Windows updates.

Microsoft says that today's servicing stack updates (SSUs) are addressing an "elevation of privilege vulnerability that exists when the Windows Modules Installer improperly handles file operations" tracked as CVE-2020-1346.

"To exploit the vulnerability, an attacker would first need code execution on a victim system," Microsoft explains. "An attacker could then run a specially crafted application."

Windows 10 users are encouraged to update their servicing stack to the latest available version before installing the latest July 2020 cumulative updates, (LCU), Monthly Rollup updates, or security updates.

SSUs available on the Microsoft Update Catalog

Windows 10 users should update their systems' servicing stack to prevent potential issues during the installation process of future quality and feature updates.

Microsoft states in the servicing stack support document that:


Servicing stack updates improve the reliability of the update process to mitigate potential issues while installing the latest quality updates and feature updates. If you don't install the latest servicing stack update, there's a risk that your device can't be updated with the latest Microsoft security fixes.

		Installing servicing stack updates

Servicing stack updates contain "the 'component-based servicing stack' (CBS), which is a key underlying component for several elements of Windows deployment, such as DISM, SFC, changing Windows features or roles, and repairing components," as Microsoft states in the Windows IT Pro Center.

SSUs can wither be installed automatically via the Windows Update or by using standalone update packages that can be downloaded from Microsoft Update Catalog website — links to knowledgebase articles with links to the most recent SSUs are available in the table above.

Windows Server users can use the Windows Server Update Services (WSUS) to mass deploy SSUs to all computers on their enterprise network.

Servicing stack updates installation notes:


• Servicing stack updates contain the full servicing stack; as a result, typically administrators only need to install the latest servicing stack update for the operating system.
• Installing servicing stack update does not require restarting the device, so installation should not be disruptive.
• Servicing stack update releases are specific to the operating system version (build number), much like quality updates.
• Search to install the latest available Servicing stack update for Windows 10.


Windows 10 users can use this guided walk-through or this troubleshoot support article to address any issues encountered during Windows updates.

Microsoft today also released the July 2020 Patch Tuesday security updates, with updates for 123 vulnerabilities, 18 of them being rated by Microsoft as critical severity.

The July 2020 Microsoft Office security updates were also published today, bundling a total of 25 security updates and five cumulative updates across seven different products.
