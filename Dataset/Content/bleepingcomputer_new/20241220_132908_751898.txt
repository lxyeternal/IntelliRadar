Remote code execution vulnerabilities allow an attacker to create specially crafted web sites or files that could allow the attacker to execute commands and programs on vulnerable platforms. These types of vulnerabilities are the most serious as they could allow an attacker to virtually perform any action on the device, including the downloading of other programs.
