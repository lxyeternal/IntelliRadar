
	   


Hackers attacking banks and government institutions have used legitimate and reputable applications to infect computers and steal data, all while leaving minimal traces behind.

Discovered by Kaspersky Lab researchers, signs of this type of attacks have been found in over 140 hacks in 40 countries around the globe. The common pattern in all of these incidents was the lack of any clues in logs and other data storage devices.

According to Kaspersky researchers, a plausible attack scenario would start with hackers using an exploit to gain an initial foothold inside a private, high-value network.

Once attackers found themselves inside, they used the Mimikatz password-dumping application to extract local credentials, and gain access to accounts with higher privileges on the local machine or nearby workstations.

From this point on, the attackers used a combination of Metasploit modules, PowerShell scripts, and the Windows SC tool to run malicious code inside the computer's memory.

To exfiltrate the data, attackers used the NETSH utility, creating an undetectable tunnel to their desired server.

This type of attack restricted all the malicious behavior to the computer's RAM and a few Windows registry keys, leaving minimal traces of malicious actions in logs and backups.

As time passed by and logs and backups were rotated, any left-over traces were removed, while the attackers continued to run their malicious code from the computer's RAM.

Attacks are extremely difficult to detect

Kaspersky says that, in theory, the tactics are similar to past attacks from cyber-criminal gangs such as GCMAN and Carbanak, but they can't be sure since there's no evidence to tie these silent attacks to previous hacks.

"Techniques like those described in this report are becoming more common, especially against relevant targets in the banking industry," the Kaspersky team explained.

According to security experts, this type of attack is only detectable at the memory and network level only, which would require up-to-the-minute updates with the latest indicators of compromise, such as recently used registry keys and C&C server IPs.
