
	   


Microsoft released the December 2019 Office security updates, bundling a total of 16 security updates and five cumulative updates for five different products, three of them patching flaws allowing remote code execution.

Redmond today also released the December 2019 Patch Tuesday security updates, with security updates for 36 vulnerabilities, 7 of them classified as Critical and one zero-day privilege elevation vulnerability in Win32k actively exploited in the wild.

Patched Microsoft Office vulnerabilities

Out of the 16 Office security updates released by Microsoft today, three of them patch remote code execution bugs detailed in the CVE-2019-1462 advisory within PowerPoint 2010, 2013, and 2016.

"A remote code execution vulnerability exists in Microsoft PowerPoint software when the software fails to properly handle objects in memory. An attacker who successfully exploited the vulnerability could run arbitrary code in the context of the current user," the security advisory says. "If the current user is logged on with administrative user rights, an attacker could take control of the affected system."

"An attacker could then install programs; view, change, or delete data; or create new accounts with full user rights. Users whose accounts are configured to have fewer user rights on the system could be less impacted than users who operate with administrative user rights."

The rest of the security patches issued by Microsoft today also four denial of service and nine information disclosure flaws described in the CVE-2019-1461 and the CVE-2019-1400, CVE-2019-1463, CVE-2019-1464 advisories, respectively.

These issues impact several products including Office 2016, 2013, and 2010, Word 2016, 2013, and 2010, as well as Excel 2016, 2013, and 2010.
