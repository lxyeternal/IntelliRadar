checkra1n makes use of the Checkm8 jailbreak-enabling iOS bootrom exploit released on Twitter last month by security researcher axi0mX.

As Cisco Talos researchers found, a scam group has noticed the attention this new jailbreak tool has amassed lately and reacted by registering and hosting checkrain[.]com, a "fake website that claims to give iPhone users the ability to jailbreak their phones."

An iOS jailbreak bait

iPhone and iPad users are being baited using this website to install an application that should allow them to jailbreak their devices.

As Cisco Talos says, the users will only be asked to install a mobileconfig profile file on their iOS devices instead of the checkra1n jailbreak advertised to work on devices with A5 to A13 processors and running any iOS released between 12.4.2 and 13.1.2.

"The checkm8 exploit (and, by consequence, the checkra1n jailbreak) only impacts iOS devices running on the A5 to A11 chipsets. The fact that the website mentions the A13 device is the first indicator that this website is not legitimate," says Cisco Talos.

"Additionally, the website proposes the user can install the checkra1n jailbreak without a PC, when in reality, the checkm8 exploit requires the iOS device to be in DFU mode and is exploitable via the Apple USB cable."


Fake jailbreak website SSL certificate

The attackers have also gone all the way and are using a LetsEncrypt SSL certificate generated on October 10 for their fake website to further solidify the illusion that their site is the real deal.

"Once the app is downloaded and installed, a checkrain icon appears on the user's iOS springboard. The icon is in fact a kind of bookmark to connect on a URL," found the researchers.

"This icon may look like an app from the user's perspective, but it actually doesn't work like one at all on the system level."

The springboard is supposed to help the users launch the jailbreak app to start the iOS jailbreak process. As expected, this is only a ruse, given that the victims will only see a full-screen fake jailbreaking message loaded as an Apple Web Clip.


Fake jailbreak preparation message

The fake jailbreak webpage will also detect if the user has loaded it without using an iOS device, in which case it will display an alert requesting to be loaded on an iOS device.

Games and click-fraud

Cisco Talos recorded a video demo of the entire fake jailbreak process, which goes through "multiple redirects occurring on the user's iOS device."

"This ultimately occurs in click-fraud, resulting in multiple verification chains and then finishing on an iOS game install, with in-app purchases available," found the researchers.

While being bounced around through this redirection chain, the users will go through various ad-tracking, verification, and geolocation loops, with the landing page instructing them to install a slot machine game called Pop! Slots from the App Store.



The attackers also provide what they call "unlock instructions" asking their targets to "Install, Open & Complete Level 8 within 7 Days of Downloading to unlock this content. Your content will automatically unlock once completed. Tap to Install."

Among the countries targeted by this scam, most users that have potentially fallen for this scam are from the U.S. according to the Cisco Talos report.

As the researchers added, users from the U.K., France, Nigeria, Iraq, Vietnam, Venezuela, Egypt, Georgia, Australia, Canada, Turkey, Netherlands, and Italy were also affected.


Targeted countries

Some of the users who were targeted by this online scam caught on and went on to Reddit to warn others to be vigilant and not fall for the crooks' tricks.

Unfortunately, as per the Reddit thread, some were already tricked by this scam, while others have brought up a similar fake jailbreak website hosted at unc0ver.[]vip which clones the site of the legitimate unc0ver jailbreak tool reachable at unc0ver[.]dev.
