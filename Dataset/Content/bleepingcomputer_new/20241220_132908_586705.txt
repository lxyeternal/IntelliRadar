While the Tor Browser should alert you when a new update available, you can manually check by going to the Tor Browser menu -> Help -> About Tor Browser, and letting the program check for new updates.

The fix for this vulnerability has been ported to the bundled Firefox browser in Tor Browser 8.5.2.

This JavaScript type confusion vulnerability was discovered being actively used in targeted attacks and thus needed immediate attention. This bug did not affect users running under the Safer or Safest security levels.



In addition, the bundled NoScript addon has been upgraded to version 10.6.3.

Unfortunately, the release announcement has stated that the Android version of Tor Browser 8.5.2 will not be available until the weekend as part of the Tor team who handles the Android signing token is away at an event.

Note: As part of our team is currently traveling to an event, we are unable to access our Android signing token, therefore the Android release is not yet available. We expect to be able to publish the Android release this weekend. In the meantime, Android users should use the safer or safest security levels. The security level on Android can be changed by going in the menu on the right of the URL bar and selecting Security Settings.

Tor 8.5.2 can be downloaded from the Tor Browser download page and from the distribution directory.

The full changelog for Tor Browser 8.5.2 is:

Tor Browser 8.5.2 -- June 19 2019
 * All platforms
   * Pick up fix for Mozilla's bug 1544386
   * Update NoScript to 10.6.3
     * Bug 29904: NoScript blocks MP4 on higher security levels
     * Bug 30624+29043+29647: Prevent XSS protection from freezing the browser
