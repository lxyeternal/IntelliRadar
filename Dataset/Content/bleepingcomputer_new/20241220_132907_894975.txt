Dubbed 'Sharpshooter,' the hacking campaign was observed impacting at least 87 entities across the globe in a timespan of just two months.

Disguised as a job recruitment campaign, the attack flow starts with an email that links to a malicious Microsoft Word document in a Dropbox account. The file contains containing job titles and description at unknown companies.

The macro embedded in the document downloads Rising Sun, a backdoor that includes source code present in a similar tool, Duuzer, used by the North Korean Lazarus group in 2015.



The malicious script in the Word file also downloads another document, named 'Strategic Planning Manager.doc,' believed to act as a decoy to hide the malicious content, which opens automatically after retrieval.

Although many technical clues point to Lazarus, researchers at McAfee say that they "seem too obvious to immediately draw the conclusion that they are responsible for the attacks."

Rising Sun backdoor comes with 14 capabilities

Rising Sun's purpose is to run reconnaissance activity on the compromised machine. It can deliver to the command and control (C2) server information about the system network adapters, system details, username, IP address, and operating system product name.

Additional capabilities available in the implant enable the attacker to learn all the important details about the infected machine.

The full set of features has 14 commands that allow executing commands using Windows Command Prompt, getting details about drives, files, and running processes, or writing and deleting files

It can also be used to change file attributes, clear process memory, read files, terminate processes, and launch processes from Windows library.

Striking similarities to Lazarus

While analyzing the Sharpshooter operation, the Advanced Threat Research team and Malware Operations Group at McAfee noticed clear similarities with the Lazarus group.

One of the clues was the Microsoft Word document created in a Korean version of the software. Another was a technique associated with the activity of the North Korean hackers.

Furthermore, the experts highlight that "the operation is very similar to a Lazarus operation from 2017 that targeted the US defense and energy
sectors," both of them with matching techniques, tactics, and procedures (TTP).

All this adds to the fact that source code from a backdoor used by the hackers three years ago was found in Rising Sun.


Code signatures for executing commands - Duuzer (left), Rising Sun (right)

Nevertheless, the researchers avoid attribution with high confidence fearing that the evidence may be purposefully planted by the attacker to hide their traces.
