
	   


Today Apple released updates for their core products that includes iCloud, Safari, macOS Mojave, High Sierra, & Sierra, tvOS 12.1.2, and of course iOS 12.1.3.

Included in these security updates are fixes for numerous code execution, privilege escalations, and information disclosure vulnerabilities. Due to this, if you are the user of any of the above products, you should update them as soon as possible.

iOS 12.1.3 fixes FaceTime RCE

iOS 12.1.3 fixes numerous privilege elevation, remote code execution, and sandbox escape bugs.  There are a few, though, that stand out.

macOS Mojave 10.14.3 fixes Intel graphics RCE

Even though macOS shares many of the same vulnerabilities as iOS, the macOS operating system had a few to itself.

CVE-2018-4467 was discovered by researchers at VMware that discovered a hypervisor bug that could allow attackers to elevate their privileges. Then we had CVE-2018-4452, which could allow remote code execution through the Intel graphics driver.

Finally, we had CVE-2019-6220, which is a vulnerability in the image and animation processing API called QuartzCore that allows attackers to read restricted memory.

Even though iOS and macOS are the most popular of today's updates, we also had updates for tvOS, watchOS, Safari, and iCloud. So if you use any of those devices, be sure to check out the complete list of Apple security updates released today.
