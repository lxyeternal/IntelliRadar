
	   
While the week was dominated by small little ransomware creations, we did have some interesting news. First, we have had a resurgence of Locky variants, which has been mostly silent this past year. We also continue to see a constant stream of GlobeImposter variants variants. Last, but not least, the SyncCrypt ransomware utilized an interesting and successful distribution method of hiding inside JPEG files.

August 14th 2017

Polish Jigsaw Ransomware Released

Michael Gillespie discovered a Polish Jigsaw Ransomware variant that appends the .pabluklocker extension to encrypted files.

Shinigami Ransomware Released

Michael Gillespie discovered a new ransomware called Shinigami. Uses a well designed ransom note if your into the Joker. Encrypts with DES and renames files .shinigami.



Generic Ransomware Discovered

Michael Gillespie discovered a new ransomware that is loosely based off of HiddenTear. Uses 5 contact emails and appends the .locked extension to encrypted files.

MMM Ransomware Discovered

Michael Gillespie is on a roll with his discovery of the MMM Ransomware. This ransomware appends the .0x009d8a extension to encrypted files.

Xorist Ransomware Variant Impersonating Cerb

Michael Gillespie found a extension submitted to ID-Ransomware that uses the .Cerber_RansomWare@qq.com extension. This variant can be decrypted.

New GlobeImposter Appends .Granny?

Michael Gillespie keeps bustin' em out with the discovery of a GlobeImposter variant that appends the .GRANNY" & .granny extensions to encrypted files.



 

More GlobeImposter Variants

Other GlobeImposter variants discovered this weekend on ID-Ransomware are: .D2550A49BF52DFC23F2C013C5, .zuzya, .LEGO, & .UNLIS.

Jigsaw Themed Screen Locker Discovered

Jigsaw themed screen/locker encrypter was discovered by malware analyst Leo .



August 15th 2017

2016 Open-Source Repo Continues to Fuel the PHP Server Ransomware Scene

A PHP ransomware project open-sourced on GitHub is still spawning active threats, more than a year after it was released in early 2016.

Infinite Tear Ransomware Discovered

Leo tweeted about  new ransomware called Infinite Tear that appends the .JezRoz extension to encrypted files  and drops a ransom note named Important_Read_Me.txt.



Null Ransomware Discovered

A test verison of the Null Ransomware was discovered by GData analyst Karsten Hahn that appends the .null extension to encrypted files.



New RotoCrypt Variant Discovered

ESET malware analyst Jiri Kropac discovered a new variant of the RotoCrypt ransomware that has a contact email of diligatmail7@tutanota.com and appends the .OTR extension.

Crypt12 Ransomware Discovered

Emsisoft malware analyst xXToffeeXx discovered a new ransomware called New Crypt12 that appends the .extension=[id]=[email].crypt12 extension to encrypted files.



BRansomware Discovered

Michael Gillespie discovered a new ransomware called BRansomware that appends the .GG extension to encrypted files.

August 16th 2017

SyncCrypt Ransomware Hides Inside JPG Files, Appends .KK Extension

A new ransomware called SyncCrypt was discovered this week by Emsisoft security researcher xXToffeeXx that is being distributed by spam attachments containing WSF files. These WSF attachments download images that have a zip file containing the ransomware embedded in it.



Locky Ransomware switches to the Lukitus extension for Encrypted Files

Today a new Locky Ransomware variant was discovered by Rommel Joven that switches to the .lukitus extension for encrypted files. It is important to note that if you are infected with this ransomware, you are not infected with the Lukitus Ransomware, as some sites may call it. You are instead infected by Locky, which is using the .lukitus extension.  There is a difference.



Clico Crypter Discovered

Karsten Hahn discovered the Java based Clico Crypter Ransomware that appends the .enc extension to encrypted files. Claims to be educational.



New SamSam/Samas Variant Discovered

Michael Gillespie discovered a new SamSam/Samas variant that appends the .prosperous666 extension and drops a note named PLEASE-README-AFFECTED-FILES.html.

Decryptor for LambdaLocker Released

The EC3 announced that a new decrypter was released by Avast Software for the LambdaLocker ransomware.

New Matroska Variant Released

Malwarebytes security researcher S!Ri discovered a new variant of the Matroska Ransomware that appends the .encrypted[Payfordecrypt@protonmail.com] extension to encrypted files.



August 17th 2017

Ransomware Was the Most Prevalent Malware Payload Delivered via Email in Q2 2017

Malware activity has ramped up in the second quarter of 2017, according to reports from cyber-security firms Cyren, Check Point, Kaspersky Lab, Proofpoint, and Symantec.

WoodMan Screen Locker Discovered

Karsten Hahn discovered that intricate and highly developer graphical user interface of the WoodMan screenlocker. You can use the mm2wood.mid code to close it down.



Moon Crypter Ransomware Discovered

Karsten Hahn found another high quality ransomware called Moon Crypter/Moon Decryptor, which was developed by someone named Timmy. Hi Timmy! This ransomware appends the .fmoon extension to encrypted files.



 

In-dev Draco PC Ransomware Discovered

Lawrence Abrams discovered the in-dev Draco PC Ransomware. Claims it will delete your files if you do not pay the ransom. Does not encrypt.



New GlobeImposter variant discovered

Lawrence Abrams discovered a new GlobeImposter variant that appends the .{saruman7@india.com}.BRT92 extension to encrypted files and drops a ransom name named #DECRYPT_FILES#.html. The BRT92 extension has been used before, but this time with a different email. 



August 18th 2017

Ransomware Hits LG Self-Service Kiosks Across South Korea, Possibly WannaCry

Representatives for LG South Korea said on Wednesday that a mysterious ransomware strain has infected self-servicing kiosks at various service centers across the country.

New ERROR CryptoMix Ransomware Variant Released

Today, Lawrence Abrams of BleepingComputer discovered a new variant of the CryptoMix ransomware that is appending the .ERROR extension to encrypted file names. 



Polish Screen Locker Discovered

MalwareHunterTeam discovered a Polish screenlocker. The unlock code is 023135223.
