
	   


Mozilla is finally making it so extensions are not enabled by default when in Firefox Private browsing mode. This move increases security by preventing extensions from tracking user behavior while in a mode that users expect the greatest degree of privacy.

Chrome, Opera, and Microsoft Edge have already disabled extensions in their private modes due to their potential risk to privacy. This is because it is common for extensions to utilize tracking scripts like Google Analytics or redirects through servers that are used to track a user's browsing and search behavior.

Based on a recent update to a bug report and a new doorhanger that is being displayed in Firefox Nightly builds, Mozilla is planning on disabling extensions by default when using Private windows in Firefox.

Doorhanger explaining that extensions are disabled

This doorhanger explains that extensions are disabled in Private windows so that they cannot track your online activities.

"Extensions are not allowed to run by default in Private Windows. They won't work while private browsing, and they won't have access to your online activities. You can allow each extension to run in Private Windows by managing your settings."

When this new setting goes into effect it does not mean that it is not possible to run extensions in Private windows, but that you have to enable the specific extensions that you wish to run. This is useful for those who wish to use an ad blocker or a userscript extension, while benefiting from the enhanced privacy of the Private browsing mode.

To allow an extension to run in Private windows, you can go into the installed Extensions list and click on an extension to open its properties. Under the properties will be a setting that you can enable titled "Run in Private Windows" as shown below.


Run in Private mode setting

When an extension is enabled in Private windows, Firefox will indicate this in the Manage Your Extension screen by displaying "Allowed in Private Windows" under the extension's description.


Enabled in Private mode indicator

In the current Nightly builds for Firefox 67, extensions are still allowed by default so you will not be able to see the above screens until you disable them. To test it out now, you go into about:config and can set the extensions.allowPrivateBrowsingByDefault setting to false as shown below.


extensions.allowPrivateBrowsingByDefault setting

Once you disable extension in Private mode, you will be able to see the doorhangers and new extension settings as described in this article.
