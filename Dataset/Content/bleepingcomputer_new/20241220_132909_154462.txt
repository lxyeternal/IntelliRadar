
	   


Citrix today fixed 5 vulnerabilities impacting multiple versions of Citrix Endpoint Management (CEM) on-premise instances, also known as XenMobile Server.

On-premise Citrix XenMobile provides a unified interface to manage employees' desktops, notebooks, and mobile devices (tablets and smartphones) through a single platform.

Customers urged to update vulnerable servers

The company strongly recommends customers to immediately update vulnerable XenMobile Server deployments since attackers will most likely immediately start scanning for vulnerable servers and attempt to exploit them.

"Remediations have already been applied to cloud versions, but hybrid rights users need to apply the upgrades to any on-premises instance."

Citrix has already pre-notified CERTs and customers with active maintenance support on July 23 about these security vulnerabilities.

Over 70 percent of alerted customers have already upgraded their vulnerable XenMobile Server deployments as of August 9th by applying the latest rolling patches according to Citrix.

XenMobile Server versions exposed to attacks

Two of these vulnerabilities are rated as critical severity and, collectively, they could allow unauthenticated attackers to takeover XenMobile Servers after gaining admin control following successful exploitation.

These two flaws are tracked as CVE-2020-8208 and CVE-2020-8209, and they affect the following XenMobile Server versions:

• XenMobile Server 10.12 before RP2
• XenMobile Server 10.11 before RP4
• XenMobile Server 10.10 before RP6
• XenMobile Server before 10.9 RP5

The three other security issues found to affect XenMobile Servers are rated as medium and low severity, and could make it possible for CEM admins to access unauthorized information if abused.

These vulnerabilities are tracked as CVE-2020-8210, CVE-2020-8211, and CVE-2020-8212, and the impact the following versions:

• XenMobile Server 10.12 before RP3
• XenMobile Server 10.11 before RP6
• XenMobile Server 10.10 before RP6
• XenMobile Server before 10.9 RP5

Patches already available

"The latest rolling patches that need to be applied for versions 10.9, 10.10, 10.11 and 10.12 are available immediately," Citrix explains.

"Any versions prior to 10.9.x must be upgraded to a supported version with the latest Rolling Patch. We recommend that you upgrade to 10.12 RP3, the latest supported version."

The latest XenMobile Server rolling patches can be downloaded from:

• XenMobile Server 10.12 RP3
• XenMobile Server 10.11 RP6
• XenMobile Server 10.10 RP6
• XenMobile Server 10.9 RP5
