
	   


F5 Networks (F5) patched a critical remote code execution (RCE) vulnerability found in undisclosed pages of Traffic Management User Interface (TMUI) of the BIG-IP application delivery controller (ADC).

F5 customers using BIG-IP software and hardware solutions include enterprise governments, Fortune 500 firms, banks, service providers, and consumer brands (including Microsoft, Oracle, and Facebook), with the company's website saying that "48 of the Fortune 50 rely on F5."

F5's Big-IP ADC is used by Fortune 500 firms, governments, and banks all around the world, and, last month, more than 8,000 such devices were found to be vulnerable to attacks designed to exploit this vulnerability.

Maximum severity RCE vulnerability

The security issue was discovered by Positive Technologies security researcher Mikhail Klyuchnikov in undisclosed pages of Big-IP ADC's TMUI (aka Configuration utility) component and it affects most supported BIG-IP and BIG-IQ products.

The vulnerability is tracked as CVE-2020-5902 and F5 assigned it 10/10 CVSSv3 rating, the maximum severity rating possible.

"By exploiting this vulnerability, a remote attacker with access to the BIG-IP configuration utility could, without authorization, perform remote code execution (RCE)," Klyuchnikov explained.

		CVE-2020-5902 enables unauthenticated attackers or authenticated users to run arbitrary system commands and Java code, create or delete files, disable services, and/or execute arbitrary Java code through the BIG-IP management port and/or Self IPs.

To exploit this security issue, attackers have to send maliciously crafted HTTP requests to servers hosting TMUI for BIG-IP configuration.

Successful exploitation of the vulnerability could lead to full system compromise, including the interception of controller application traffic and lateral movement to further targets on the internal network.

"The BIG-IP system in Appliance mode is also vulnerable," F5 says. "This issue is not exposed on the data plane; only the control plane is affected."



Patching and mitigation measures

The vulnerability can be fully mitigated in vulnerable devices by upgrading to one of the fixed versions listed in the table above.

BIG-IP versions vulnerable to attacks (11.6.x, 12.1.x, 13.1.x, 14.1.x, 15.0.x, 15.1.x) should be upgraded to a corresponding patched versions (11.6.5.2, 12.1.5.2, 13.1.3.4, 14.1.2.6, 15.1.0.4).

Cloud marketplaces (e.g., AWS, Azure, GCP, and Alibaba) users are advised to switch to BIG-IP Virtual Edition (VE) versions 11.6.5.2, 12.1.5.2, 13.1.3.4, 14.1.2.6, 15.0.1.4, or 15.1.0.4, if available.

For customers who can't immediately upgrade to a patched software version, F5 provides temporary mitigations involving settings editing affecting all network interfaces, self IPs, or the management interface.

A detailed description of all the steps needed to implement these mitigations is available at the end of F5's CVE-2020-5902 security advisory.

F5 also patched a Cross-Site Scripting (XSS) vulnerability (CVE-2020-5903) found by Klyuchnikov in the BIG-IP configuration interface which can be used to fully compromise the BIG-IP system through remote JavaScript code execution if the currently logged-in user is an administrator.
