
	   


A vulnerability in the SAP POS Xpress Server allows attackers to alter configuration files for SAP Point-of-Sale systems, alter prices, and collect payment card data and send it to one of their servers.

SAP POS solutions are based on a client-server architecture that retailers can install in their stores. The system is made up of different POS clients — where customers pay — and a POS server running somewhere in a store back office.

On every payment, clients connect to the server and get the price for a scanned product, and then relay the payment card data to the processing bank. ERPScan says SAP's POS solution is used by around 80% of the retailers in the Forbes Global 2000.

SAP POS server does not authenticate internal commands

The vulnerability was discovered by security researchers from ERPScan, reported to SAP in April 2017, and fixed in SAP Security Note 2476601 and SAP Security Note 2520064.

Attackers can modify product prices, how payment operations are handled, or even install sniffers that collect payment card data.

The only condition is that attackers have access to the same network where the SAP POS Xpress Server is installed. If this server is connected to the Internet, an attack can be carried out from remote locations.

If the POS system's network is air-gapped, researchers say an attacker needs to be in the store and connect a special device that automatically runs all the malicious commands. The device is a run-of-the-mill Rasberry Pi board that costs around $25.

According to the ERPScan team, finding open ports is easy, and the attack takes only a few seconds to carry out, as the malicious commands execute, upload a new SAP POS Xpress Server configuration file with modified prices, and restart the POS server.

Vulnerability can cause serious financial losses

The video at the top of this article shows ERPScan researchers using the vulnerability they discovered to alter the price of an expensive Macbook Pro to $1.

While this demo is flashy and does its purpose in showing the vulnerability's severity, researchers say that in a real-world scenario hackers would not risk having their scheme exposed. The real danger relies on applying 20% to 50% discounts on expensive products, which store clerks won't consider suspicious, but would be enough for crooks to resell the products later on and gain a profit on the black market.

Experts also warn that this flaw could be used to brick SAP POS systems and cause serious financial losses to retailers who fail to install the SAP security patches.

"We strongly advise our customers to secure their SAP landscape by applying the available security patches from the SAP Support Portal immediately," a SAP spokesperson told Bleeping Computer via email. "All vulnerabilities in question in SAP Point of Sale (POS) Retail Xpress Server have been fixed, and security patches are available for download on the SAP Support Portal."

"SAP Product Security Response Team collaborates frequently with research companies like ERPScan to ensure a responsible disclosure of vulnerabilities," the company added.
