
	   


Adobe today released security updates to fix two code execution vulnerabilities affecting Magento Commerce and Magento Open Source, rated as important and critical severity.

Affected software includes Magento Commerce versions 2.3.5-p1 and earlier and Magento Open Source versions 2.3.5-p1 and earlier.

Merchants running vulnerable Magento versions are advised to update their installation to the latest version (2.4.0) or to upgrade to Magento Commerce 2.3.5-p2 or Magento Open Source 2.3.5-p2 as soon as possible.

One of the issues fixed today, caused by a path traversal bug and tracked as CVE-2020-9689, is rated as a critical severity issue and it could allow attackers with admin privileges to execute arbitrary code.

Adobe also fixed an important severity pre-auth DOM-based Cross-Site Scripting (XSS) bug (CVE-2020-9691) which could enable unauthenticated attackers to run arbitrary code on unpatched systems.

A third vulnerability (CVE-2020-9690) is caused by an observable timing discrepancy bug and it makes it possible for attackers with admin privileges to bypass signature verification.

		The priority rating for these security updates is 2, which means that there are currently no known exploits and attacks are not imminent, although this product comes with an elevated risk of potential attacks.

Magento also fixed two other sets of critical code execution vulnerabilities in April and in January, all of them allowing potential attackers to run arbitrary code if successfully exploited.

Software updates as mitigation against Magecart attacks

Magento stores not updated to the latest version are often compromised using similar known security vulnerabilities to plant malicious JavaScript card skimmers designed to help threat actors collect and exfiltrate payment card data and sensitive customer information.

Known as Magecart, these attacks have been targeting both SMBs (small and medium-sized businesses) and government agencies that process online payments, with multiple cybercriminals groups engaged in such campaigns that have already hit hundreds of thousands of e-commerce stores.

The FBI warned govt agencies and SMBs to defend against Magecart attacks in October 2019, and urged online shop owners to keep their stores' software updated since this is one the main mitigation measures against web skimming attacks.

Earlier this month, Adobe also added two-factor authentication (2FA) throughout the Magento platform in response to the widespread number of Magecart attacks where threat actors inject skimmer scripts within the paces of hacked e-commerce sites to steal customers' credit cards.
