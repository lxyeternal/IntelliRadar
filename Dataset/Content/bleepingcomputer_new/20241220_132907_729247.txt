
	   


A collection of new Mirai malware samples compiled to run on new processors and architectures have been discovered by Palo Alto Networks' Unit 42 in the wild during late February 2019.

Unit 42's report says that "the newly discovered samples are compiled for Altera Nios II, OpenRISC, Tensilica Xtensa, and Xilinx MicroBlaze processors" which allows the attackers using this new variant of Mirai to expand their attack surface and target new devices.

While this can also be done by adding more exploits to be used in the attacks, adding more supported architectures is another simple way to increase the number of devices that can be added to the botnet they control.

These Mirai variants also "make use of a modified version of the standard byte-wise XOR (as implemented in the toggle_obf function) used in the original Mirai source code" which uses 11 8-byte keys, the equivalent of a byte-wise XOR with 0x5A.


Open directory hosting the new Mirai variants

Also, the "developers" added a new DDoS attack option called attack_method_ovh with the same parameters used for TCP SYN DDoS attacks by the original Mirai source code.

The new samples found by Unit 42 in an open directory hosted on an unprotected server came with a number of exploits also found in previous Mirai samples, ranging from a ThinkPHP Remote Code Execution exploit and a D-Link DSL2750B OS Command Injection to exploits targeting Netgear, Huawei, and Realtek equipment using remote code execution exploits.

The fact that these exploits are also used in these recompiled versions of Mirai show that the same threat actor is likely behind multiple attacks using various variants of this botnet malware according to the researchers.

In related news, just last month, Palo Alto Networks' Unit 42 also found a Mirai variant that features eleven new exploits with the LG Supersign TVs and the enterprise WePresent WiPG-1000 Wireless Presentation systems as the most notable new devices being targeted.

Ever evolving malware threat

Previously, during September, Unit 42 also spotted a strain of the Mirai botnet switching targets to attack Apache Struts servers with exploits also utilized during last year's Equifax breach, while a new Gafgyt version was seen assailing SonicWall firewalls, as part of a broader move against enterprise devices.

"These new features afford the botnet a large attack surface. In particular, targeting enterprise links also grants it access to larger bandwidth, ultimately resulting in greater firepower for the botnet for DDoS attacks," said the Unit 42 researchers.

Mirai is a self-propagating botnet malware designed to attack Internet of Things (IoT) devices such as routers, digital video recorders, and IP cameras, converting them into "bots" after successfully compromising them, using them as sources for large-scale Distributed Denial of Service (DDoS) attacks.

During 2016, various malicious actors advertised huge Mirai botnets of hundreds of thousands of bots capable of launching DDoS attacks over 650 Gbps, with hundreds of thousands of devices [1, 2] impacted during each attack.
