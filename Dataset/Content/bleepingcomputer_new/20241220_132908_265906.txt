New Dharma variant using amagnus@india.com Email

A new variant of the Dharma Ransomware was discovered by R0bert R0senb0rg that uses the amagnus@india.com email for payment instructions.



New in-dev CryptoBlock Ransomware Discovered

R0bert R0senb0rg discovered a new in-development ransomware called CryptoBlock.



December 19th 2016

It's Now Commonplace for Android Banking Trojans to Include Ransomware Features

The current generation of Android banking trojans are all equipped with ransomware-like features in order to lock the user's device, and in some cases encrypt his data.

RansomFree Is the Latest App That Tries to Stop Ransomware Infections on Windows

The team at Cybereason released today a new tool that tries to help users stay safe from ransomware infections. Named RansomFree, this application can help users of Windows 7, 8 and 10, and Windows Server 2010 R2 and 2008 R2 PCs.

New variant of the Apocalypse Ransomware Discovered

xXToffeeXx discovered a new variant of the Apocalypse ransomware that uses *md5*.txt as the ransom note and appends .ID-[A-F0-9]{8}+countrycode[cryptcorp@inbox.ru].[a-z0-9]{13} to encrypted files.

M4N1F3STO devs included encryption in the Jhon Woddy Screen Locker

I discovered that the M4N1F3STO devs started adding encryption to their screen lockers. A new screen locker was released that pretends to be from Jhon Woddy of Microsoft that also includes encryption. The decryption part of the code is broken. A decryptor has been created for this ransomware by Michael Gillespie.



MSN CryptoLocker Discovered

A new ransomware was discovered by Gdata security researcher Karsten Hahn that uses the alex.vas@dr.com email address as a contact.



December 20th 2016

Kaspersky updates RannohDecryptor to decrypt CryptXXX's Crypt, Cryp1, and Crypz Extensions

If you are a CryptXXX Ransomware victim who didn't pay the ransom and instead decided to store their encrypted files and ransom notes for future fixes then you are in luck. Today, Kaspersky announced that they have updated their RannohDecryptor utility to decrypt CryptXXX encrypted files that have the .crypt, .cryp1, and .crypz extension.



New Samas variant discovered

A new variant of the Samas/Samsam ransomware was discovered by Michael Gillespie that appends the .theworldisyours extension and uses a ransom note called CHECK-IT-HELP-FILES.html.

New Ransomware written in Go Discovered

xXToffeeXx discovered a new ransomware written in Go that appends the .braincrypt extension to encrypted files and uses the !!! HOW TO DECRYPT FILES !!!.txt ransom note.



New ransomware called EnkripsiPC

I discovered a new Indonesian ransomware called EnkripsiPC or IDRANSOMv3. The encryption password is based on the computer name. A decryptor has been created for this ransomware by Michael Gillespie.



December 21st 2016

Introducing the Manifestus Ransomware

Karsten Hahn discovered the Manifestus Ransomware.



The ProposalCrypt Ransomware was Discovered

MalwareHunterTeam discovered a ransomware called ProposalCrypt. This ransomware appends the .crypted extension to encrypted files. A decryptor has been created for this ransomware by Michael Gillespie.



Padlock Screen Locker can easily be Unlocked

I discovered the Padlock Screenlocker, which can be unlocked using the code ajVr/G\RJz0R. 



Free-Freedom Ransomware released by 13 Year Old

I discovered a new ransomware called Free-Freedom. The ransomware is supposedly created by a 13 year old boy, who wants to make sure we know about that! The unlock code is adam. At this time it does not encrypt, but rather messes up file permissions.



December 22nd 2016

How to Protect and Harden a Computer against Ransomware

2016 is almost over and it definitely taught us one thing; Ransomware is here to stay and it's only going to get worse. This guide contains tips and steps that every computer user needs to do in order to protect their data from ransomware.

Cerber Ransomware Doesn't Delete Shadow Volume Copies Anymore, Prioritizes Office Docs

Recent versions of the Cerber ransomware are behaving somewhat different from older variants, with the ransomware not deleting shadow volume copies, prioritizing specific folders and ignoring others.



Info given on how the Winnix Cryptor Team Ransomware is Installed

xXToffeeXx tweeted some info on how the Winnix Cryptor is installed. According to xXToffeeXx, the criminals remote into servers, run a bat file which encrypts all files on each drive using GPG (private/public key).

Cerber is using new IP Ranges for the UDP Stats

MalwareHunterTeam discovered that Cerber is now using the 115.22.15.0/27, 114.23.16.0/27, and 91.239.24.0/23 ranges for UDP stats.

Guster Ransomware arrives with an annoying Ransom Screen

I discovered the Guster Ransomware, which uses a very annoying and noisy animated ransom screen. This ransomware appends the .locked extension to encrypted files.



Adam rebrands Free-Freedom Ransomware into Roga

Our friend Adam of Free-Freedom fame has rebranded his ransomware into Roga. This ransomware will append the .madebyadam extension to encrypted files and has a decrypt password of adamdude9. The decryption is broken at this time.



December 23rd 2016

Koolova Ransomware Decrypts for Free if you Read Two Articles about Ransomware

There have been a lot of strange twists and turns when it comes to ransomware this month. First, we had Popcorn Time that gave you the option of screwing over people by infecting them to possibly get a free decryption key.  Now, we have a new in-development variant of the Koolova Ransomware that will decrypt your files for free if you educate yourself about ransomware by reading two articles.



New ransomware calling itself CryptoLocker

Fabian Wosar discovered a new ransomware that is pretending to be CryptoLocker. It appends the .cryptolocker extension to encrypted files.



Cerber gang getting into the Christmas Spirit

MalwareHunterTeam tweeted that the Cerber gang decided to get into the Christmas spirit by using domains with christmaas in them. 2 of the 3 domains have already been suspended.



VenusLocker still Alive and Kicking

MalwareHunterTeam found a new sample of the Venus Locker



In-Dev Alphabet Ransomware/Screen Locker Discovered

xXToffeeXx discovered a new in-developer ransomware/screen locker called Alphabet. It does not decrypt any files and currently provides the key.
