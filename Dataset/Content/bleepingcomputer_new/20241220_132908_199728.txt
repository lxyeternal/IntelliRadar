
	   



An update for Sophos UTM has been released that resolves three vulnerabilities in the network security platform. Two of these vulnerabilities are related to bundled open source software and a third is for a component related to inbound mail processing.

According to an advisory issued by Germany's DFN-CERT, version 9.602 of the Sophos Unified Threat Management platform fixes vulnerabilities in OpenSSH, Apache HTTP, and a component that processes incoming mail.

For the bundled open source components, the OpenSSH CVE-2018-15473 vulnerability is classified as Medium and allows user enumeration has been fixed. For Apache HTTP, this update fixes CVE-2018-17199, which is classified as High and under certain conditions prevents the expiration of cookies, thus allowing a security bypass.
