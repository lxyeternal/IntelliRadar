Crooks use browser pop-ups to display warnings saying that the computer was infected or "blocked" because it was hacked, and designed to look like they're coming from companies like Microsoft, Google, or various security outfits.

This is done by the crooks behind the scam in an attempt to induce a feeling of urgency that would trick the targets into calling a "support" hotline using the phone number included in the fake alert pop-up.

TSS campaign

The new technical support scam (TSS) campaign discovered by Trend Micro's Samuel P Wang fraud researcher tries to pass up the scammers hotline as an official Microsoft support one.


Its URLs show a webpage disguised to look like a typical Microsoft tech support page. However, it hides several different functions. Entering any of the involved URLs will open two pop-up windows: One that asks for user authentication and another that simply urges users to ask for technical support. By then the user has unknowingly entered a loop.


Once the authentication pop-up is displayed within the web browser, the users will have a very hard time getting rid of it because the OK and Close buttons don't do anything, while clicking on the Cancel will only lead back to the same URL.

As mentioned in the beginning, while most TSS campaigns use JavaScript-based methods that "put the user in a loop where clicking on any pop-up button would simply take them back to the same pop-up window," this one adds an extra level of sophistication by using iframes which are HTML documents embedded within other HTML documents.


It is done by setting iframe as the page’s showLogin, making it appear when the URL is entered. Iframe’s source or contents, in turn, is the authentication page URL and therefore just returns the user to the URL.



iframe usage

What makes this campaign even more effective is the fact that it employs adaptive authentication pop-ups designed to match the web browser the target uses, choosing automatically between Firefox, Chrome, and Edge, as well as a rule designed to cover all other browsers.

As Wang further found out after analyzing this iframe-based TSS campaign, the URLs of the campaign uses (which change roughly 12 times per day) were accessed up to 575 times per day between April 1 and April 19.


Daily visits

Just last month, another scammer group used Google search results fake ads designed to mimic legitimate eBay advertisements and redirecting targets to a tech support scam website that would attempt to lock up their browsers instead of opening the advertised eBay auction site.

Back in December 2018, scammers made use of JavaScript to create an inescapable loop which would claim all CPU resources and made it impossible for users to close the tab, the web browser, or their computer until killing the Chrome process.

To make matters even worse, as reported by Symantec back in November 2018, TSS campaigns have been increasingly using obfuscation techniques like Base64 encoding, custom obfuscation routines, or AES encryption to make them harder to detect and block.

As the Trend Micro researcher concluded, "Users should remember that there are other ways to recover their browser. Users that encounter a similar attack can simply close the browser using Task Manager. If they are truly worried about the security of their device and system, they can find other legitimate means of confirming the status of their systems."

Trend Micro also provides the full list of URLs used by this TSS campaign in the Indicators of Compromise (IOCs) section of their analysis.
