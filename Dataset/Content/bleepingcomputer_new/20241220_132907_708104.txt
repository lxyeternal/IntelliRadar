The new deep learning model is "now adopted and applied to expand our coverage of detecting malicious PowerShell scripts, which continue to be a critical attack vector," says Microsoft.

Microsoft's deep learning model used for malicious PowerShell script detection "combines several deep learning building blocks such as Convolutional Neural Networks (CNNs) and Long Short-Term Memory Recurrent Neural Networks (LSTM-RNN)."

The company adopted the best performing model designed for NLP and trained on collections of PowerShell scripts the Microsoft Defender ATP platform observed via the Antimalware Scan Interface (AMSI).

After its first deployment on Microsoft Defender ATP, this deep learning model specifically trained for spotting malicious scripts was able to find malicious PowerShell behavior that bypassed other Microsoft Defender ATP monitoring features.


Model generation process

"Stronger detection of malicious PowerShell scripts and other threats on endpoints using deep learning mean richer and better-informed security through Microsoft Threat Protection, which provides comprehensive security for identities, endpoints, email and data, apps, and infrastructure," concludes the Microsoft Defender ATP team.

Deep learning models are also used as part of the platform's file classification ML engine for almost real-time classification via deep neural network classifiers designed to inspect full file contents for an extra layer of defense against attacks.

Advanced Threat Protection upgrades

The Microsoft Defender ATP also utilizes deep learning classifiers as part of its detonation-based ML engine which would detonate suspicious files inside a sandbox to analyze the observed behaviors for attack blocking.

In March, Microsoft announced the addition of a "Tamper Protection" feature designed to block changes to key security features, and to prevent disabling the antimalware solution or to delete security updates without the user permission.


Malicious PowerShell scripts detected by the trained model

Two months later, in May, Microsoft Defender ATP was upgraded with new live response capabilities that enable security operation teams to perform system forensic analysis remotely.

Microsoft Defender ATP is an endpoint protection solution which allows system administrators to monitor their network's malware and threat landscape from one centralized location using security and data privacy capabilities.

"Microsoft Defender ATP combines data collected from millions of endpoints with Microsoft computational resources and algorithms to provide industry-leading protection against attacks," says Redmond.
