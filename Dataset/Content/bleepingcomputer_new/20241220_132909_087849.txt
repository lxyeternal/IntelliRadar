
	   


Piriform has released CCleaner v5.55 today, which for Professional users now includes a Software Updater feature that will check if installed 3rd party applications are running the latest version.

With this new version, CCleaner continues to offer cleaning for free to users who do not wish to purchase the program. For paid users, though, you now have access to a new feature called "Software Updater" that keeps 3rd party programs updated to the latest version.

"We know that keeping on top of updates can be challenging but also that it’s vital to ensure ongoing protection against the latest malware attacks," stated Paul Yung, VP Product, CCleaner. “The speed at which new attacks appear and vulnerabilities are identified can create more numerous updates which can be an administration headache for users, as shown by the two-thirds of users who admitted to ignoring updates. Software Updater helps to make it quick and easy by giving people visibility and control of all required updates in one place."

This will display a screen that checks for installed applications and displays any that need to be updated.


Programs to Update

You can also click on the Up-to-date Programs tab to see a list of supported programs that are already utilizing the latest version.


Up-to-Date Programs

If you are a free user and attempt to update any detected outdated applications, CCleaner will prompt you to upgrade to the Professional version along with a $10 discount offer.


Upgrade Prompt

As outdated programs are a known vector for vulnerabilities that can be exploited by bad actors, it is recommended to use a software updating tool like the one bundled with CCleaner.

If you are happy with the free version of CCleaner and do not wish to pay for the upgrade, you can utilize a free software update program like UCheck, Ninite, Patch My PC, and SUMo Free.

- Added new Software Updater feature to the ‘Tools’ menu 
- Scans your PC and shows any available updates 
- Select which apps you want to update and queue them up 
- More improvements coming soon! 

Browser Plugins 
- Fixed Opera plugins not displaying correctly
