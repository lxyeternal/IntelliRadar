
	   


On last month's Patch Tuesday, Microsoft announced that a vulnerability in Remote Desktop Services was discovered that could allow a wormable malware, such as a ransomware, to easily propogate through vulnerable systems.

This vulnerability, now known as BlueKeep, was given the unique ID of CVE-2019-0708 and affects Windows 7, Windows 2008 R2, Windows Server 2008, Windows XP, and Windows Server 2003. Due to its severity, Microsoft released patches for all supported versions of Windows as well as for Windows XP and Windows Server 2003, which no longer received security updates.

Since then, numerous security vendors and researchers have successfully created proof-of-concept exploits that can exploit this vulnerability. While none of these have been released, it would not be surprising if malware developer and threat actors were working on their own exploits.

To aid in this, researchers have created tools and scripts that can be used to check if a Windows machine is vulnerable to the BlueKeep vulnerability so that they can be patched.

Below we have described two of the available tools.

How to find Windows systems affected by BlueKeep

RDPScan by Robert Graham (Windows/macOS)

Security researcher Rob Graham created a program called RDPScan for Windows and macOS, which is based off of Zerosum0x0's rdesktop patch.

To use RDPScan, simply download the latest version from the project's releases section. Once downloaded, you can run the program from the command line using the following commands:

Scan a single host:

rdpscan [ip_address]
rdpscan 192.168.1.29

Scan a range of IP addresses:

rdpscan [start_ip_address]-[end_ip_address]
rdpscan 192.168.1.29-192.168.1.100

Scan a network with CIDR notation:

rdpscan [network]/[cidr_notation]
rdpscan 192.168.1.0/24

When using RDPScan, it will probe each of the IP addresses to see if port 3389 is open and then determine if the machine is vulnerable. To change the port being scanned, you can use the -p argument. You can also use the --workers argument to increase the speed of the scanning.

For a full list of arguments, use rdpscan -h.

When scanning for the vulnerability, it will list either Safe, Vulnerable, or Unknown. Any hosts that are marked as Vulnerable, as shown below, should have the appropriate security updates installed.


RDPScan showing vulnerable system

Metasploit Framework module by Zerosum0x0 and JaGoTu

For users of the Metasploit penetration testing framework, security researchers Zerosum0x0 and JaGoTu have created a module that can be used to scan for the BlueKeep vulnerability.

If Metasploit is installed, you can load the module with the following command:

use auxiliary/scanner/rdp/cve_2019_0708_bluekeep

Once the module is loaded you can perform a scan of individual systems and networks. As you can see below, we checked the host 192.168.8.60, which has been detected as vulnerable.
