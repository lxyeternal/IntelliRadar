
	   


Microsoft released the October 2019 Microsoft Office security updates, bundling a total of 14 security updates and four cumulative updates across seven different products, nine of them patching remote code execution flaws.

Customers are strongly advised to install them as soon as possible given that some of the Microsoft Office security updates published today also resolve various critical vulnerabilities,

To download today's Microsoft Office security updates, users have to click on the corresponding Knowledge Base article in the table below and scroll down to the "How to download and install the update" section to download the update packages on the page that opens.

Patched Microsoft Office vulnerabilities

Out of the 14 Office security updates released by Microsoft today, five of them patch remote code execution vulnerabilities (CVE-2019-1327 and CVE-2019-1331) within Office 2016, Office 2013, Office 2010, Excel 2016, Excel 2013, Excel 2010, Office Online Server, SharePoint Enterprise Server 2013, and SharePoint Server 2010.

The remote code execution security vulnerabilities patched today come with a severity rating of 'Important' by Microsoft seeing that they could allow attackers to execute arbitrary code and/or commands after successful exploitation of vulnerable Windows devices.

The rest of the security patches issued by Microsoft today also fix elevation of privilege, cross-site-scripting (XSS), and spoofing vulnerabilities (i.e., CVE-2019-1070, CVE-2019-1328, CVE-2019-1329, CVE-2019-1330) impacting SharePoint Server 2019, SharePoint Enterprise Server 2016, SharePoint Enterprise Server 2013, SharePoint Foundation 2013, and SharePoint Foundation 2010.
