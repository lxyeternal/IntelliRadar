
	   


A new malware downloader delivered via multiple campaigns uses detection evasion techniques and Microsoft SQL queries to drop malicious payloads onto compromised machines.

The malware, dubbed WhiteShadow by researchers at Proofpoint Threat Insight Team who found it, comes in the form of a set of Microsoft Office macros designed to work together to infect targets with a large array of malware strains it downloads from attacker-controlled Microsoft SQL Servers.

WhiteShadow is delivered via malspam emails containing malicious URLs or Microsoft Word and Microsoft Excel attachments that bundle malicious the downloader's Visual Basic macros which will install the malware payloads after execution.

Multiple WhiteShadow campaigns observed in just two months

Proofpoint's research team observed multiple malspam campaigns peddling the WhiteShadow downloader, with almost a dozen of them being spotted since the malware was first spotted in August.

While, in the beginning, the malware authors didn't bother to add any measures to prevent detection, during later campaigns they started slowly adopting various detection evasion techniques like code obfuscation.

For instance, they started altering the case of various strings that could be used for automated detection and misspelling some variables during early September, and got to use the StrReverse Visual Basic function to revers some strings in their macros' code and added randomized strings to prevent string re-use.

Most of the WhiteShadow campaigns detected by Proofpoint delivered the Crimson malware, another downloader used in the Operation Transparent Tribe malicious campaign that targeted Indian military and diplomatic victims.


WhiteShadow campaigns spanning two months

However, the attackers also distributed Agent Tesla, AZORult, Nanocore, njRat, Orion Logger, Remcos, and Formbook RATs, downloaders, and keylogger strains.

"It appears that WhiteShadow is one component of a malware delivery service, which includes a rented instance of Microsoft SQL Server to host payloads retrieved by the downloader," also found the researchers. 

WhiteShadow infection chain

After the targets open the malicious messages that come in the form of Microsoft Office docs riddled with WhiteShadow's VBA macros and executes them, the macros will connect to the compromised MSSQL servers using an SQLOLEDB connector.

It will next download the malware stored as an ASCII-encoded string within the MSSQL database and will decode it and write the result to the system's hard drive as a PKZIP archive.

The binary that gets extracted from the archive in the next step of the infection process is used to launch the installation process for the final malware payload that can be one of the several strains detected in previous campaigns.


Hex view of the PKZIP archive

"More importantly, this appears to be a new malware delivery service, allowing a range of threat actors to potentially incorporate the downloader and associated Microsoft SQL Server infrastructure into their attacks," concludes the Proofpoint Threat Insight Team.

"Organizations need to be cognizant of both the incoming malicious email and outbound traffic on TCP port 1433 which should be blocked or at least restricted on modern ACL configurations in firewalls today."

An extensive list of indicators of compromise (IOCs) associated with these campaigns and including malware sample hashes, as well as C2 server domains and IP addresses is available at the end of Proofpoint's WhiteShadow report.

More information on infrastructure and IOCs is available on VirusTotal and AlienVault (h/t Angel Hun‏ and J5m1th‏).
