Recently Microsoft announced that they will be rebuilding Microsoft Edge to be a Chromium based browser in order to provide greater compatibility and performance. One of the questions, and possibly concerns, is whether Microsoft would also enable the use of Chrome extensions in their new browser.

This was answered by Kyle Pflug, a Microsoft Senior Product Manager for the Microsoft Edge team, who posted to Reddit stating that "It's our intention to support existing Chrome extensions.".

As many people rely on Chrome extensions to enhance their browsing experience, enabling Chrome extensions makes it easier for existing Chrome users to migrate to the new Edge browser

Unfortunately, this also opens the browser up to the many, and I do mean many, malicious Chrome extensions that are created on a daily basis.

Welcome to the chaos of Chrome extensions

One of the things going for the current Microsoft Edge browser is that its market share is so low that most malware developers do not bother targeting the browser. This is not to say that malware can't affect Edge, but rather that far greater malware development is targeting Chrome and its over 60% browser market share.

A common methods for performing unwanted activity in Chrome is through malicious Chrome extensions. Some examples of malicious behavior we have seen caused by Chrome extensions in the past include hijacking your search pages, injecting ads, stealing contact information from logged in accounts, registering free domains for attackers, stealing account credentials, and injecting in-browser cryptocurrency miners.

Google has had a hard time to keeping up the quality control regarding extensions submitted to Chrome Web Store and new unwanted extensions are added daily. There are some search hijacker developers that create a brand new extension almost every day as Google removes one of their older ones from the store.

To combat this problem, it would be nice to see Microsoft's quality control come to Chrome extensions as well. One way this could be done is by requiring Edge to only install Chrome extensions from a Microsoft extension store.

Doing this will cause a bit of extra work for developers who now have to submit to both the Chrome and Microsoft stores, but it would also allows Microsoft's quality control to weed out the malicious extensions that we see all-too-often in Chrome.
