June 11th 2016

CryptXXX Ransomware started to utilize the cryptz Extension

The CryptXXX ransomware switched the extension used by encrypted files to the .cryptz extension and started scrambling encrypted files time stamps last week. Otherwise, there are no other changes to the ransomware.

June 13th 2016

Decryptor for the Apocalypse Ransomware released by Emsisoft

Fabian Wosar of Emsisoft released a decryptor that victims of the Apocalypse Ransomware can use to decrypt their files for free. This ransomware appends the encrypted extension to encrypted files and then requires you to email decryptionservice@mail.ru in order to get instructions on how to pay the ransom. For information on how to decrypt this ransomware, please see this article: Decryptor for the Apocalypse Ransomware released by Emsisoft.

Apocalypse Ransom Note

The new RAA Ransomware is created entirely using Javascript

The RAA Ransomware is a ransomware discovered by security researchers @JAMESWT_MHT and @benkow_ that is created entirely in Javascript. This ransomware utilizes the CryptoJS library so that AES encryption could be used to encrypt the files. 

RAA is currently being distributed via emails as attachments that pretend to be doc files.  When the JS file is opened it will encrypt the computer and then demand a ransom of ~$250 USD to get the files back. To make matters worse, it will also extract the embedded password stealing malware called Pony from the JS file and install it onto the onto the victim's computer. Encrypted files will have the .locked extension appended to them.


RAA Ransom Note

FLocker Mobile Ransomware Crosses to Smart TV

An article by TrendMicro was released that talks about the Flocker screen locking ransomware. This malware is a Android ransomware that locks your screen and then demands $200 USD in iTunes gift cards.  An interesting point that Trend makes is that the code used to lock an Android device does not care what that devices actually is. Therefore it could also be used to lock an devices running Android, such as televisions.

June 16th 2016

The Ded Cryptor Ransomware thinks you have been Naughty this Year

A new EDA2 ransomware was discovered by Michael Gillespie called Ded Cryptor. This ransomware has been around for quite a while and targets both Russian and English speaking victims. They request 2 bitcoins get the decryption key and there is no way to decrypt for free at this time.

When your files are encrypted they will have the .ded extension appended to them. Ded Cryptor will also change the wallpaper of the Windows desktop to an image that contains the ransom amount and the email address, dedcrypt@sigaint.org, which the victim is told to email for payment instructions.

It appears that Russian victims can contact the malware developers and will receive their key for free. According to the developers, they never meant to target Russian victims, which is strange as their ransom note is written in Russian. Strangely, the decryptor they provide clear your shadow volume copies, so you are better off using Michael's decrypter instead.

For more information and support, you can visit this topic: DED Cryptor Help & Support Topic ( dedcrypt@sigaint.org / .ded)

June 17th 2016

New Jigsaw Ransomware with Anonymous themed Background

A new variant of the Jigsaw Ransomware was released that utilizes a Anonymous theme for it's background.  This particular variant encrypts your data, appends the .epic extension, and then demands $5,000 in bitcoins in order to decrypt your files.

The good news is that Michael Gillespie was able to update his Jigsaw Ransomware decryptor to decrypt this variant as well. Instructions on how to use his decryptor can be found here: Jigsaw Ransomware Decrypted: Will delete your files until you pay the Ransom.


Anonymous themed Jigsaw Variant

New dr.jimbo@bk.ru Ransomware Discovered

Security researcher JAMESWT_MHT discovered a new ransomware that encrypts your data, appends the .encrypted extension and then tells you to email dr.jimbo@bk.ru for payment instructions. At this time there is no way to decrypt encrypted files for free.


Dr. Jimbo Ransom Note

Russian Crypt38 Ransomware allows for Free Decryption

Fortinet recently encountered a new ransomware targeting Russian victims. This ransomware will encrypt your files and append the crypt38 extension. In order to decrypt your files, the developer demands 1000 Rubles, or $15 USD, to get your files back

In their analysis, Fortinet discovered that the password required to unlock the files is easy to generate. Unfortunately, they did not release a key generator, so Michael Gillespie whipped one up quickly so that victims can get their files back.  

Victim's of this ransomware can download Michael's key generator and enter it into the ransom note to decrypt their files. It is suggested that you backup your encrypted files before using the developer's decryptor.


Ransom Note

New CryptoShocker Ransomware Fails to Impress

A new ransomware was discovered by S!Ri of Malwarebytes, and further analyzed by @benkow_,  that encrypts your data using AES encryption and then demands $200 USD worth of bitcoins to get your files back.  When CryptoShocker encrypts a victim's files it will append the .locked extension to them. It will also create a shortcut on your desktop to their TOR decryption site called ATTENTION.url. The decryption site also contains the cryptoshocker@tutanota.com email for the developer.

If you are infected with CryptoShocker, please let us know in the following support topic as we me be able to get your key back for free: CryptoShocker Ransomware Help and Support Topic ( .locked ATTENTION.url
