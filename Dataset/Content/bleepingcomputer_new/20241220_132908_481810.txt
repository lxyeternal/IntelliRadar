
	   


Baseboard management controllers (BMC) of some Supermicro servers are vulnerable to unauthorized virtual USB mounting attacks that can be carried out remotely.

Many of the affected servers are on internal networks but researchers say they found as many as 47,000 of them exposed on the internet.

Insecure connection and authentication

Several issues have been discovered in the virtual media implementation of the BMC component in Supermicro X9, X10, and X11 platforms. Collectively, the bugs are named USBAnywhere.

Administrators can use them to configure a server or reinstall the operating system and update the firmware.

These micro components also allow mounting a disk image as a virtual  USB drive. Researchers at firmware hardware security firm Eclypsium found that on some Supermicro platforms the virtual media service responsible for this action is insecure over a remote connection.


"When accessed remotely, the virtual media service allows plaintext authentication, sends most traffic unencrypted, uses a weak encryption algorithm for the rest, and is susceptible to an authentication bypass" - Ecluypsium


Attackers can take advantage of these weaknesses and gain the same level of remote access to the target server as if they had physical access to the USB port.

It is easy to see that such a scenario would mean a complete compromise of the server, as an USB-based attack offers numerous possibilities: reinstalling the operating system, planting malware, or altering server configuration.

The weaknesses

In a research paper today, Eclypsium details the vulnerabilities and how they can be exploited by a threat actor.

The researchers explain that accessing the virtual media service is done through a Java application launched from the BMC's web interface. The app connects to the virtual media service and listens on TCP port 623 on the BMC.

The service authenticates clients using a custom packet-based format and move the USB packets between the client and the server.



Even if the Java application relies on unique session IDs for authentication, the researchers found that the service allows plaintext credentials.

Furthermore, the traffic is encrypted only for the initial authentication packet. Adding to the list of weakness is the use of poor encryption that relies on the vulnerable RC4 stream cipher and a key that is present in the BMC firmware.

Another is an authentication bypass affecting Supermicro X10 and X11 platforms. According to the research, after a client's proper authentication to the virtual media service and a disconnect, the internal state of the service regarding that client remains unchanged.


"As the internal state is linked to the client’s socket file descriptor number, a new client that happens to be assigned the same socket file descriptor number by the BMC’s OS inherits this internal state. In practice, this allows the new client to inherit the previous client’s authorization even when the new client attempts to authenticate with incorrect credentials."


As dangerous as this looks, the good part is that this is unlikely to be controlled by the attacker as the assignment is performed by the BMCs operating system. By this logic, though, if an attacker is persistent enough, they could theoretically be assigned the socket file descriptor number of a previously authenticated user.

Nevertheless companies should apply the latest firmware updates Supermicro released to fix these issues on its X9, X10, and X11 platforms.

The researchers say that running a scan on Shodan for devices with port 623 "revealed 47,339 BMCs from over 90 different countries with the affected virtual media service publicly accessible."

A simple search for all devices with port 623 exposed shows that there are more than 95,000 devices accessible over the internet, a third of the results being from the U.S. Not all of them are vulnerable, though.
