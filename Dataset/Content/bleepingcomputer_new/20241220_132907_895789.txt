
	   
Today Microsoft, Oracle, and Adobe all released security updates for critical vulnerabilities in their products.  Critical vulnerabilities allow attackers to execute commands on the vulnerable computers that could allow them to download and installer further programs without your permission.  These vulnerabilities are the most dangerous as they are commonly utilized by exploit kits and hackers to gain full access to a computer.

In today's Patch Tuesday release, Microsoft released 13 security updates for many of their products. Six of these updates update were for critical vulnerabilities in Internet Explorer, Microsoft Edge, Windows, Windows Journal, and Microsoft Office. The full list of Microsoft updates are:

Oracle released the out-of-band Security Alert CVE-2016-0603 update that resolves a critical vulnerability in Java 6, 7, and 8.  This vulnerability requires an attacker to trick a victim into downloading a malicious file before installing Java. When the user then installs Java, the installation program will use the previously downloaded malicious file. This would allow the attacker to take full control over the victim's computer.  Though this attack is fairly complex to pull off, it is still advised that all Java users update to the latest software.
