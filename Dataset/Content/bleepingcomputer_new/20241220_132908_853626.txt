
	   


Microsoft announced today the final version of its security configuration baseline settings for Windows 10 Version 1903 and Windows Server Version 1903, downloadable today using the Microsoft Security Compliance Toolkit.

The Windows 10 security baseline allows enterprise security administrators to use Microsoft-recommended GPO baselines for improving the overall security posture of a system and reduce a Windows 10 machine's attack surface.

As announced on April 24 when a draft of the security baseline for Windows 10 19H1 was published, Microsoft made a number of changes to the Windows 10 Version 1809 recommended security settings among which the removal of password expiration policies and of specific BitLocker drive encryption method and cipher strength settings stand out.

According to Redmond, the preset password expiration settings should be replaced after being removed with more modern and better password-security practices like multi-factor authentication, detection of anomalous log on attempts, detection of password-guessing attacks, or the enforcement of banned passwords lists (such as Azure AD's password protection currently available in public preview).

Nevertheless, as Microsoft further clarifies, "While we recommend these alternatives, they cannot be expressed or enforced with our recommended security configuration baselines, which are built on Windows’ built-in Group Policy settings and cannot include customer-specific values."

In 2016, the United States National Institute for Standards and Technology (NIST) also urged government organizations to remove password expiration policies and it now recommends forced password changes only after fraudulent activity is observed within an org's IT systems.

Microsoft also says that "to try to avoid inevitable misunderstandings, we are talking here only about removing password-expiration policies – we are not proposing changing requirements for minimum password length, history, or complexity."

Removal of specific BitLocker encryption method and cipher strength settings

While until Windows 10 Version 1809 Microsoft's recommended security settings required administrators to enable the strongest available BitLocker encryption, Redmond is now dropping it from the baseline because the default 128-bit encryption is in no danger of "being broken in the foreseeable future."

In addition, the removal of specific BitLocker settings from the baseline has been prompted by "noticeable performance degradation going from 128- to 256-bit" on some hardware configurations.

"And finally, many devices such as those in the Microsoft Surface line turn on BitLocker by default and use the default algorithms," also states Microsoft's Security Guidance blog post.

"Converting those to use 256-bit requires first decrypting the volumes and then re-encrypting, which creates temporary security exposure as well as user impact."

The final Windows 10 v1903 baseline also has extra changes

The just-released final security baseline also removes the enforcement of the built-in Administrator and Guest accounts being disabled by default, a change that was included as a proposal in the initial draft.

This enables administrators to toggle the two accounts as they are required but the removal of this policy does not automatically mean that the accounts will be enabled by default.

On top of  the changes detailed in the baseline draft from April, Microsoft has also decided to adopt several other updates to its recommended security settings:


Dropping the enforcement of the default behavior of disabling the built-in Administrator and Guest accounts. We had floated this proposal at the time of the draft baseline, and have since decided to accept it. The change is discussed in more detail below.
	Dropped a Windows Defender Antivirus setting that applies only to legacy email file formats.
	Changed the Windows Defender Exploit Protection XML configuration to allow Groove.exe (OneDrive for Business) to launch child processes, particularly MsoSync.exe which is necessary for file synchronization.


As mentioned in the beginning, the Windows 10 v1903 security baseline is available for download via the Microsoft Security Compliance Toolkit, and it includes Group Policy Object (GPO) backups and reports, scripts to apply settings to the local GPO, and Policy Analyzer rules files.

A detailed list of all the changes implemented in the final version of the baseline is available in Microsoft's Security Guidance blog post announcing the release.
