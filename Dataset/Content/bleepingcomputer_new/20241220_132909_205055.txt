16Shop is a commercial phishing kit that emerged as a sophisticated tool with layered defenses and multiple attack mechanisms that can adapt its visual tricks to the platform used by the victim.

Extensive language support

It has support for 10 languages (English, Japanese, Chinese, French, Spanish, Malay, Latin, German, Thai, and Dutch), so it can target Apple users from a large number of countries.

To protect from losing revenue, the author of 16Shop uses an API-driven system where license validation happens in real time. On top of this, code-level defenses prevent making unauthorized copies.

All worked well until someone figured out a way to crack 16Shop and in late  2018 pirated variants became available with a local configuration file and the authorization no longer occurred via the phishing kit's website.

The double-crossing code

Researchers at Akamai analyzing a cracked version of the malicious software noticed that it included code that leaked all the data collected from the victims via the Telegram messaging service.



"Criminals, such as those who use 16Shop, don't like to share the information they've compromised freely, opting instead to sell it or trade it for something of equal value," says Akamai's Amiram Cohen.

So whoever used this unauthorized version of 16Shop had their operation compromised as the illegally harvested information was copied and then delivered to a bot in a channel on Telegram.

Researchers discovered the code responsible for extracting the user information in the file "main.php," and was highly obfuscated. After cleaning it up, it looked like this:

extract(valid($valid($image($data,5126))));

According to Akamai's findings, the code "collects information for all of the forms visited by the victim, and no matter what storage and delivery options are selected by the 16Shop operator, the victim's data is siphoned off and sent to the Telegram bot via API calls."

The author of 16Shop indeed used Telegram as a means for data storage but the researchers also found a small American Express image file embedded with commands using steganography technique.

Based on this evidence, the researchers conclude that anyone using the cracked version of 16Shop they analyzed is bound to be ripped off and the victim's data is twice stolen.

Phishing kit can spoof sites of 117 banks

16Shop is a complex tool that can do more than just serve a webpage impersonating a service. The image blow shows just how complex its work flow is, with customization options for stealing email credentials  as well as banking data.



Akamai created a simplified version of the diagram, and one easier to read, that shows the variety of information an attacker wielding 16Shop can steal.



There are multiple attack levels that can pilfer credentials for email services. The version studies by the researchers could target users on Yahoo and Yahoo Japan, AOL, Gmail, Hotmail, and Hotmail Japan, and featured a generic login for unfamiliar services.

In a third attack stage, 16Shop can collect bank-related data, including name, credit card details (account number, expiration, CVV code) - date of birth, mother's maiden name, and security code.

It can spoof the web pages of 117 banks, complete with logos. Among them are Fifth Third Bank, ANZ, Bancolombia, Bangkok Bank, State Bank of India, Barclays, Bank of America, Bank of China, Capital One, Chase, HSBC, Citi, ING, LAPD Credit Union, Navy Federal Credit Union, PNC, RBS, TCU, USAA, and Wells Fargo.

Japanese victims are also asked for their Web ID and Card Password, while those in the U.S. are asked for the Social Security Number.

Details about the author

The author of 16Shop is obviously a skilled developer. Researchers found that he is someone using the online aliases "Riswanda" and "devilscream."



It appears that he left behind an online trail that led to tracking his GitHub repositories, security presentations, email addresses, social media accounts, and samples of website defacements. The volume of data uncovered about the author of 16Shop is so large that there are two theories: he is either bad at protecting his identity or is very good at inventing and maintaining a new one.
