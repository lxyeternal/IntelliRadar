
	   


Microsoft Edge is testing a new feature in their Canary build that allows you to block potentially unwanted programs (PUPs) from being downloaded by the browser.

Potentially unwanted programs, or PUAs as Microsoft calls them, are software that straddle the line between legitimate applications and malware. They tend to display unwanted ads, perform redirects, hijack functions of your browser or computer, use scare tactics, or claim to fix system issues, but don't really do anything.

In many cases these types of programs should be classifed as malware, but are not for legal reasons.

Once enabled, as described later in the article, you will see a new setting under the Privacy and services settings titled "Block potentially unwanted apps".


Block potentially unwanted apps setting

Once enabled, any downloads that are determined to be PUAs by Microsoft Edge will be blocked and the browser will state "Example.exe was blocked becaused it could harm your device."


Blocking a PUA test file

If you want to test this feature yourself against a PUA, you can use the test file here.

Block the downloading of PUPs or PUAs in in Microsoft Edge

To enable the new PUA blocking feature, you need to enable an experimental flag in the edge://flags screen.

From edge://flags search for "pua" and a flag titled "Microsoft Defender Smartscreen PUA support" will appear. To enable the new user interface, change this setting from Default to Enabled and then relaunch the browser when it prompts you to do so.


Microsoft Defender Smartscreen PUA support flag

Once Edge has restarted, you can enable the Block potentially unwanted apps setting in order to block PUAs from being downloaded by Microsoft Edge.
