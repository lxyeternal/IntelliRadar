A code injection vulnerability exists in VMware Cloud Director (vCloud Director) 10.0.0.2, 9.7.0.5, 9.5.0.6, and 9.1.0.4 that may lead to remote code execution, VMware says in its security advisory.

Cloud Director software allows cloud-service providers around the world to deploy, automate, and manage virtual infrastructure resources in a cloud environment.

Tracked as CVE-2020-3956, the security flaw was discovered by Tomas Melicher, and Lukas Vaclavik, penetration testers at Citadelo, when auditing the cloud infrastructure of a company using VMware Cloud Director for managing virtual datacenters for clients.

Auditors found that an authenticated attacker can use the product’s HTML and Flex user interfaces or API calls to send malicious traffic to the system. This could put them in “control of private clouds within an entire infrastructure.”

Authentication would not be an obstacle, though. The researchers say that attackers could pick from cloud providers that offer free trial access to the platform.

Leveraging CVE-2020-3956, they were able to view sensitive information belonging to customers on the infrastructure as well as escalate their privileges to those of a system administrator with access to all cloud environments. Below is a list of possible actions:

View content of the internal system database, including password hashes of any customers allocated to this infrastructure.
	Modify the system database to steal foreign virtual machines (VM) assigned to different organizations within Cloud Director.
	Escalate privileges from “Organization Administrator” (normally a customer account) to “System Administrator” with access to all cloud accounts (organization) as an attacker can change the hash for this account.
	Modify the login page to Cloud Director, which allows the attacker to capture passwords of another customer in plaintext, including System Administrator accounts.
	Read other sensitive data related to customers, like full names, email addresses, or IP addresses.
Citadelo created a proof-of-concept exploit for CVE-2020-3956 and made it available on GitHub. They also published a video demonstrating how the flaw can lead to a complete takeover of the cloud infrastructure:



The issue received a severity rating of 8.8 (high), though Citadelo clearly shows the risk for enterprising using an outdated version of Cloud Director.

Organizations that cannot update the product to a version considered safe can apply the workarounds VMware provides for affected releases in the security advisory.
