
	   


New research explores the similarities of three illicit mining cybercrime groups that are known to compromise enterprise services in order to install miners. Combined, these three groups have generated approximately 1,200 Monero coins, which at one point were worth over $400 USD each.

When Cisco Talos first started researching these groups, based on the similar tactics and procedures used when conducting cybercrime operations, the researchers had thought they were the same group. After further analysis, it was determined that the monitored activity is actually the work of three different groups called Rocke, 8220 Mining Group, and the Tor2Mine group.

"Through Cisco Talos’ investigation of illicit cryptocurrency mining campaigns in the past year, we began to notice that many of these campaigns shared remarkably similar TTPs, which we at first mistakenly interpreted as being attributed to a single actor," Cisco Talos stated in research shared with BleepingComputer. "However, closer analysis revealed that a spate of illicit mining activity over the past year could be attributed to several actors that have netted them hundreds of thousands of U.S. dollars combined."

These tactics include hosting their tools and scripts in GitHub repositories, PasteBin, and .tk domains and utilizing JPEG files that contain hidden scripts, the open-source XMRig miner, and tools such as XHide Process Faker and PyInstaller.

The tactics used by these groups are summarized below.

Rocke

Cisco Talos first started monitoring the group known as Rocke when the attackers targeted one of their honeypots. After examining their wallets and infrastructure, they were able to track them to other operations targeting Apache Struts 2, Jboss, and Jenkins servers.

"Cisco Talos wrote about Rocke earlier this year, an actor linked to the Iron Cybercrime group that actively engages in distributing and executing cryptocurrency mining malware using a varied toolkit that includes Git repositories, HTTP File Servers (HFS), and a myriad of differentpayloads, including shell scripts, JavaScript backdoors, as well as ELF and PE miners," stated the researchers. "Talos first observed this actor when they attacked our honeypot infrastructure."

This group utilizes GitHub repositories, HTTP File Servers (HFS), various exploits, scripts, JavaScript backdoors, JPEGs embedded with scripts, and ELF and PE miners as part of their operations.

The Rocke group's attacks are also known to utilize scripts that acts as ransomware or perform worm-like propagation to other vulnerable servers.

When monitoring this group, they noticed that they forked a repository called whatMiner, which led the researchers to another group called the 8220 Mining Group.

8220 Mining Group

The 8220 Mining Group is another cybercrime group that hosts their projects on GitHub and has been able to earn almost $200,000 through their malicious mining activities. Cisco Talos gave this name to the group as they are known to communicate with their malware infrastructure and C2 servers using TCP port 8220.

Talos first noticed this group after Rocke forked their malicious whatMiner Monero mining repository. This repository contains numerous scripts, exploit code, and methods for attacking Redis, Oracle WebLogic, Struts 2, Drupal, and Hadoop Yarn servers and installing Miners on them


whatMiner GitHub Page

Like Rocke, the 8220 Mining Group also utilizes JPEG files named logo*.jpg that contains embedded scripts. These scripts are executed by the compromised server's shell to download and install the XMRig miner on the server.

According to the researchers, the 8220 Mining Group is also known for utilizing malicious Docker images to cryptojack compromised services.

tor2mine

The researchers have also been tracking a group called tor2mine for their use of Tor gateways to communicate with their C2 servers. A Tor gateway is a site that acts as a bridge between the Internet and the TOR network. By utilizing these gateways, the attackers do not need to install a Tor client on the compromised server to communicate with a Tor site and are still able to hide the IP address of their Tor Command & Control servers.

This group targets both Linux based systems as well as Windows computers through the use of PowerShell and bash scripts that download the XMRig miner, other scripts, and malware to the compromised devices.


HTA File containing a PowerShell script

Some of the executables analyzed by Cisco Talos also included code to exploit EternalBlueEternalBlue & EternalRomance vulnerabilities that allow them to spread their malware to other machines.

Fall of cryptocurrency affecting cryptojacking?

In January 2018 a single Monero coin was worth over $400 USD. Now that same coin is worth only $45.

With these rapid declines in value for cryptocurrency, the question is whether cybercrime groups will continue focusing on cryptojacking as a way to earn revenue?

Cisco has seen that the Rocke repositories continue to update their cryptojacking tools and scripts, so it looks like they are still in the game. As for the attackers, it is still too early to tell if they will continue with their activities or switch to other attack methods such as ransomware or data exfiltration.
