
	   


Adobe has published their monthly Patch Tuesday updates for the month of September 2019 that resolves three security vulnerabilities in two programs. All the vulnerabilities fixed today are for arbitrary code execution that could allow an attacker to execute commands on a vulnerable machine.

Of particular concern are the Critical vulnerabilities found in Adobe Flash Player, which could allow attackers to execute code on a vulnerable machine through specially crafted web sites. Thankfully, most browsers have started to disable Flash Player by default in the latest versions.

APSB19-45 Security update available for Adobe Application Manager

Adobe released a security update for Adobe Application Manager related to a DLL hijacking vulnerability that could lead to arbitrary code execution. This allows an attacker to replace a DLL used by the Application Manager installer with a malicious executable that is then launched instead.

Vulnerability Category
			Vulnerability Impact
			Severity
			CVE Numbers   
		Insecure Library Loading (DLL hijacking) 
			Arbitrary Code Execution
			Important 
			CVE-2019-8076
		This vulnerability was fixed in Adobe Application Manager (installer) 2019 Release.

APSB19-46 Security updates available for Adobe Flash Player

An update for Adobe Flash Player has been released that fixes two Critical vulnerabilities that could lead to arbitrary code execution. Both of these vulnerabilities were disclosed to Adobe through Trend Micro's Zero Day Initiative.

Vulnerability Category
			Vulnerability Impact
			Severity

		Same Origin Method Execution
			Arbitrary Code Execution 
			Critical 
			CVE-2019-8069 
		These vulnerabilities were fixed in Adobe Flash Player 32.0.0.255.
