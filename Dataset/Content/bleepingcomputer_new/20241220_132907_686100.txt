In Silicon Valley, Microsoft was one of the first companies to set up a bug bounty program that rewards security researchers for discovering and privately reporting vulnerabilities in the company's products.

What few people know is that almost all of these programs, including Microsoft's, work based on a very well defined set of rules that limit the software and domains that security professionals can target for their research.

Or at least not in the way most people thought.

Edge wasn't a full member of the Microsoft bug bounty program

Microsoft first added Edge to its official bug bounty program in April 2015, two months before the company launched the browser as part of its Windows 10 OS.

At the time, Edge was known as Project Spartan, and Microsoft wanted researchers to submit bugs such as sandbox escapes and remote code execution (RCE) flaws, for which it was willing to pay up to $15,000.

That initial bug bounty program stopped with Windows 10's release, but after a slew of vulnerabilities discovered in Edge and abused by exploit kits, the company decided to re-add Edge to its bug bounty program in August 2016.

This second run in Microsoft's bug bounty program was limited from the get-go, lasting from August 2016 to May 2017. In addition, Microsoft was mainly interested in RCE flaws in Edge running on Windows Insider Preview builds only, although it allowed researchers to submit other types of bugs, but for smaller monetary rewards.

According to Akila Srinivasan, member of the Microsoft Security Response Center, this second bug bounty run resulted in significant security improvements in Edge's security.

Microsoft paid researchers more than $200,000

Srinivasan says Microsoft paid over $200,000 to security researchers since August 2016, receiving all sorts of vulnerabilities, and not just the RCEs it was interested in.

Convinced of the program's effectiveness, the OS maker is now making Edge a permanent part of its bug bounty program, allowing researchers to submit bugs they find at any time, not just in special bug bounty runs.

The decision to make Edge a permanent part of the Microsoft bug bounty program was to be expected, as Microsoft has slowly abandoned Internet Explorer, and has been aggressively pushing Edge on Windows 10 users.

Below are the bug bounty program's main rules. More details are available here.

Any critical remote code execution or important design issue that compromises a customer’s privacy and security will receive a bounty
	The bounty program is sustained and will continue indefinitely on Microsoft’s discretion
	Bounty payouts will range from $500 USD to $15,000 USD
	If a researcher reports a qualifying vulnerability already found internally by Microsoft, a payment will be made to the first finder at a maximum of $1,500 USD
	Vulnerabilities must be reproducible on the latest Windows Insider Preview (slow track)
	All security bugs are important to us and we request you report all Microsoft Edge browser security bugs to secure@microsoft.com via Coordinated Vulnerability Disclosure (CVD) policy
