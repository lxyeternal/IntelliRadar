A popular open-source text search server, Sphinx offers impressive performance for indexing and searching data in databases or just in files. It is cross-platform, available for Linux, Windows, macOS, Solaris, FreeBSD, and a few other operating systems.

Local access only

CERT-Bund posted the warning on Twitter today alerting network operators and providers about the risk of running Sphinx servers with a default configuration that are open on the web.

Exposing it on the web gives an attacker the possibility "to read, modify or delete any data stored in the Sphinx database."



By default, the server listens on ports 9306/TCP and 9312/TCP on all network interfaces.Shodan returned a few thousand results when we searched for one of the ports, plenty of them for Sphinx servers.

Admins have a simple way to check if their servers can be reached from the internet, using standard tools available in Linux/Unix systems.

By running 'netcat' from a computer outside the local network, admins can check if a connection can be established. If this is the case, they will see the version information for the server.



CERT-Bund's recommendation is not to expose Sphinx servers online and block any incoming connection from the internet to its communication ports.

For setups where Sphinx and the web server share the same machine, admins can configure Sphinx to listen on the local interface.

The advisory also comes with the standard recommendation to run the most current version of Sphinx.  Many of the versions we noticed on Shodan were outdated.
