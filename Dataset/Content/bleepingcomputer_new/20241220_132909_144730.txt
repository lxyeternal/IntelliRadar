
	   


Cisco fixed a critical remote code execution vulnerability present in the web-based management interface of the RV110W Wireless-N VPN Firewall, RV130W Wireless-N Multifunction VPN Router, and RV215W Wireless-N VPN Router devices.

Cisco's security advisory rates the vulnerability currently tracked under CVE-2019-1663 as critical and assigns it a 9.8 base score based on the Common Vulnerability Scoring System (CVSS) 3.0 given that it could allow potential unauthenticated attackers to remotely execute arbitrary code on any of the three vulnerable routers.

The flaw is due to "improper restriction of operations within the bounds of a memory buffer" where "the software performs operations on a memory buffer, but it can read from or write to a memory location that is outside of the intended boundary of the buffer," as described in the CWE-119 entry of The MITRE Corporation's Common Weakness Enumeration database.

The vulnerability is due to improper validation of user-supplied data in the web-based management interface. An attacker could exploit this vulnerability by sending malicious HTTP requests to a targeted device. A successful exploit could allow the attacker to execute arbitrary code on the underlying operating system of the affected device as a high-privilege user.

Only devices with custom configurations are vulnerable

There is some good news though given that, by default, remote connections on the web-based management interface are disabled for all three vulnerable devices, with the only way to manage them being over a LAN connection.

As stated by Cisco, "To determine whether the remote management feature is enabled for a device, administrators can open the web-based management interface and choose Basic Settings > Remote Management. If the Enable box is checked, remote management is enabled for the device."

Cisco has released software updates to fix the CVE-2019-1663 security issue, available in the following firmware releases:


RV110W Wireless-N VPN Firewall: 1.2.2.1
	RV130W Wireless-N Multifunction VPN Router: 1.0.3.45
	RV215W Wireless-N VPN Router: 1.3.1.1


All customers using one of the impacted devices are advised to update their firmware to the latest version to avoid any potential exploitation of the vulnerability.

To update the firmware, users can get the patched software from the Software Center on Cisco.com by clicking the "Browse All" option and following the detailed procedure available on the advisory page.

Elevation of privilege fixed in Webex Meetings and Productivity Tools

The CVE-2019-1663 vulnerability was first presented without using details regarding the impacted devices during the GeekPwn Shanghai conference that took place between October 24-25, 2018, by security researchers Yu Zhang and Haoliang Lu.

Cisco also released software fixes for a high impact elevation of privilege vulnerability tracked as CVE-2019-1674 and impacting the Cisco Webex Meetings Desktop App and the Cisco Webex Productivity Tools products.

The CVE-2019-1674 security issue could allow unprivileged local attackers to elevate privileges and run arbitrary commands using the SYSTEM user privileges on devices running the affected software.

Security researchers found other vulnerabilities impacting Cisco's WebEx online video collaboration software and the one discovered by Counter Hack's Jeff McJunkin and Ron Bowes on October 24, 2018, definitely takes the cake.

The vulnerability known as WebExec allows would-be attackers to remotely execute arbitrary commands through a component of vulnerable versions of the WebEx client even when WebEx is not configured to listen for remote connections.
