Microsoft's Alex Simons says that, after receiving the alerts, "You can then view your account activity and take actions to protect your account if needed. The goal of these notifications is to increase awareness and help you react quickly if there is unexpected activity."

To receive security notifications via the Microsoft Authenticator app all users have to do is to set up the app using their personal Microsoft account.

Microsoft Authenticator security notifications

This app is available for Android, iOS, and Windows Phone, and it replaced the Azure Authenticator application as the recommended auth tool for Azure Multi-Factor Authentication users.

The Microsoft Authenticator app is an authentication tool designed to help users sign-in to accounts where two-factor verification (also known as two-step authentication or 2FA) is enabled.

Two-factor authentication makes it possible for users to log into their accounts securely, especially when the accounts allow access to highly sensitive information such as banking or medical information. 

According to Microsoft, if you receive a security notification regarding unusual sign-in attempts, you will be provided with the means to view account activity and take any necessary actions such as changing the password or update the security contact info.

You should go through these steps to make sure that your account is secure:


Sign in to the Security basics page for your Microsoft account.
	Select Review activity to check for any unusual sign-in attempts. If you see account activity that you're sure wasn't yours, flag it on the recent activity page and we'll help you secure your account. 
	If you think someone else may have accessed your account, go back to the Security basics page and select Change password. Create a strong password that you can remember, and don't share it with anybody else.
