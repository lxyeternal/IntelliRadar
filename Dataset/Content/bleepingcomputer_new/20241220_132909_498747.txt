Starting Friday, when launching Tor, users would have noticed a message stating "One or more installed add-ons cannot be verified and have been disabled."

Disabled NoScript and HTTPS-Everywhere Addons

As the Tor Browser is based on Firefox and requires all addons to be signed by a valid certificate before being enabled, once the certificate expired, so did the bundled addons in Tor.

As a temporary fix until Tor releases a new version, you can disable this signature requirement by setting the xpinstall.signatures.required setting to false. Since requiring valid signatures is a security feature, it should only be disabled until Tor releases a new version with a bundled fix.

To disabled signatures, go to about:config, search for xpinstall.signatures.required, right-click on it, and select Toggle.  Once you do that, the setting should be set to false.


Toggle xpinstall.signatures.required setting

You can now go back to the about:addons page and the NoScript and HTTPS Everywhere extensions should be enabled.


Tor Addons Enabled Again

The only difference is you will now see a warning stating "NoScript could not be verified for use in Tor Bowser. Proceed with caution."

This warning will go away when the new version of Tor is released with the fix and you set the xpinstall.signatures.required setting to true again.
