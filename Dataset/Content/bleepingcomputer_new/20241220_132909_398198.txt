
	   


A targeted attack against pro-Tibetan supporters has been discovered that installs the ExileRat remote access Trojan through malicious PowerPoint attachments. Once infected, the RAT will allow attackers to retrieve information, execute commands, and steal data from the infected computers.

In new research released by the Cisco Talos Group, a malspam campaign was discovered that targets the Central Tibetan Administration (CTA) mailing list. The CTA is an organization that is considered to the Tibetan government in exile and this mailing list is used by the organization to communicate with their supporters.

This attack was initiated by sending a email to the the CTA mailing list that pretends to be from the CTA. This email had a subject of "Tibet-was-never-a-part-of-China" and contains a PowerPoint document that discusses how Tibet was never part of China.

Fake CTA Email to the CTA Mailing List

According to Cisco everyone on the mailing list received the emails and the attackers modified the Reply-To header so that the attackers would receive any response to the email.

"Everyone on the CTA's mailing list received this email," stated the Cisco Talos Group's research. "The mailing list's infrastructure is run out of DearMail, an India-based company that bills itself as a "powerful cloud enabled web-based email campaign manager." The attackers modified the standard Reply-To header normally used by the CTA mailings so that any responses would be directed back to an email address belonging to the attackers: mediabureauin [at] gmail.com."

A PowerPoint presentation of the same name and content is available on the CTA's site, but the one attached to this email has been modified to exploit vulnerabilities on the recipient's computer.  Once the attachment was opened, the presentation would be displayed and an arbitrary code execution vulnerability in Microsoft office (CVE-2017-0199) was used to retrieve a JScript script from a remote server and execute it.


Malicious PowerPoint Presentation

This JScript script, shown below, will download a file called syshost.exe from a server at 27.126.188.212, save it to %AppData%\syshost.exe, and execute the file.


Malicious JScript Script

After syshost.exe is executed, a schedule task will be created called Diagnostic_System_Host that enables persistence for the RAT so that it is launched every time the user logs in. As stated by Cisco, this scheduled task uses a similar name as the legitimate Windows service called Diagnostic System Host in order to evade detection.


Diagnostic_System_Host Scheduled Task

Once syshost.exe is started, it will connect to iplocation.com to determine the victim's public IP address and their geographic location. The data returned by this site is then written to a file named c:\data.ini.

The researchers state the RAT would then gather other information such as running processes, computer name, username, network adapter information, drive information and upload it to the attacker's Command & Control server. This malware also has the ability to execute commands issued by the attackers and exfiltrate, or steal, files from the victim.

It is not currently known what files were being extricated by the attackers.

C2's IP address uses in previous attack on Pro-Tibet users

Cisco states that the IP address for the ExileRate command & control server was also utilized by another malware campaign called LuckyCat Android RAT.

This malware campaign also targeted pro-Tibetan supporters and activists and when installed could execute commands, perform location tracking, record calls, and steal SMS texts.

While a state-sponsored attack from China could be a reasonable guess, there is no known evidence that this is the case at this point.
