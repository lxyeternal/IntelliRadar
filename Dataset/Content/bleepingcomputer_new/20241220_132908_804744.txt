Kali Linux is a distribution built for security professionals and comes with numerous software packages and tools that can be used by ethical hackers to perform penetration testing.

With this release, the Kali Linux Team introduces a variety of new features outlined below.

With this release, the Kali Linux Team begins their plan to switch from a default Bash shell to ZSH.

In the next version, Kali Linux 2020.4, the default shell will automatically be switched to ZSH so that users can benefit from the many plugins, themes, and extra features such as path expansions, auto directory changing, and auto-suggestions.

"You can do a lot of advanced things with bash, and customize it to do even more, but ZSH allows you to do even more. This was one really large selling point," the Kali Linux Team explains.

With this release, bash will continue to be the default shell, but ZSH will also be installed with a new configuration created by the Kali team.


ZSH shell benefits

For Kali users installing a fresh install, you can try out the ZSH shell simply by entering the 'zsh' command.

For users upgrading to 2020.3, you will first need to install the ZSH shell using the following commands:

sudo apt install -y zsh zsh-syntaxhighlighting
zsh-autosuggestions

For those upgrade, to use the new ZSH configuration created by Kali, you then need to copy it to your home:

cp /etc/skel/.zshrc ~/

If you find you enjoy using ZSH and want to make it your default shell, you can use the following command:

chsh -s /bin/zsh

Tool Icons

With this release, every tool in the Kali menu will now sport new themed icons, which are displayed below.

"Over the last few releases, we have been showing the progress on getting more themed icons for tools. We can now say, if you use the default tool listing ( kali-linux-default ), every tool in the menu (and then a few extra ones!), should have their own icon now," the Kali Linux Team states in their blog post about the new release.


Kali tool icons

Kali NetHunter improvements

The Kali NetHunter mobile penetration testing suite has been updated to include the new Bluetooth Arsenal tool to discover bluetooth devices and snoop or inject audio into them.

"It combines a set of bluetooth tools in the Kali NetHunter app with some pre-configured workflows and exciting use cases. You can use your external adapter for reconnaissance, spoofing, listening to and injecting audio into various devices, including speakers, headsets, watches, or even cars."


Kali NetHunter BlueTooth Arsenal

This release of Kali NetHunter also adds support for installing the suite on Nokia 3.1 and Nokia 6.1 phones.

Other changes in Kali 2020.3

Other changes in Kali 2020.3 include improvements in the setup process to increase its speed when performing an installation that requires a lot of updates.

This release also added greater support for ARM devices with a total of 39 install images, up from 19 images supported in Kali Linux 2020.2. Numerous improvements were also added to improve device compatibility and speed in ARM.

Finally, changes have been made to the Kali desktop environment to use a new theme for Nautilus, improved designs for 'nested headerbars', and an overhauled color scheme for system-monitor.


Desktop environment changes

How to get Kali Linux 2020.3

To install a fresh version of Kali Linux 2020.3, you can download ISO images that support full installs or live distributions.

For those updating from a previous version, you can use the following commands to upgrade:

echo "deb http://http.kali.org/kali kali-rolling main non-free contrib" | sudo tee /etc/apt/sources.list

sudo apt update && sudo apt -y full-upgrade

[ -f /var/run/reboot-required ] && sudo reboot -f


You can then check if the upgraded was successful with the following command:

grep VERSION /etc/os-release
