
	   


Microsoft has issued a warning Friday night about an active spam campaign targeting European languages that is utilizing an exploit that could infect users simply by opening the attached document.

In a series of tweets from the Microsoft Security Intelligence account, Microsoft is warning that they have detected an active campaign that contains RTF attachments utilizing the Microsoft Office and Wordpad CVE-2017-11882 vulnerability.


Example attachment with CVE-2017-11882 Exploit

When successfully exploited, this vulnerability can automatically infect users by simply opening the attached document.

The CVE-2017-11882 vulnerability allows RTF and Word documents to be created that automatically execute commands once opened. This vulnerability was patched in 2017, but Microsoft states that they continue to see the exploit used in attacks, with an uptick over the past few weeks.

"Notably, we saw increased activity in the past few weeks. We strongly recommend applying security updates."

According to Microsoft, when the attachment is opened, it will "execute multiple scripts of different types (VBScript, PowerShell, PHP, others) to download the payload."

When we tested one of the sample documents, upon opening the document, it immediately started executing a script downloaded from Pastebin, which executed a PowerShell command. This PowerShell command would then download a base64 encoded file and saved it to %temp%\bakdraw.exe.


Downloading Scripts and Malware

A copy of bakdraw.exe will then be copied to %UserProfile%\AppData\Roaming\SystemIDE and a scheduled task called SystemIDE will be configured to start the executable and add persistence.


Scheduled Task

Microsoft states that this executable is a backdoor that is currently configured to connect to a malicious domain that is no longer accessible. This means that even though the computer will be infected, the backdoor is not able to communicate with its command and control server to receive commands.

This payload could easily be switched out for a working one, though, so Microsoft suggests that all Windows users install the security update for this vulnerability as soon as possible.

The CVE-2017-11882 vulnerability was also recently discovered by FireEye being used in a campaign targeting Central Asia and installing a new backdoor called HawkBall.  It is not known if these campaigns are connected.
