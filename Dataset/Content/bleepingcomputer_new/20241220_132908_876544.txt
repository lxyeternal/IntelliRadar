Security researchers have discovered that a very popular photo retouching iOS and Android application is collecting user data and sending it for storage to servers in China.

Developed by the eponymous Chinese company, Meitu is a very popular mobile application with over 10 million users just on Android.

The app launched in 2008, but became very popular at the end of 2016 due to its advanced photo editing features that rivaled the ones you'd find in desktop editing tools, but also because of a function that allows users to transform themselves into Manga-like, huge-eyed characters.

Meitu Android app asks for 25 permissions

According to security researchers Greg Linares, Jonathan Zdziarski, and FourOctets, the Meitu app, both on Android and iOS, requests extensive user permissions, of which very few are needed for the actual photo retouching functionality.

According to the researchers, the app collects phone numbers, IMEI codes, MAC address, and GPS coordinates, data which it neatly packages and sends back to a series of servers in China. Tests have allowed FourOctets to compile a list of IPs to where the app sends the user data.



Furthermore, the app also checks what mobile carrier the user is using and if the phone is rooted/jailbroken.

Starting last year, Chinese authorities mandated that app developers collect the necessary information to identify all users, data which they must provide to authorities at their request.

The Meitu user privacy debacle might be rooted in lazy development, as Meitu developers failed to set a filter in place to trigger this data collection system for Chinese users only. The app's sudden and quick rise to fame might have also caught developers off guard.
