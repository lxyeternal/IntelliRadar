
	   



Today, Adobe released security updates for Adobe Flash Player and Adobe Connect that fix a total of ten vulnerabilities. The Adobe Connect update resolves a cross-site scripting (XSS) vulnerability, while the Flash Player updates resolves 9 critical vulnerabilities that could lead to remote code execution.

Code execution is when the vulnerability can be exploited to execute commands on the affected computer.  This allows attackers to create specially crafted code that can be inserted onto web sites, which cause a vulnerable visitor to download malware or perform other actions that the attacker desires.

If you are a user of any of the below products, it is strongly advised that you update them immediately.

APSB16-35 Security Updates Available for Adobe Connect

Adobe has released a security update for Adobe Connect for Windows. This update resolves an input validation vulnerability in the events registration module that could be used in cross-site scripting attacks. 

CVE numbers:  CVE-2016-7851

APSB16-37 Security Updates Available for Adobe Flash Player

Adobe has released security updates for Adobe Acrobat and Reader for Windows and Macintosh. These updates address critical vulnerabilities that could lead to code execution, which may allow an attacker to take control of the affected system.

CVE numbers: CVE-2016-7857, CVE-2016-7858, CVE-2016-7859, CVE-2016-7860, CVE-2016-7861, CVE-2016-7862, CVE-2016-7863, CVE-2016-7864, CVE-2016-7865
