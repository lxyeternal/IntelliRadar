With the release of a Mac endpoint, enterprise customers utilizing Microsoft Defender ATP can now manage the security of Mac computers from a centralized administrative console.

Microsoft Defender Advanced Threat Protection, or Microsoft Defender ATP, is an endpoint protection solution from Microsoft that allows administrators to monitor the virus and threat landscape for computers on their network from one centralized location. This centralized console is called Windows Defender Security Center and allows you to manage all the endpoints on your network and see any threats that they may be or have been exposed to.


Windows Defender Security Center Console

Adminsitrators can install Microsoft Defender ATP for Mac endpoint client on  macOS Mojave, High Sierra, and Sierra in order to provide antivirus, vulnerability, and breach protection to Mac users.
