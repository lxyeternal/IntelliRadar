
	   


To the delight of Windows system administrators everywhere, Microsoft has announced that a new version of Sysmon is coming out this week that will include the ability to log DNS queries performed on a monitored computer. Even better, Sysmon will also log the process that performed the query.

For those not familiar with Sysmon, or System Monitor, it is a Sysinternals tool that is installed as a service in Windows that can log various events and information to the Windows event logs.

In a recent tweet by Mark Russinovich, the CTO of Microsoft Azure and creator of the Sysinternals tools, it was announced that a new version of Sysmon was being released this Tuesday that includes DNS Query Logging.

DNS Query Logging Example

While DNS query logging is already available on Windows, as mentioned by Sam King is is missing a piece of crucial information - the name of the executable performing the query. 



As shown in a blown up portion of the image from Russinovich's tweet, you can see that the upcoming version of Sysmon will provide the name of the process that is performing the DNS query in the event log.


Executable performing the DNS Query

This can allow administrators to quickly track down offending applications that may be connecting to unwanted sites or performing other unwanted behavior.

Administrators and security professionals are excited

DNS query logging will be particularly useful for Windows administrators and security professionals who can now use Sysmon to feed DNS query data into the event log. This data can then be consumed by other tools in order to find executables creating suspicious traffic or connecting to malicious domains.

SwiftOnSecurity who maintains a Sysmon configuration file on GitHub that monitors and logs intrusion events and malicious activity, is very excited for this feature.. 



With this new feature, we can expect updated configuration files and tools that can now utilize the data that this free tool provides.
