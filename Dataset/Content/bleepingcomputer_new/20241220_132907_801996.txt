
	   


A new botnet identified in the wild leverages close to a dozen exploits for high and critical-severity vulnerabilities against Windows systems to turn them into cryptomining clients and sources for distributed denial-of-service (DDoS) attacks.

The authors gave the malware the name Satan DDoS but security researchers call it Lucifer, to distinguish it from the Satan ransomware threat.

The botnet grabbed the attention of researchers at Palo Alto Networks' Unit following multiple incidents involving exploitation of CVE-2019-9081, a critical vulnerability in a component of Laravel web framework that can lead to remote code execution.

That campaign stopped on June 10 only to resume the next day with an updated version of the botnet.

Initially, the malware was believed to serve cryptocurrency mining (Monero) purposes but later it became apparent that it also has a DDoS component as well as a self-spreading mechanism by leveraging severe vulnerabilities and brute-forcing.

The dirty dozen

Spreading on the network is possible via EternalBlue, EternalRomance, and DoublePulsar exploits leaked by the Shadow Brokers hacker group. A list of weaponized exploits used by Lucifer operators is available below, and all have been patched:

CVE-2014-6287
	CVE-2018-1000861
	CVE-2017-10271
	ThinkPHP RCE vulnerability (CVE-2018-20062)
	CVE-2018-7600
	CVE-2017-9791
	CVE-2019-9081
	PHPStudy Backdoor RCE
	CVE-2017-0144
	CVE-2017-0145
	CVE-2017-8464

"Once exploited, the attacker can execute arbitrary commands on the vulnerable device. In this case, the targets are Windows hosts on both the internet and intranet, given that the attacker is leveraging certutil utility in the payload for malware propagation" - Unit 42


For the brute-force attack, the malware relies on a dictionary with 300 passwords and the and just seven usernames: "sa," "SA," "su," "kisadmin," "SQLDebugger," "mssql," and "Chred1433."

Apart from the three exploits for spreading internally, Lucifer may also scan for machines with TCP ports 135 (RPC) and 1433 (MSSQL) open and tests the username/password combination in its dictionary. Once in, the malware plants a copy of itself via a shell command.

The newer version of the botnet malware comes with anti-analysis protection and checks the user and computer name of the infected machine before proceeding any further. If it finds non-friendly names that correspond to analysis environments, its activity stops.

Despite these capabilities, the threat actor behind Lucifer has a cryptocurrency wallet with just 0.493527 XMR - about $30 at the current exchange rate, suggesting that it only started.

Unit 42 labels Lucifer as "a new hybrid of cryptojacking and DDoS malware variant that leverages old vulnerabilities to spread and perform malicious activities on Windows platforms."

Keeping software updated with the latest patches should greatly improve an organization's security stance against this type of threat. Combine this with strong passwords to prevent dictionary attacks and the environment should be safe from most malware.
