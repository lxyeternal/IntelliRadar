
	   


Hackers compromised the infrastructure of Volusion cloud-based e-commerce platform to inject customer checkout pages with malicious JavaScript code that steals payment card data.

The attackers added code for dynamic injection of the card data thieving script to a JavaScript that is part of the Volusion e-commerce software.

Thousands of websites are likely loading the attackers' script and sending payment information to their server. Some may have been compromised as early as September 12.

Check Point security researcher Marcel Afrahim discovered the compromise while shopping on Sesame Street Live Store, a website from Feld Entertainment that sells official Sesame Street merchandise.

The store is built with Volusion, who even provides the nameservers. On the checkout page, Afrahim noticed JavaScript code loading from Google Cloud Storage (storage.googleapis.com), a file storage web service for storing and accessing data on Google Cloud Platform infrastructure.

The oddity was that this was the only resource loaded from a source other than 'sesamestreetlivestore.com' or 'volusion.com' affiliated websites.

The malicious JavaScript is called 'resources.js' and comes from a bucket named 'volusionapi.'



It looks like the attacker was careful with the naming of the files to make them appear as innocuous as possible. This is further supported by the description of the code, which was copied from the GitHub repo of Javascript Cookie v2.1.4, a legitimate API for handling cookies.


MageCart script on rocknthreads.com

Analyzing the code, though, reveals that the script reads the values typed in the fields for credit card information, encodes it in Base64 and stores it in the browser's temporary 'sessionStorage' with the name '__utmz_opt_in_out'

Next, it is exfiltrated to 'volusion-cdn.com/analytics/beacon' - the attacker's domain that was created to look like it was part of Volusion's infrastructure.

The names of the folder are designed to make the traffic seem like harmless analytics or web tracking data. Even more, making a GET request to the domain redirects to a legitimate Volusion CDN (content delivery network), the researcher notes in a post today.

However, a whois lookup of the domain shows that it was registered on September 7, suggesting that the compromise occurred early last month and Volusion customers may have been infected around that time.

BleepingComputer emailed Feld Entertainment about the compromise and while we received no answer, the Sesame Street Live Store website was taken down, apparently for "scheduled maintenance and updates."

In fact, Afrahim told BleepingComputer that he received information that a source got compromised on September 12.



Stealing payment card data this way is known as a MageCart compromise. RiskIQ noticed the first attack of this kind in 2010 but the incidents ramped up only recently and grew to huge proportions, with hundreds of thousands of websites being infected with JavaScript that steals payment card data from checkout pages.

Thousands of stores may be impacted

Getting the malicious script to load on Volusion customers' pages is done through the 'vnav.js' JavaScript, which is used for navigating the UI menu.

According to its description, the file is jQuery UI - v1.10.3 and it is not particular to a store. Thousands may be infected.



The malicious script loaded by vnav.js was located at 'storage.googleapis.com/volusionapi/resources.js' and contained the Magecart script that would steal payment information inputted into the form.



BleepingComputer reached out to Volusion but at publishing time received no reply to a request for comments.

On the company page, Volusion boasts 30,000 merchants actively using the platform. They are from a variety of fields and the dedicated page shows merchants selling products in the apparel, home and garden, health and beauty, auto and industry, and electronics categories. From our checks, not all of them are still in business.

A cursory search for the domains containing the tainted Volusion JavaScript returned almost 6,600 results. It is possible that not all of them were compromised, though.

Following reports from news outlets and security researchers, Volusion addressed the issue a few hours ago. Before that, Google took steps and displayed the red 'malware danger' warning when visiting websites loading the malicious JavaScript.
