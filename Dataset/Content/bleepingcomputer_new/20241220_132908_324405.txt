New Ransomware called JuicyLemon

First, and foremost, I do not make these names up! With that said, a new ransomware called JuicyLemon was discovered by security researcher Kafeine. When users are encrypted by JuicyLemon, they are instructed to email support@juicylemon.biz for payment instructions. Victim's who have sent emails report that the dev is requesting 1,000 Euros in order to receive the decryption key.

Encrypted files will have a string like the following appended to their filenames: 1039734717_email1_support@juicylemon.biz_email2_provectus@protonmail.com_BitMessage_BM-NBRCUPTenKgYbLVCAfeVUHVsHFK6Ue2F.

Support topic: JuicyLemon Ransomware Help & Support Topic (support@juicylemon.biz)

CryptXXX Rebranded as UltraCrypter

A new update to the CryptXXX Ransomware has made significant design changes to both the ransom notes and the TOR payment site. Previously, CryptXXX, like many other ransomware infections, copied the layout and design of CryptoWall. With this recent update, they have now created their own template and changed the name of their decryptor to UltraDeCrypter. Could this indicate a formal name for the ransomware as UltraCrypter?

A big change is that CryptXXX will now target unmapped network shares. So lock down those open shares!

Read more: CryptXXX rebranding as UltraCrypter?Support topic: CryptXXX / UltraDeCrypter Ransomware Support and Help Topic (.crypt .cryp1 ext).



June 1st 2016

Emsisoft Releases a decryptor for the BadBlock Ransomware

Fabian Wosar of Emisoft has released a free decryptor for the BadBlock ransomware so that victims are able to recover their files for free. The article also discusses how BadBlock encrypts Windows system files, which will cause Windows to not boot properly.

Read More: BadBlock encrypts System Files. Decryptor Released by EmsisoftSupport Topic:  BadBlock Ransomware Support and Help Topic - Help Decrypt.html



June 2nd 2016

New Jigsaw variant with NSFW Background

A new variant of the Jigsaw Ransomware was released that contains a NSFW background.  Script kiddies are definitely having fun with this ransomware.  This variant will append .paybtc extension to encrypted files.  Michael Gillespie discovered this new variant and updated his decryptor so that it can decrypt victim's files for free.

To learn more about how to use this decryptor, read this article: Jigsaw Ransomware Decrypted: Will delete your files until you pay the Ransom

June 3rd 2016

A new ransomware called Black Shades was discovered that likes to taunt Security Researchers

A new ransomware called Black Shades was discovered by a security researcher named Jack that targets Russian and English speaking victims.  It has a very low ransom payment of $30, which can be paid in either bitcoins or a Paypal payment. Strangely, it also contains numerous taunts and boasts targeted at security researchers.

Read More: Black Shades Ransomware encrypts your PC and Taunts Security Researchers
Support Topic: SilentShade BlackShades Ransomware (.silent) Help Topic (Hacked.txt, YourID.txt)
