Adobe security engineer Antonio Sanso discovered the flaw over the summer and worked with PayPal since September to fix the issue.

After initially failing to understand the flaw's true depth, PayPal fixed the vulnerability on November 7, awarded the researcher a monetary reward, and yesterday, Sanso went public with details on his blog.

According to Sanso, the problem was found in the "redirect_uri" parameter included in server requests exchanged during the OAuth authentication procedure.

The "redirect_uri" parameter is the URL where OAuth servers deliver the access token, used by local clients (such as PayPal desktop, web, and mobile apps) to access customer accounts.

In the past, Sanso has been an advocate and urged OAuth providers to use "exact matching" for redirect_uri links, meaning that the value declared in the app's developer dashboard must be the same as the URL where the server sends the access, with no other second-stage redirects.

While PayPal was apparently using an exact matching for the redirect_uri parameter, Sanso discovered that if he inserted the term "localhost" anywhere in the redirect_uri URL, the PayPal server would consider this a request from a test app, and ignore the exact matching procedures.


Proof of concept (Credit: Antonio Sanso)

What this meant was that by tinkering with the initial OAuth request, an attacker would have hijacked the access token for any app and any user just by inserting his own URL that contained the term "localhost" somewhere in there (such as http://localhost.attacker-site.com).

Sanso told Bleeping Computer via email that depending on the scope (permissions) of the OAuth access token, the attacker could have had full access to customer accounts.

Earlier this month, three Chinese security researchers have disclosed pr in the implementation of Single-Sign-On (SSO) procedures via the OAuth 2.0 protocol on Android devices, a vulnerability that allows an attacker to assume the identity of another person. Researchers believe that over one billion Android devices may be vulnerable to this flaw.
