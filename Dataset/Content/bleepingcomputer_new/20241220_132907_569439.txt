The bug resided in LinkedIn AutoFill, a feature of the LinkedIn platform that powers the "AutoFill with LinkedIn" buttons that are found on some public job portals or private job application pages.

The button is meant to be added to job application forms, and when pressed, makes a query to the LinkedIn website, retrieves the user's data, and embeds it on the job application form.

The buttons are useful and handy, but last week, security researcher Jack Cable discovered that any website could abuse them for carrying out a secret user data harvesting operation.

He explained in a report published earlier today that any website could have secretly embedded this button on a page, modified the button's size to cover the entire screen, and made it invisible by tweaking a few CSS settings.

Any user navigating to this type of rogue website would have unwittingly submitted LinkedIn information to the website the first time he clicked anywhere on the page.

Such a simple-to-pull-off mechanism could have been very easily abused for mass user data harvesting, a topic that's quite sensitive today with most social networking operators, mainly due to the Facebook Cambridge Analytica privacy scandal.

LinkedIn deploys a universal fix

Cable notified LinkedIn's security team of the issue on April 9, and the social network responded by temporarily restricting the button to a whitelist of trusted domains, so malicious actors could not abuse the feature by secretly loading the "AutoFill with LinkedIn" button on shady sites.

Speaking to Bleeping Computer earlier today, Cable said that LinkedIn has released a permanent fix for the issue, just after the researcher published his report.

"LinkedIn has released a fix universally," Cable told us. "They now prompt an alert asking for the user to approve sharing their information. You can test this functionality here, by clicking the AutoFill button."



In a canned response, LinkedIn said that it "seen no signs of abuse."

Prior to discovering this LinkedIn issue, Cable was known for ranking first in the Hack the Air Force bug bounty program.
