
	   


Microsoft has recently lost control of the subdomain used to deliver content to Windows Live Tiles (also known as Windows Start Screen tiles), as discovered by Golem.de journalist and security researcher Hanno Böck.

The Live Tiles which were initially introduced in Windows 8 receive new content updates from the notifications.buildmypinnedsite.com with the help of RSS feeds.

As the researcher explains, "With a special XML-based file format, web pages can control the content of the tiles; for example, they can show the latest news. To make it easier for web pages to provide this function, Microsoft ran a service that automatically converted RSS feeds into that special XML format."

Böck was able to take control of the subdomain after Microsoft "disabled a web service for the system but forgot to delete nameserver entries. This made the host vulnerable for a subdomain takeover attack - allowing us to control the contents."

"The abandoned host was vulnerable for a so-called subdomain takeover attack. The host was redirected to a subdomain of Azure. However this subdomain wasn't registered with Azure," he also said.

Böck was able to takeover the subdomain "via a so-called CNAME nameserver entry. It redirects all requests for the host to the unregistered Azure subdomain. With an ordinary Azure account, we were able to register that subdomain and add the corresponding host name. Thus we were able to control which content is served on that host."

By taking control of it, the researcher blocked potential malicious actors from launching attacks against Windows Tiles users. As of now, around 2500 websites are still using the disabled Microsoft service according to the PublicWWW website source code search engine as ZDNet discovered.


Azure Portal 403 error

While Microsoft's "Build my Pinned Site" platform designed to help websites create metatags to add support for Live Tiles updating is still available at buildmypinnedsite.com, the notifications.buildmypinnedsite.com subdomain used to forward updates to Windows customers via Live Tiles now only displays an Azure Portal 403 error.

Sites advised to remove meta tags or create custom feeds

Böck also provided a video demonstration of a possible attack against users of Windows Tiles, showing how an attacker could easily replace the contents of the Live Tiles —the researcher's Windows Tiles defacement PoC apparently reached a live audience too as reported on Reddit.

Users who want to avoid being on the end of future PoCs being run or of possible attacks, can disable their Live Tiles by right-clicking on them, going into the "More" menu, and clicking on the "Turn Live Tile off" option as in the screenshot below.



After discovering the issue and registering the subdomain for sinkholing purposes, the researcher sent a report to Microsoft but did not receive any reply.

However, since there is "a decent amount of traffic reaching this host and running up costs to hold the domain and block the corresponding subdomain even if we stop the web service and don't provide any content," Böck says that he will eventually have to deregister the subdomain, unwillingly paving the way to threat actors ready to swoop in an abuse it.

Meanwhile, until Microsoft gets control of the situation, "Web pages that include these meta tags should remove them or, if they want to keep the functionality, create the corresponding XML files themselves."
