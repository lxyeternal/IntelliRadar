As part of the first event, the Fluoroacetate team targeted and successfully exploited Mozilla's Firefox web browser with a kernel escalation using a JIT bug and an out-of-bounds write in the Windows kernel.

The same team also tried their hand against Microsoft's Edge web browser with a VMware escape and a kernel escalation, using an exploit chain combining "a type confusion in Edge, a race condition in the windows kernel, and an out-of-bounds write in VMware Workstation.

The two exploitation demos earned Fluoroacetate $180,000 during the second day, which, combined with their previous $160,000 earnings from the previous day, brings them to a total of $340,000.



Niklas Baumstark also targeted Mozilla's Firefox web browser and successfully hacked it using a JIT bug chained with a logic bug to escape the browser's sandbox, earning $40,000 in the process.

Microsoft's Edge was also exploited by Arthur Gerkis of Exodus Intelligence, who managed to escape the sandbox with the help of a double free in the renderer and a logic bug, receiving $50,000 for his efforts.

During the first two days of the Pwn2Own Vancouver 2019 contest, participants received cash awards of $510,000 for 8 exploitation attempts and one partial win, successfully hacking Safari, Firefox, Edge, VMware Workstation, and Virtualbox.

The full schedule and the results following each exploitation attempt are listed in the table below.

Challenge
			Result
		10:00 - Fluoroacetate (Amat Cama and Richard Zhu) targeting Mozilla Firefox with a kernel escalation in the web browser category. 
			Success: - The Fluoroacetate team used a bug in JIT along with an out-of-bounds write in the Windows kernel to earn themselves $50,000 and 5 Master of Pwn points.
		11:30 - Fluoroacetate (Amat Cama and Richard Zhu) targeting Microsoft Edge with a kernel escalation and a VMware escape in the web browser category. 
			Success: - The Fluoroacetate team used a combination of a type confusion in Edge, a race condition in the kernel, and finally an out-of-bounds write in VMware to go from a browser in a virtual client to executing code on the host OS. They earn $130,000 plus 13 Master of Pwn points.
		14:00 - Niklas Baumstark targeting Mozilla Firefox with a sandbox escape in the web browser category. 
			Success: - Niklas used a JIT bug in Firefox followed by a logic bug for the sandbox escape. The successful demonstration earned him $40,000 and 4 Master of Pwn points.
		15:30 - Arthur Gerkis of Exodus Intelligence targeting Microsoft Edge with a sandbox escape in the web browser category. 
			Success: - In his Pwn2Own debut, Arthur used a double free in the renderer and logic bug to bypass the sandbox. The effort earned him $50,000 and 5 points towards Master of Pwn.
