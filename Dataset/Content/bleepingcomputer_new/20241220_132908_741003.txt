
	   
A group called the "Dark-Liberty Team" have rereleased the iOS iBoot source code on a TOR site titled "iBoot Source Code Leak - Reloaded". This source code was previously released on GitHub, but Apple's legal team quickly had it removed via a DMCA takedown request.


			
			TOR Site Part 1
			
			
			
			TOR Site Part 2
			
		As Apple has been quick to take down any public repositories of this source code, creating a TOR site to host the source code sounds like it would be a good way to distribute it without fear of takedown requests. What is strange, though, is that instead of hosting the source on the TOR site, this group released it as a MediaFire download link, which can be easily taken down by Apple.

This makes it a strange and a easily defeated way to release the source code.


MediaFire Page

Source code leak not such a big deal

Despite Apple's desire to keep the source code off the Net, some security experts do not feel that its release is such a big deal. This is because security researchers have often reversed the iBoot code as part of a constant search for vulnerabilities and bugs in Apple's products. It also appears that this source code was posted on Reddit over four months ago and has been circulating among security researchers for even longer.
