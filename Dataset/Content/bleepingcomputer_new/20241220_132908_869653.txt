
	   


Sophos is reporting that if their business products are installed on Windows 7, installing the May 2019 Patch Tuesday updates may cause Windows to hang on the update screen showing "Configuring 30%".

In a new support bulletin from Sophos, the antivirus company states that Windows 7 and Windows 8.1 users of their Sophos Endpoint Security and Control and Sophos Central Endpoint Standard/Advanced will find their computer hanging at the configuring updates screen while installing the updates.


We have had an increase in customers reporting that following on from the Microsoft Windows 14th May patches they are experiencing a hang on boot where the machines appear to get stuck on "Configuring 30%"

Initial findings suggest that this relates to the below Microsoft Patches:

May 14, 2019—KB4499164 (Monthly Rollup)
May 14, 2019—KB4499165 (Security-only update)


The KB4499164 update is a Windows 7 update titled "2019-05 Security Monthly Quality Rollup for Windows 7" and the KB4499165 is a "2019-05 Security Only Quality Update for Windows 8.1" and Windows Server 2012 R2.

Follows similar issues from the April 2019 updates

This bug follows a similar issue last month where Sophos users found Windows freezing and becoming slow after installing the April 2019 update. 

In that particular case, it was determined that a Windows security update for the Windows Client Server Run-Time Subsystem (CSRSS) service was causing the issues with various antivirus programs and Windows.
