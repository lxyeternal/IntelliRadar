
	   
A hacking group using the name Amn3s1a Team has dumped data online that they claim to have stolen from several Mega.nz servers. In a statement released following the public data dump, Mega Chairman Stephen Hall confirmed the incident but said no user data was compromised.

According to Hall, hackers had managed to obtain access to internal credentials used by one of Mega's contractors, who worked on maintaining the company's blog and help center.

The hackers used these credentials to gain access to the contractor's computer and Mega servers.

Hackers dumped Mega CMS source code, admin credentials

The hackers initially dumped a Pastebin file containing the admin logins for several Mega employees. Later in the day, the hackers published a second PasteBin, which contained a link to more of the data, which ironically, was hosted on Mega.nz itself.

This second dump was confirmed by Hall, who said: "The material posted by the hacker relates to the system that delivers blog posts, help centre content and translations, together with personal files from the contractor’s PC."

Amn3s1a Team told TorrentFreak that they've also stolen around 2GB of code, including the source code for Mega Chat, the company's browser-based chat application.

The group is auctioning off access to the rest of the stolen data and the source code of various Mega apps for 0.6 Bitcoin (~$445).

In his statement, Hall confirmed that hackers stole some of Mega's source code, but downplayed its value.

"The hacker may have accessed a development version of some client-side code but MEGA actively publishes such source code to provide transparency. See https://www.github.com/meganz," he wrote.

Hall also said that the company has secured the breached system and that the Mega blog and help center will be restored shortly.

Hackers didn't get their hands on Mega user data

As Hall states, the hackers never accessed Mega users data. The hackers never claimed to have accessed or stolen Mega user details.

On Twitter, Kim Dotcom, the Mega's founder and ousted leader, criticized the new management.

"When I was still at Mega we used to pay rewards to security experts for identifying weaknesses in our network. Guess that was discontinued," he wrote.

Hall made sure to reassure both users and security researchers that Mega still invests in its security. "MEGA continues to pay a reward for any valid report of a system vulnerability, which is immediately fixed," he said. Hall's full statement is embedded below.
