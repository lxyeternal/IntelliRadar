On Monday, a user publicly disclosed a zero-day remote code execution on the Full Disclosure security mailing list for the popular forum software called vBulletin. This is a critical vulnerability as it allows an attacker to execute any command on the site, which could allow them to download malware, reverse shells, or tamper with the site's code.

Customers have contacted vBulletin through their forums about this vulnerability and BleepingComputer has contacted them via their press email, but there has been no official response as of yet.

This is especially concerning, as thousands of sites utilize this forum software including high profile organizations such as Pearl Jam, NASA, EA, STEAM, Houston Texans, Sony Pictures, Zynga, and more. 

Unofficial patch released by security researcher

Update 9/25/19: An official patch has been released by vBulletin. More info can be found here.

This remote code execution vulnerability exists in the includes/vb5/frontend/controller/bbcode.php file and is caused by the evalCode ($code) function.

When this function is executed, it will launch any command passed in the $code argument using the eval() function. This can be any command available on the system, such as possibly adding new users, opening firewall ports, or downloading and executing files and scripts.

To fix this vulnerability, security researcher Nick Cano created a very easy patch that comments out the eval() statement in the evalCode function.

To add this patch yourself, edit the file includes/vb5/frontend/controller/bbcode.php and look for the following function.:

function evalCode($code)
{
    ob_start();
    // find in: public_html/includes/vb5/frontend/controller/bbcode.php
    eval($code);
    $output = ob_get_contents();
    ob_end_clean();
    return $output;
}

Now edit this function so that the eval($code) is commented out like:

function evalCode($code)
{
    ob_start();
    // comment out. idk what it breaks but it's a fix for now
    //eval($code);
    $output = ob_get_contents();
    ob_end_clean();
    return $output;
}

Once you comment out the eval() function, this particular vulnerability can no longer be exploited.

It is strongly advised that users immediately apply the above patch to resolve this vulnerability.

Exploited for years

After news broke about this vulnerability, Chaouki Bekrar, the CEO of the Zerodium exploit acquisition company, tweeted that his company has known about this exploit for three years and that many researchers have been selling the exploit for some time.



So while this public disclosure may have increased the uptick of attacks using this vulnerability, it has most likely been secretly used for some time.
