
	   

Slack outage map (Image: downdetector.com)

The Slack team collaboration and instant messaging platform is currently experiencing a worldwide outage caused by performance degradation issues impacting users from all over the world, with multiple services reportedly being down.

Currently affected Slack services at the moment are:


• Notifications
• Calls
• Connections
• Search
• Messaging
• Apps/Integrations/APIs
• Link Previews
• Workspace/Org Administration
• Posts/Files


According to user reports and from what BleepingComputer was also able to observe, some Slack messages are not being delivered with users receiving an error message stating that "Slack couldn’t send this message Try again | Cancel."


Slack failed message error

While other users have also reported that the Slack desktop app does not allow them to create new workspaces, the Slack team did not provide an estimated time for when the issues will be resolved.

Slack services status

This story will be updated when new information regarding the current Slack outage will be available.

3:33 PM GMT+3: New update on Slack's status page:


Some customers are still reporting issues with multiple Slack services. We're currently investigating and will keep you posted as soon as we have more information. We're sorry for the disruption.


9:04 PM GMT+3: After multiple attempts to fix the ongoing issues, the Slack team says that "We're seeing some signs of recovery, though we aren't in the clear yet. We'll continue to keep you posted on our progress."

Jun 29, 00:54 AM GMT+3: Slack renamed the ongoing incident to"Outage — Many users unable to connect to Slack" and the status page now says that:


We expect users to be able to connect to Slack after a refresh (Cmd/Ctrl + R) but we are still experiencing some issues with file uploads.


Jun 29, 6:15 AM GMT+3: Full functionality has been restored and Slack says that "A fix has been rolled out and all features should be working normally.
