New KillerLocker Ransomware threatens Victims with a Scary Clown

The KillerLocker Ransomware is a new ransomware discovered by MalwareHunterTeam. When executed, the ransomware will encrypt all files in certain locations and then appends the .rip extension to encrypted files.



October 2nd 2016

Beta version of the Fsociety Locker Ransomware Discovered

The beta version for the Fsociety Ransomware was discovered by xXToffeeXx. When this ransomware encrypts files it will append the .realfs0ciety@sigaint.org.fs0ciety extension and generate ransom notes named fs0ciety.html. If you are infected with this ransomware you should not pay the ransom and instead ask for encryption help in the Fsociety Locker Ransomware Help and Support Topic. When posting for help, please include the ID from the ransom note.



October 3rd 2016

New In-Development Hidden Tear Ransomware called CryptoLocker 5.1

A new ransomware called CryptoLocker 5.1 based off of Hidden Tear was discovered by MalwareHunterTeam. The ransomware is not active at this time.



October 4th 2016

Cerber Ransomware switches to a Random Extension and Ends Database Processes

Late last week, a new version of Cerber Ransomware was released that included some new features. The most notable change is the switch from the static .Cerber3 extension for encrypted files to a random 4 character extension, the use of a HTA file as the ransom note, and the termination of various database processes before encryption.



October 5th 2016

WildFire rises from the grave as the rebranded Hades Locker

The WildFire Locker ransomware has risen from the dead and rebranded itself using the apropos name of Hades Locker.  Hades Locker was discovered by Michael Gillespie when a victim uploaded a copy of the ransomware's ransom note to ID Ransomware. ProofPoint security researcher Matthew Mesa was then able to discover a sample and after MalwareHunterTeam examined it, it was determined that Hades Locker is a new version of the WildFire locker.



October 6th 2016

Numerous variants of the Globe Ransomware were Released.

Numerous variants of the Globe Ransomware were released this week. These include variants that add the following extensions to encrypted files: .[random].encrypted, .[random].raid10, .[mia.kokers@aol.com], and .[random].globe.
