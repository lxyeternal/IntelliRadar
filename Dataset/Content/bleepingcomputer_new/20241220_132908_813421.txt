
	   


Microsoft announced today that the accuracy of its Azure Active Directory Identity Protection detection algorithms has been increased by 100%, while the false-positive rate has been decreased by roughly 30%.

Azure AD is Microsoft's identity and access management solution designed to be used with on-premises, cloud-based and hybrid implementations, and to help employees sign in and access both internal and external resources.

"Together, these improvements improved our ability to detect compromised sign-ins by over 100 percent," says Alex Simons, Corporate Vice President PM, Microsoft Identity Division.

Azure AD Identity Protection baseline flow

Azure AD Identity Protection's Unfamiliar Sign-in Properties available for customers with Azure AD Premium P2 subscriptions is an algorithm designed to detect in real-time if a given sign-in action uses properties not seen recently for the user attempting to log in.

The new and improved Unfamiliar Sign-in Properties triggers three risk levels, from no risk to high risk, each of them associated with the likelihood of the analyzed authentication being compromised based on a risk score.

This risk score "represents the probability that the sign-in is compromised based on the user’s past sign-in behavior" and it is generated based on the analysis of several properties "including device identifiers, IP address, location, tenant corporate IP addresses, IP carriers, and available browser sessions."

"We’re continuously adapting to add new ones! One of the new features, the Exchange Active Sync (EAS) mail client ID, allows us to reduce false positives significantly when users are roaming on mobile networks," adds Maria Puertas Calvo, Microsoft lead data scientist.


Azure AD Identity Protection security overview

The false positives triggered by previous versions of the algorithm have been lowered by adding a component which will also look into the users' corporate IP addresses, an approach which drastically reduces compromised sign-in detection errors.

The improved version of Identity Protection is available today and it can help IT admins prioritize risky sign-in probes with the help of the newly added real-time risk levels.

This refreshed version of Identity Protection also bundles new User and Entity Behavior Analytics (UEBA) based detections for medium and high risk levels, with support for low-risk levels to be added soon.

"To take full advantage of this and other detections, make sure you set up conditional access policies that can automatically mitigate the risk in your organization," adds Puertas Calvo. "For example, you can set up a policy to require MFA on medium-risk sign-ins and another one to block high-risk sign-ins."
