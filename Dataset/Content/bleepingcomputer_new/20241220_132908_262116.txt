
	   
Ransomware is running rampant!  This week we have 10 stories, with 6 new ransomware, a decryptor, Locky being distributed as a DLL, and more. Pop culture ransomware continues to be the "thing" as new Purge and Pokemon based ransomware were released this week.

The big news is the Dutch Police seizing control of one of the WildFire Locker's command and control servers and retrieving some keys! Using those keys decryptors were made that could help some victims recover their files for free.

August 22nd 2016

New Alma Locker Ransomware being distributed via the RIG Exploit Kit

A new ransomware called Alma Locker has been discovered by Proofpoint​ researcher Darien Huss that encrypts a victim's data and then demands a ransom of 1 bitcoin within five days. There has been a lot of ransomware released lately, but thankfully most of them have been broken implementations or have had suspended command and control servers. Though Alma Locker still has some bugs in its implementation, it is one of the few released lately that has a working TOR command & control server and a secure encryption algorithm.

August 23rd 2016

Possible new CTB-Locker or a Knockoff Discovered

Proofpoint​ researcher Darien Huss discovered a ransomware that appears to be a fake CTB-Locker.  It is unknown whether this is a legitimate new version of CTB-Locker or a fake copycat.



August 24th 2016

The Globe Ransomware wants to Purge your Files

With both Pokemon and Mr. Robot based ransomware released this month, integrating pop culture into ransomware is a dominant theme this month. The new Globe Ransomware is no exception with malware developers basing their ransomware on the popular Purge movies. With a Purge based based wallpaper and adding the .purge extension to encrypted files, the malware developer was clearly inspired by the movies.



Dutch Police seize WildFire Locker Command and Control Servers. Decryptors Released

As part of the NoMoreRansom.org initiative, the National High Tech Crime Unit of the Dutch Police was able to seize the Command & Control server for the WildFire Locker ransomware.  This allowed them to recover approximately 5,800 decryption keys that were then used by McAfee and Kaspersky to create free decryptors for WildFire victims.



Alma Ransomware: Analysis of a New Ransomware Threat (and a decrypter!)

PhishLabs wrote a detailed analysis of the Alma Locker ransomware and provided code that can be used to build a decryptor if the victim has their private key. If a victim was lucky enough to be running a network sniffer while the ransomware infected a computer, then they may have their private key. Using PhishLabs' decryptor, the victim can use this key to recover their files for free.

August 25th 2016

Fantom Ransomware Encrypts your Files while pretending to be Windows Update

A new ransomware called Fantom was discovered by AVG malware researcher Jakub Kroustek and the source decompiled by MalwareHunterTeam that is based on the open-source EDA2 ransomware project. The Fantom Ransomware uses an interesting feature of displaying a fake Windows Update screen that pretends Windows is installing a new critical update. In the background, though, Fantom is secretly encrypting a victim's files without them noticing.



August 26th 2016

The curious case of the Domino Ransomware, a Windows Crack, and a Cow

The Domino Ransomware is a new infection discovered by Daniel Gallagher and Michael Gillespie that is based off of the Hidden Tear open-source ransomware project.  What makes this variant interesting is that it pretends to be the KMSPico Windows activation crack that will actually install KMSpico, but also encrypt a victim's files as an added bonus. It should be noted that this does not appear to be the official KMSpico program, but rather a modified installer.



Locky / Zepto Ransomware now being installed from a DLL

Over the past few days, the Locky / Zepto developers have switched to using a DLL to install the Locky Ransomware rather than an executable. This is probably being done for further obfuscation and to bypass executable blockers as rundll32.exe is typically white listed.



Smrss32 Ransomware being distributed via Fake US Election E-mails

Roland Dela Paz, a antivirus analyst for Fortinet, discovered that the Smrss32.exe Ransomware is being distributed via SPAM with attachments that pretend to be news about the US election.  Researchers had previously thought that this ransomware was distributed solely via Remote Desktop hacks, but it appears that it is distributed via email as well.



New Serpico DetoxCrypto Variant

A new DetoxCrypto variant has been discovered by security researcher S!Ri that is written in Serbsko-Croatia.  This variant has been named Serpico for the name of the folder it stores its associated files within. When encrypting data it will not append an extension and encrypted files will retain their original names.
