
	   


A couple of bugs in some versions of Samba software can help an attacker crash key processes on the network in charge of providing directory, application, and other services.

The two vulnerabilities can be leveraged separately to crash the LDAP (Lightweight Directory Access Protocol) and the RPC (remote procedural call) server processes in Samba Active Directory Domain Controller, supported since version 4.0 of the software.

Crashing the LDAP server process

One of the issues is tracked as CVE-2019-12436 and affects all Samba versions since 4.10.0 but the current one, 4.10.5, which includes a fix. Exploiting it requires read access to the LDAP server.

Originally reported by Zombie Ryushu, the issue has a severity score of 6.5 out of 10 and can cause a "can cause a NULL pointer de-reference using the paged search control" and produce a Samba AD DC LDAP server crash.

Updating Samba or applying the patch solves the problem. If these options are not possible right away, a short-term solution is to return to the default settings by running 'samba' with the "-M" standard.

RPC server process

The second flaw, identified as CVE-2019-12435, is also a NULL pointer de-reference, reported by Coverity. It impacts Samba versions 4.9 and 4.10 and exploiting it requires authentication.

Successfully leveraging this bug leads to a denial-of-service condition in the DNS management server, the advisory informs.


"The (poorly named) dnsserver RPC pipe provides administrative facilities to modify DNS records and zones. An authenticated user can crash the RPC server process via a NULL pointer de-reference."


A temporary workaround to this issue is to stop the dnsserver task. This is possible by setting the "dcerpc endpoint servers = -dnsserver" in Samba's configuration file; a service restart is required.

A fix for CVE-2019-12435 is present in Samba 4.9.9 and 4.10.5. Administrators are recommended to upgrade or apply the individual patch or upgrade to the latest releases. The patch for CVE-2019-12436 covers this vulnerability, too.
