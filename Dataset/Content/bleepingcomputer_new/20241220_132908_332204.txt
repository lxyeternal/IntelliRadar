
	   
This was a very quiet week with very few ransomware variants released and not much news at all, which we are always happy about. The biggest news has been the CryptON campaign that really picked up speed this month. As this ransomware is installed over hacked remote desktop services, everyone needs to make sure RDP is not accessible directly from the Internet and to use a VPN instead.

Contributors and those who provided new ransomware information and stories this week include: @campuscodi, @DanielGallagher, @hexwaxwing, @fwosar, @struppigel, @FourOctets, @PolarToffee, @malwrhunterteam, @BleepinComputer, @Seifreed, @jorntvdw, @demonslay335, @malwareforme, @LawrenceAbrams, @GrujaRS, and @thyrex2002.

May 21st 2018

New Unlock92 Variant

GrujaRS found a new variant of Unlock92 that appends the .cdrpt extension.

Alex Svirid discovered a new CryptConsole2 variant that uses the zizz@tutanota.de and drops a ransom note named README.hta. According to Michael Gillespie, it is still decryptable.

New RotorCrypt Variant

Michael Gillespie found a new RotorCrypt ransomware with the extension !________INKOGNITO8000@TUTAMAIL.COM_________.SPG.

PGPSnippet Ransomware

MalwareHunterTeam found a new ransomware called PGPSnippet that drops a note named !!!README_DECRYPT!!!.txt and uses the extension .decodeme666@tutanota_com.



New variant of the AES-Matrix ransomware

Michael Gillespie found a new variant of the AES-Matrix Ransomware that drops a note named ACCUDATA_pay and get your data back.txt.



May 22nd 2018

JosepCrypt discovered

MalwareHunterTeam discovered a new ransomware named JosepCrypt that appends the .josep extension and drops a ransom note named RECOVERY.txt.

May 23rd 2018

CryptON Ransomware Installed Using Hacked Remote Desktop Services

A new and active campaign for the CryptON Ransomware is currently underway where attackers are hacking into computers with Internet accessible Remote Desktop Services. Once the attackers gain access to the computer they manually execute the ransomware and encrypt your files.



New Russian ransomware

MalwareHunterTeam found a Russian ransomware sample that uses the ransom note named Dont_Worry.txt and appends the .UPS-%random% (changes for every file) to encrypted files.



May 24th 2018

New CryptConsole2 variant

Alex Svirid discovered a new CryptConsole2 variant that uses the szem@tutanota.com and drops a ransom note named README.hta. According to Michael Gillespie, it is still decryptable.

ID Ransomware introduces a new notification feature

Michael Gillespie added a new feature to ID Ransomware that allows users to subscribe to a ransomware so that they are notified when a decryptor becomes available.

May 25th 2018

New FLKR Ransomware variant

Michael Gillespie discovered a new variant of the FLKR Ransomware that appends the extension __murzik@jabber.mipt.ru and drops a ransom note named INSTRUCTIONS.txt.

New CryptConsole Variant

Michael Gillespie found a new CryptConsole variant that uses the desparo@tuta.io email. It is still decryptable.

That's it for this week! Hope everyone has a nice weekend!
