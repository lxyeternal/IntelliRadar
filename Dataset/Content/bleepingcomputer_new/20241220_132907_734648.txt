MuddyWater (also known as SeedWorm and TEMP.Zagros) is an advanced persistent threat (APT) group — or a hacking group backed by a government — which was first observed in 2017 while mainly targeting Midle Eastern entities.

Although quite new, it was already seen diversifying its attacks by also targeting government and defense entities in Central and Southwest Asia, as well as various public and privately-held organizations in Europe, Asia, and North America [1, 2, 3].

According to a report published today by the Cisco Talos Intelligence Group, a recent malicious campaign designed to "bypass certain security controls" is attributed to the MuddyWater threat actor with moderate confidence, a campaign which displays clear signs of the cyber-espionage group's intent to move to more stealthy attack techniques.

As part of the BlackWater campaign, the group used an obfuscated Visual Basic for Applications (VBA) macro script which allows its malware to gain persistence on compromised Windows machines after infection by adding a Run registry key.

The targets received the malware via malicious phishing emails which ask the victims to enable the password-protected trojanized macros which would block attempts to view its source code "likely as an anti-reversing technique" as the researchers state.

Between February and March 2019, MuddyWatter included in the malicious attachments the PowerShell commands used to establish persistence and to collect information on the targets' infected computers, as well as hardcoded command-and-control (C2) server IP addresses.

During the BlackWater campaign, however, they made use of a PowerShell stager script which would download a PowerShell-based Trojan from an actor-controlled C2 server with host enumeration components partly based on the open source FruityC2 post-exploitation framework 


Powershell stager

This Trojan payload is the one which starts enumerating and collecting machine information, immediately sending it to a different C2 server as part of the data in the URL field. This makes it a lot harder to detect on the host by eliminating the need to write the data on the server before shipping it to a server controlled by the attackers.

Additionally, as Cisco Talos found out, "This could allow the threat actor to monitor web logs and determine whether someone uninvolved in the campaign made a request to their server in an attempt to investigate the activity."

The hello messages sent during the infection process to the C2 servers which contained the term BlackWater, as well as the name of the trojanized macros and harcoded values in the stager script were the ones who gave the campaign the BlackWater moniker says Cisco Talos.

As the researchers found out, MuddyWater also made some extra efforts to avoid detection after successfully compromising a target by trying to avoid Yara rules and host-based signatures by modifying their tools, replacing variable names while still maintaining their malicious implants overall functionality and structure.
