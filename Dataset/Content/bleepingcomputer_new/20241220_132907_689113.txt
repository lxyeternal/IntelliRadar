
	   
Microsoft researchers Itai Grady and Tal Be'ery released today a new tool designed to help system administrators protect enterprise networks from reconnaissance attacks.

The tool's name is SAMRi10 (pronounced Samaritan) and is designed to harden Windows computers against SAMR (Security Account Manager Remote) queries, which allow attackers to get a list of local and domain users, group memberships, aliases, and more.

An attacker that has a foothold inside an enterprise can put this information together and create a virtual map of a company's network that can help him identify and target computers or servers holding more sensitive information.

What is SAM and SAMR

To get a better grasp of what the tool can do and protect. We first need to understand what SAM and SAMR are.

SAMR is the act of querying a remote SAM database.

Every Windows computer supports SAM. Computers assigned to a network domain, store information about their accounts in the domain's SAM database. They then use SAMR to perform remote queries on the SAM database and get information on their users, or the users on other computers/servers.

If the computer is not part of a network domain, then the computer stores information on all local accounts into a local SAM database. These computers don't need SAMRi10, since the attacker is usually contained only on the infected computer.

What is SAMRi10?

SAMRi10 comes in handy for securing networked computers connected through Windows domains.

SAMRi10 is a PowerShell script that system administrators can run on the computers on their network.

The tool, which must be run with administrative privileges, is for Windows 10 and Windows Server 2016 only. SAMRi10 automates a series of operations and limits the ability to perform SAMR queries for information on users on the same domain.

SAMRi10 does this by editing a registry key value that controls remote access to SAM databases. The registry key was introduced in Windows 10 and is not found in previous Windows versions. The registry key SAMRi10 edits is:

>>HKLM/System/CurrentControlSet/Control/Lsa/RestrictRemoteSAM


Support for limiting SAMR queries

SAMRi10 also allows sysadmins to filter who can perform remote queries. The tool can allow members of the Administrators group to query the remote SAM database.

Sysadmins can also use the tool to create a new custom group named "Remote SAM Users." Trusted users assigned to this group will be allowed to perform SAMR queries, even if they're not domain administrators.

SAMRi10 can be downloaded from here. In-depth usage instructions are included in the download package.

SAMRi10 has been tested against SAMR queries performed by popular reconnaissance tools such as PowerSploit or BloodHound.

In October, Grady and Be'ery released another anti-reconnaissance tool named NetCease that can block NetSessionEnum scans, which allows attackers to collect information from local networked devices by using the NetSessionEnum method available via SMB.

Grady and Be'ery, who are members of Microsoft's Advanced Threat Analytics (ATA) team, presented NetCease and SAMRi10 at this year's Black Hat Europe 2016 security conference.
