Zebrocy is a toolkit composed of a set of downloaders, droppers, and backdoors associated with an advanced threat group known as Sednit, APT28, Fancy Bear, Sofacy or STRONTIUM that runs cyber-espionage operations.

The use of Zebrocy increased since August 2018 when researchers noticed two new components. Victims include embassies, ministries of foreign affairs, and diplomats from countries in the Middle East and Central Asia.

Researchers at ESET have analyzed a version of the Zebrocy backdoor written in Delphi (variants coded in AutoIt and C++ also exist) with a focus on the commands the operators deliver after compromising a target.

They followed a campaign initiated at the end of the summer last year that distributed shortened URLs leading to downloading the first stage of Zebrocy components.

It is worth noting that this approach is unusual for the group as it is more direct than the typical strategy of relying on exploits for the initial phase of the attack.

It is believed that the URL reached the victim via spearphishing emails, although the researchers have yet to recover a sample of a malicious message. Also, it is unknown if the email contained instructions for the victim.

At the end of the URL there is an archive with an executable file disguised as a Word document and an empty PDF document, acting as a decoy.

"That [PDF] document appears to be empty, but the downloader, which is written in Delphi, continues running in the background. The IP address is also used in the URL hardcorded into the first binary downloader," say the researchers.

After creating an ID, the original downloader retrieves the Delphi-based Zebrocy backdoor, which has the configuration file split into four, hex-encoded and encrypted sections.



Commands run minutes after infection

After infecting a system, the malware sends out basic information about the host, which signals Zebrocy operators that they can start sending commands; this happens in minutes.


"The number of supported commands has increased over time, with the latest version of the backdoor having more than thirty. As we did not identify a pattern in the order which the commands are invoked, we believe the operators are executing them manually."


The initial set of commands is for reconnaissance purposes, allowing the operator to take screenshots, collect data about the system and its network. None of these came with arguments.

Targeted data types

The researchers noticed that the following commands typically accompanied the initial set, and came with arguments. These are to retrieve documents, archives, images, and other files from different drives of the infected host:



The data is demanded minutes after the compromise and overlaps with data delivered in previous stages of the attack. This means that the operators have their work cut out for them as they have to sift through large amounts of details, some of them duplicates.

To get to the information of interest, Zebrocy operators upload on the target machines tools that collect login credentials nad private keys from web browsers (Yandex Browser, Chromium, 7Star Browser (a Chromium-based browser), CentBrowser, and versions of Microsoft Outlook from 1997 through 2016.

The malware looks for databases from other programs, as well. Firefox and Opera browsers, and email client The Bat! are among the targeted software.

"The operators retrieve these files on the machine using the DOWNLOAD_LIST command. This command can be used when the operators are aware of the presence of interesting files on the computer."

If the victim presents a high interest, Zebrocy is used to deploy another custom backdoor, which is executed using the command "CMD_EXECUTE:"



The researchers have not determined the purpose of the custom backdoor but they note that it has a lower detection rate than the common variant and is deleted from the system, despite having persistence capabilities.

Furthermore, it is similar to the common variant but has some tweaks that set it apart. For instance, it has fewer commands (3 compared to 5) and comes with a custom encryption algorithm.



The researchers conclude that Zebrocy operators deal with a considerable amount of data without selecting it, which is in contrast with the strategy for deploying the malware.

Based on the evidence observed, it seems that the operators are careful and try to avoid backdoors with custom configuration files and modules falling in the hands of researchers.
