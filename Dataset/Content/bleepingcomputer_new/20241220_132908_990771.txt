
	   
Financial and government institutions in Asia and Africa have been the victims of targeted cyber-attacks that have leveraged a zero-day in the InPage Word processor in attempts to install keyloggers and backdoor trojans on targeted computers.

InPage is a word processor for RTL (right-to-left) languages such as Arabic, Urdu, Persian, and Pashto. The application is very popular in countries such as Pakistan, India, the Middle East, and some parts of Africa, where many users prefer it to Word or LibreOffice.

InPage used at many banks, press agencies, and government institutions

Many government agencies, financial institutions, and press agencies use InPage as their main word processor. Furthermore, because the InPage team doesn' benefit from the same resources that Microsoft puts in the Office Suite, it's very likely that finding an exploitable zero-day is much easier.

This makes InPage an easy target for both cyber-espionage groups and other parties interested in economical espionage, data theft, or more.

According to a report from Kaspersky Lab, this is exactly what happened, with several groups exploiting the same zero-day in different campaigns attacked financial institutions and government agencies in Sri Lanka, Myanmar, and Uganda.

The attackers used spear-phishing campaigns to send emails with multiple files attached. The files ranged from DOCX and DOC Word documents to INP InPage files.


Sample spear-phishing email (Kaspersky Lab)

When the user opened the INP file in his InPage word processor, shellcode hidden in the file's header executed, decrypted itself, dumped an EXE file on the victim's PC and attempted to run it.

Security researchers say that depending on the group exploiting the zero-day, this EXE file installed backdoors or keyloggers written in Visual C++, Visual Basic, or Delphi.

Zero-day used for years, still unpatched

"By all appearances, this newly discovered exploit has been in the wild for several years," says Denis Legezo, security researcher for Kaspersky Lab.

The latest attempts to exploit the zero-day took place as recent as September 2016. Legezo says the security firm contacted Concept Software, InPage's developers, about the zero-day, but they haven't heard back, meaning users are still in danger when using the app.

Deploying zero-days to target software used only in certain countries isn't a new tactic. In the summer of 2015, supposed North Korean hackers exploited a similar zero-day in Hangul, a word processor used in South Korea, to target various government agencies.
