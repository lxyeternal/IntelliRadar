Both programs contain critical code execution vulnerabilities and should be updated immediately.

Adobe Security Updates Summary:

APSB19-18 Security update available for Adobe Acrobat and Reader

Adobe released a monstrous security update for Adobe Acrobat and Reader that fixes 84 vulnerabilities. These vulnerabilities include information disclosure and artbitrary code execution, so it is strongly advised that you upgrade as soon as possible.
