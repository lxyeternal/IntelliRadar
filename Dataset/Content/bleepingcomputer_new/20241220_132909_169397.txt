
	   


Cisco has released security updates to address a critical vulnerability in the IOx application environment for Cisco IOS Software that could enable authenticated remote attackers to access the Guest Operating System (Guest OS) as the root user.

This high severity security flaw caused by an improper access control weakness is tracked as CVE-2019-12648 and it has a CVSS 3.0 base score of 9.9/10.

CVE-2019-12648 impacts Cisco 1000 Series Connected Grid Routers (CGR 1000) and Cisco 800 Series Industrial Integrated Services Routers running vulnerable releases of Cisco IOS Software with the Guest OS installed.

"An attacker could exploit this vulnerability by authenticating to the Guest OS by using the low-privileged-user credentials."

"Guest OS is available as part of a bundle IOS image that contains the Hypervisor, IOS, and Guest OS images," adds Cisco. "Customers that utilized a Cisco IOS Software image bundle for performing either an initial install or for a software upgrade will have Guest OS automatically installed as part of the software image bundle installation."

Cisco has released free security updates to address the vulnerability for all impacted devices and advises customers to contact the Cisco Technical Assistance Center (TAC) or contracted maintenance providers for further info if needed.

How to find if a device is vulnerable

Administrators can determine if Guest OS is enabled on a device by using the show iox host list detail command in the device CLI. 

Cisco's advisory provides the following example showing the command's output for a device with Guest OS enabled:


Router#show iox host list detail | include OS status

 OS status: 		RUNNING

If this command does not exist, or if it produces an output that does not show the string "RUNNING" within the OS Status field, the device is not affected by the vulnerability described in this advisory.


No workarounds available

While there are currently no workarounds to mitigate CVE-2019-12648 for devices that can't be quickly upgraded, the attack vector leading to the exploitation of this vulnerability can be removed by uninstalling Guest OS until the devices can be patched using the "the guest-os image uninstall command in global configuration mode."

Also, no malicious use or public information on the vulnerability has been discovered until the advisory was published according to the Cisco Product Security Incident Response Team (PSIRT).

This vulnerability was disclosed as part of the semiannual Cisco IOS and IOS XE Software Security Advisory Bundled Publication, which includes 12 Cisco Security Advisories describing 13 different security flaws, all of them being rated as high severity, with CVSS base scores within the 7.5 - 9.9 range.

Cisco has released security updates to address all these vulnerabilities, blocking attackers from exploiting patched devices to "gain unauthorized access to, conduct a command injection attack on, or cause a denial of service (DoS) condition."
