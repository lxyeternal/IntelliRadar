
	   


Adobe has published their monthly Patch Tuesday updates for the month of February 2019. These updates are for Flash Player, Creative Cloud Desktop Application, and ColdFusion.

These vulnerabilities can lead to code execution, information disclosure, or privilege escalation. It is strongly advised that all users update to the latest versions to be protected from these vulnerabilities.

Adobe Security Updates Summary:

APSB19-06 Security updates available for Adobe Flash Player

This update resolves a information disclosure vulnerability in Adobe Flash Player for Windows, macOS, Linux, and Chrome OS. If exploited, it could lead to information disclosure in the context of the logged in user.

		APSB19-10 Security update available for ColdFusion

This update fixes an arbitrary code execution and information disclosure vulnerability in ColdFusion. Arbitrary code execution vulnerabilities are labeled as Critical because it could allow attackers to execute commands on the server without your knowledge or permission.

These vulnerabilities were discovered by Wang Cheng of Venustech ADLab (CVE-2019-7091) and Pete Freitag from Foundeo Inc. (CVE-2019-7092).

This bug is fixed in the latest versions of ColdFusion.

		APSB19-11 Security update available for the Adobe Creative Cloud Desktop Application

Adobe has released a security updates for the Creative Cloud Desktop Application installer that fixes a privilege escalation vulnerability. This fix resolves an insecure library loading vulnerability, otherwise known as DLL hijacking, that allows attackers to run programs at a higher level of privileges than they normally would run.

This vulnerability was discovered by Tomohisa Hasegawa of Canon Marketing Japan Inc.

This vulnerability is fixed in the installer for Adobe Creative Cloud Desktop 4.8.0.410.
