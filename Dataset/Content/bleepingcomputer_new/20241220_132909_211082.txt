
	   


Knowing that many people want to get something for nothing, a common tactic is for attackers to create fake hack tools or cheats for popular games and sites. While users think they are using these tools to hack sites and games to earn free likes, currency, or rewards, in reality the attackers are just stealing the user's login credentials.

In this article we will take a look at a a few examples of how attackers create fake hack tools and cheats for popular sites like PayPal, Facebook, CamFrog and games like Apex Legends and Roblox.

Fake PayPal Hack

A PayPal hack tool found by MalwareHunterTeam states it can add free money to your account. All you have to do is add your username and password, select the country, currency, and amount you want to add and press submit.

PayPal Money Adder

After pressing submit, the tool will pretend to deposit the money in your account as shown below.


Money Added

Behind the scenes, though, the fake PayPal tool is sending your login credentials via email to the attacker.


Sending login credentials to attacker

Once they gain access to your account, you can expect the attackers to attempt to steal any balances.

Fake Facebook hacking tool

Want likes on your latest picture of your breakfast? According to this fake hacking tool found by MalwareHunterTeam, a user can get as many likes as they want on a posted Facebook image.

All they have to do is provide their Facebook account info and an URL to the Facebook image and click on the Generate button.


Fake Facebook Autoliker

What they don't realize is that once they press the button, their login information is sent via email to the attackers so that they can gain access to the victim's account.


Sending Facebook Credentials

Guess what? They don't get the likes they were looking for.

Fake Apex Legends cheat

Popular games are commonly used for hack tools and malware distribution as well. For example, the program below pretends to be a cheat for Apex legends.


Apex Legends AuroraCheat

When executed, the program will extract a file to C:\Program Files (x86)\Microsoft Zpaxhu\Mesyeas.exe and execute it. This file is a Remote Access Trojans (RAT), which logs your keystrokes and sends them back to the attacker.


Extracted RAT/Keylogger

This allows the attacker to gain access to anything you type on the infected computer, including passwords for online banks, email, and games.

Fake WiFi password cracker

A program promoted as a WiFi password cracker gives an installer more than they expected. 

Once executed, a fake message stating that the user need to install the .NET runtime is displayed in order to make it seem the program did not work. In the background, though, the Jigsaw Ransomware is installed.



 

Fake CamFrog Pro subscription maker

CamFrog is a web site where user can join webcam chat rooms. Users who want more advanced site features can upgrade to a paid Pro version.

The below program was also found by MalwareHunterTeam and pretends to be a tool that can upgrade an inputted account to a Pro subscription for free.


CamFrog Pro Subscription Maker

In reality, when credentials are entered and the user clicks on the "click here" button, the entered credentials are emailed to an attacker's gmail address.


Sending your login credentials to the hacker

Once an attacker gains access to an account, they can use it to steal private videos or even blackmail the user by threatening to release them.

Fake Roblox Hack

A common tactic is for seedy adware bundles creators to flood the Internet with fake downloads that pretend to be game cheats, software crackz, and hacking tools.  These malicious downloaders are then distributed through fake sites created to push the adware bundles or affiliate sites that earn a commission per install.

For example, the download below pretend to be a "Free Roblox Account Hacker". When run, though, it would automatically select various offers that it would install instead.


Adware Bundle

By clicking on the Settings button, you can see that it is installing unwanted programs called AnonymizerGadget, G-Cleaner, and SeeScenicElf.


Bundled Offers

While these programs are labeled "adware bundles", they actually install malicious software such as ad clickers, miners, and even Trojans that steal your passwords and files.
