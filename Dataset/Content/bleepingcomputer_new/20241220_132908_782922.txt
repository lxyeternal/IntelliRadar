
	   


Google has announced that they will be removing extensions from the Chrome Web Store that are installed using misleading and deceptive installation tactics. This is being done to further protect Chrome users from the unending barrage of unwanted extensions being promoted online.

BleepingComputer has been covering the deceptive practices that developers use to promote their extensions for years. This includes misleading landing pages, alerts that won't go away until you install the extension, or scare tactics used to convince you that the extension is needed on your computer.

Historically, extension developers would install their extensions using inline installs on their landing page rather than redirecting visitors to the Chrome Web Store. This made it easier to convince users to install their extensions.

Inline Install of Chrome Extensions

Due to this, Google decided to block inline-installs of extensions and require all Chrome extension to be installed directly from the Chrome Web Store instead.

While Google has stated that this change decreased the amount of complaints regarding unwanted extensions by 18%, it has not done enough as extension distributors simply switched to new tactics to bypass this restriction.

Now extensions are being promoted through landing pages that open a small overlay Window to their extension on the Chrome Web Store as shown below. These overlays are sized just enough to add the extension, but don't allow the users to see the reviews and other information.


Overlay window to the Chrome Web Store

Google finally says no more

In a new policy update issued by Google today, extensions developers are no longer allowed to use deceptive installation tactics for their extensions. 

Google is giving developers until July 1st, 2019, and if they are caught performing deceptive installation tactics, the extension will be removed from the Chrome Web Store.


Extensions must be marketed responsibly. Extensions that use or benefit from deceptive installation tactics will be removed from the Chrome Web Store.

Deceptive installation tactics include:

Unclear or inconspicuous disclosures on marketing collateral preceding the Chrome Web Store item listing.
	Misleading interactive elements as part of your distribution flow. This includes misleading call-to-action buttons or forms that imply an outcome other than the installation of an extension.
	Adjusting the Chrome Web Store item listing window with the effect of withholding or hiding extension metadata from the user.
Please audit all of your install traffic to ensure it is compliant before July 1st, 2019. You can also find an FAQ on the new policy in the Chrome Developer Center.


For example, the image below shows a landing page stating that you must download and install the extension to proceed. 


Misleading landing page for a Chrome Extension

Another example is a landing page that asks you to click an "I'm human" button, which will then cause the extension to prompt to be installed.


"I'm Human" extension landing page

According to a FAQ at the Chrome Developer Center, Google states that notification emails will be sent to developers who have been flagged as using deceptive behavior.  Depending on the misleading tactics, the developer will receive a warning first or an immediate removal.


A notification email will be sent to the associated developer account of the extension about the action taken against your extension. Depending on the egregiousness of the deceptive behavior, there are different outcomes for your extension:

A warning email that deceptive installation tactics for your extension have been identified
	Immediate removal of the violating extension and disabling of its active user base


Google has stated that developers can appeal the decision and an answer will made within 48 hours.

"Yes, appeals can be made through the instructions included in the notification email you will receive to the email address listed under your CWS developer account. Our enforcement team will process the appeal within 48 hours."

While it is good that Google is making these policy changes, it is baffling that they need to be made at all. If an extension is reported for these tactics they should simply be removed without an appeal process.

In my experience tracking these types of extensions, when a developer has been willing to promote them deceptively, they will continue to do so in the future.

Google to require extension's to use narrowest permissions

Included in their announcement, Google has stated that starting today Chrome extensions must use the narrowest permissions needed for their extension to work. They also must link to privacy policies and handle user data securely.

Today, we also announced additional policies to further protect users as part of Google’s Project Strobe. We will be requiring that extensions request the narrowest permissions needed to implement their features, and requiring more extensions to post privacy policies and handle user data securely.
