
	   


Security researchers have encountered a new macOS malware sample believed to be the work of the North Korean group of hackers known as Lazarus.

The threat has a very low detection rate and comes with capabilities that allow it to retrieve a payload from a remote location and run it in memory, making the forensic analysis more difficult.

macOS threat on trading platform

Malware researcher Dinesh Devadoss on Tuesday provided a hash for a new macOS malware sample that could load a mach-O executable file from memory and execute it.

Checking the sample on VirusTotal shows that its detection is almost inexistent. At the moment of writing, just four antivirus engines flagged it as malicious, improving to five at publishing time.

Security researcher and macOS hacker Patrick Wardle analyzed the malware found by Devadoss and determined that "there are some clear overlaps" with another first-stage implant attributed to Lazarus Group and found by  MalwareHunterTeam less than two months ago.

This new sample is packaged under the name UnionCryptoTrader and was hosted on a website called "unioncrypto.vip" that advertises a "smart cryptocurrency arbitrage trading platform" but provides no download links.

The package is not signed, which means that opening it will trigger a warning from the operating system (OS).



In a detailed analysis published today, the researcher notes that the malware has a 'postinstall' script that installs the 'vip.unioncrypto.plist' launch daemon for persistence. The script has the following attributes:

move a hidden plist (.vip.unioncrypto.plist) from the application’s Resources directory into /Library/LaunchDaemons
	set it to be owned by root
	create a /Library/UnionCrypto directory
	move a hidden binary (.unioncryptoupdater) from the application’s Resources directory into /Library/UnionCrypto/
	execute this binary (/Library/UnionCrypto/unioncryptoupdater)
The hidden 'unioncryptoupdater' binary is set to run at each system reboot by setting its RunAtLoad key to true. According to the analysis from Wardle, it can collect basic information about the system such as the serial number and OS version.

It contacts a command and control server (C2), which may provide a payload to execute. This indicates that 'unioncryptoupdater' is designed for the initial stage of an attack.

"At this time, while the remote command & control server remains online, it's simply responding with a “0”, meaning no payload is provided," Wardle found.

The lack of a valid certificate and the missing payload could suggest that the malware was discovered before the attacker was able to prepare all the details of the operation.

The researcher also explains how the malware achieves in-memory execution of a payload, a method that he presented four years ago at the BlackHat security conference.



macOS fileless malware

While executing a file in memory is a common feature in malware for Windows, the trick is rare on macOS and is just starting to gain in popularity.

One of the few malware families capable of this is Gmera, a trojan that researchers from Trend Micro discovered in September also posing as an online trading app.

Analysis from Sentinel One revealed that despite having a very low detection rate at the time, Gmera was able to decode and execute a payload in memory, too, an obfuscated script in this case.

AppleJeus pattern

Wardle believes that this malware was created by the Lazarus group and past evidence supports this theory.

Back in October, MalwareHunterTeam discovered that an attacker had created a fake company that offered a free platform called JMT Trader for trading cryptocurrency. Anyone installing it on macOS or Windows would get a backdoor on the system.

All this has a striking similarity to an attack called Operation AppleJeus, discovered and attributed by Kaspersky to the Lazarus APT group associated with North Korea.

A trojanized cryptocurrency trading application was used in that attack, signed with a valid certificate issued for a company that did not exist at the address listed in the certificate information.
