Called SystemSleuth, the tool could be downloaded by anyone accessing a Uniguest subdomain specifically created for hosting programs used by company technicians.

Reverse engineering revealed that embedded in its code were credentials to a Salesforce API used as a destination for sending all collected data.



Using the hardcoded credentials and the open-source SOAPUI tool to connect to the API, security researchers at Trustwave say that they could have gleaned "all the data in the Uniguest cloud database."

The issue is particularly serious because the database includes access details - admin, router, and BIOS passwords, product keys, for Uniguest customers.




"With this information in hand, adversaries could deploy keyloggers, remote access trojans and various other forms of malware, attacking hotel guests or business patrons just passing through." - Trustwave


Kiosks managed by Uniguest are locked down Windows computers specifically built for consumer interaction in locations in the hospitality, senior living, specialty retail, education, and corporate sectors.

The machines have specific purposes and can be used to browse the web, print tickets, or for purchasing merchandise available from the local vendor.

Thus, it is easy to imagine attack scenarios where users are redirected to malicious websites that capture credentials for online accounts or payment card data.

In a report released today, the researchers say that the database accessed this way may have included sensitive information for all Uniguest customers.

Trustwave informed Uniguest of the security lapse and the company has placed the website behind an authentication portal. Furthermore, the company disabled the API credentials.

However, these are only the first steps in dealing with the problem as researchers discovered on some kiosks an older version of the SystemSleuth tool that referenced another account for the Salesforce API along with info on an open API containing asset inventory data.

Doing away completely with the problem requires reinstalling the operating system on the kiosk and this process may take a long while, considering that there are some several thousands of machines in need of attention.
