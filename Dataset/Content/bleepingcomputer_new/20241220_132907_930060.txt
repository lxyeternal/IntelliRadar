Companies in various sectors, including financial, use SAP ASE relational database management system for transactional applications.

SAP delivered in May patches for seven flaws flaws affecting ASE for Windows and Linux. Technical details are now available for six of them impacting various components and services.

In a report today, security researchers at Trustwave explain how the vulnerabilities they found and reported could be leveraged by a threat actor.

One of the critical issues is an arbitrary code execution (CVE-2020-6248, 9.1 severity score) that allows corrupting the Backup Server configuration file with a simple command.

dump database mydb to 'path to \ASESERVER_BS.cfg' with init go

After a restart, the server reverts to the default configuration file that allows anyone to login using “sa” and a blank password. Attackers can use this to run an arbitrary executable with the highest privileges.

Trustwave also reported CVE-2020-6252 (CVSS 9.0), an information disclosure flaw affecting the Cockpit component in default Windows installations of SAP ASE.

Cockpit uses a small helper database (SQL Anywhere) running with LocalSystem privileges. The issue is that the login password is visible to all users.


“This means any valid Windows user can grab the file and recover the password to login to the helper SQL Anywhere database as the special user utility_db and then issue commands like CREATE ENCRYPTED FILE to overwrite operating system files” - Trustwave


A less severe issue (CVE-2020-6241, CVSS 8.8) reported by Trustwave is an SQL injection in the handling routine for global temporary tables. This allows users with no special rights to connect to the server and increase their privileges to administrator.



Another high-severity vulnerability is CVE-2020-6243, CVSS 8.0. It is an arbitrary code execution as Local System via XP Server.

The researchers noticed that on default installations, database users of any privilege could serve inexistent extended stored procedures and the server would try to load and execute the file “C:\SAP\.DLL.”

That location is writeable to authenticated users, which would give attackers that can connect to SAP ASE an opportunity to run on the system arbitrary code with LocalSystem privileges.

Plain text passwords in logs

A third high-severity issue (CVE-2020-6253, CVSS 7.2) is another privilege escalation to administrator via SQL injection in WebServices. Only database owners can exploit it, though.

Trustwave’s report details another problem that affects Linux versions of SAP ASE 16 SP03 PL08 and earlier. With a medium-severity score of 6.8, the flaw (CVE-2020-6250) should not be overlooked since it consists in plain text passwords being present in installation logs.

The sensitive information is readable only to the SAP account but the researchers say that attackers could exploit a vulnerability that offers access to the filesystem and fully compromise the targeted SAP ASE installation.

These vulnerabilities were disclosed responsibly to the vendor, who already delivered fixes. Given the severity of the bugs, organizations using SAP ASE should prioritize installing the updates.
