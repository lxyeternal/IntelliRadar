
	   
A new tool developed by engineers at Stampery can help database administrators audit the security features of their current MongoDB installations, and take precautionary measures to prevent future exploitation.

The tool, named mongoaudit, was launched two weeks ago and works on Mac, Linux, and Windows 10, through the Bash for Windows 10 feature.

Mongoaudit is a CLI tool, so you'll have to be comfortable using console terminals in order to install and launch the application.

If you don't have Python and pip, then the following command will do the same thing:

Mongoaudit installation

If everything's looks like it installed without glitches, just run the "mongoaudit" command and the tool's GUI will take over your console.


Mongoaudit start screen


Mongoaudit scan types

There are two scan types available, Basic and Advanced. You can run the Basic audit against any MongoDB server online. All you need is its URL and port number.

The Basic scan checks for the following issues:

MongoDB listens on a port different to default one
	Server only accepts connections from whitelisted hosts/networks
	MongoDB HTTP status interface is not accessible on port 28017
	MongoDB is not exposing its version number
	MongoDB version is newer than 2.4
	TLS/SSL encryption is enabled
	Authentication is enabled
	SCRAM-SHA-1 authentication method is enabled
	Server-side Javascript is forbidden
	Security bug CVE-2015-7882
	Security bug CVE-2015-2705
	Security bug CVE-2014-8964
	Security bug CVE-2015-1609
	Security bug CVE-2014-3971
	Security bug CVE-2014-2917
	Security bug CVE-2013-4650
	Security bug CVE-2013-3969
	Security bug CVE-2012-6619
	Security bug CVE-2013-1892
	Security bug CVE-2013-2132

Mongoaudit basic scan configuration

For the Advanced scan mode, you'll need to provide mongoaudit with a username and password to the database you want to test, as mongoaudit cannot scan for these issues from the outside.

This second scan type includes two more checks:

Roles granted to the user only permit CRUD operations
	The user has permissions over a single database

Mongoaudit advanced scan configuration

Error messages are available at every step and will let you know if you've done anything wrong.

If you've supplied proper URLs, ports, and credentials, mongoaudit will start automatically. A scan takes around a minute and looks like the image below.


Mongoaudit running a scan


Mongoaudit displaying scan results

Mongoaudit results are also explained in depth, within their own individual page. In the case of a failed test, mongoaudit provides basic tips on how to fix the problem and protect your MongoDB instance.





If you're running the scanner from a server, you can also share mongoaudit's results with a friend via email.


Mongoaudit email report feature

While there have been several MongoDB scanners released in the past, mongoaudit was developed after hackers hijacked and ransomed almost 41,000 MongoDB servers during the past 50 days.

While mongoaudit will tell you if you've forgotten to protect your MongoDB instance against remote access, it will also tell you much more, so just give it a go and make sure you're not running an unprotected server without even knowing.
