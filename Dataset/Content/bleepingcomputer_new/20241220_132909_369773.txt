
	   


A data encryption app for Linux users named Cryptkeeper has a bug that allows anyone to decrypt locked content using the password "p".

According to Kirill Tkhai, the security researcher who uncovered the bug, this universal decryption password only works with Cryptkeeper apps on Debian 9 (codename Stretch, current unstable branch), but not with earlier, stable Debian versions.

This minimizes the bug's impact as fewer users are using the unstable branches, compared to users deploying the currently supported Debian version. Nevertheless, for an encryption app, this is a very embarrassing bug.

Tkhai says that the source of the issue is how Cryptkeeper interacts with EncFS, an FUSE-based cryptographic filesystem, which Cryptkeeper uses to store encrypted data.

According to several Debian maintainers that have looked into the bug's behavior, a recent EncFS update has fixed a long-time bug, which in turn has modified how Cryptkeeper interacts with EncFS, leading to the situation where entering the small letter "p" will decrypt any data, on any PC.

"This issue only affects [...] cryptkeeper working with encfs 1.9.1-3," Debian developer Francesco Namuri explained, "in [Debian] stable we have [encfs] 1.7.4-5 that works as cryptkeeper expects."

Cryptkeeper removed from Debian 9

Following the bug's discovery, several members of the Debian project have requested the removal of the app from the operating system's codebase altogether.

A day later, cooler heads prevailed, and developers removed Cryptkeeper only from Debian 9, where the app was having issues. The app might be re-added to the OS if the bug is fixed and Cryptkeeper works as intended, after a future update.
