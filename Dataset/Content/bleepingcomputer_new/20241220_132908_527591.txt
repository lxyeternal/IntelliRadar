
	   


Another zero-day vulnerability in Windows receives a temporary fix today, as the 0patch platform added code for a bug in Windows Contacts app that allows remote execution of arbitrary code.

Reported via the Zero Day Initiative (ZDI) program by security researcher John Page, the glitch is in the way files storing contact information (.VCF and .Contact) are processed on vulnerable systems. It affects Windows Vista through 10.

In-memory fix available

Page’s initial report to ZDI was for VCF file types, but he found that .Contact files are handled the same way. Microsoft informed ZDI that it would not fix the vulnerability and the case would be closed.

The effect is immediate as because it is an in-memory fix for running processes.

The current solution works for up-to-date Windows 10 version 1803 (64-bit) and Windows 7 (64-bit). Micropatches for other Windows versions can be provided upon request.

In a blog post today, Mitja Kolsek, CEO of Acros Security company behind the 0patch product, provides the source code that solves the zero-day issue, along with a video that demonstrates its efficiency.



Malicious contact cards

"The flaw is due to the processing of ".contact" files node param which takes an expected website value, however if an attacker references an executable file it will run that instead without warning instead of performing expected web navigation," Page writes in his advisory.

Kolsek explains that the parameter is used as an argument to a ShellExecute call. Before opening URLs in the default browser, ShellExecute tries to locate the string on the local computer and launch it, Kolsek explains. This behavior occurs with no warning to the user.

An attacker can build a contact file with a malicious payload in a sub-directory. When the victim clicks on the link inside the contact file, the malware is executed on the system.

In a demo video, Page shows an executable malware disguised with a ‘.com’ extension that is launched when the victim clicks on a link (it could be for a website or for an email address) in the contact card.



Kolsek says that the 0patch fixes are meant to be temporary, until the official patch gets out. However, since Microsoft announced that it would not repair the issue, it looks like the micropatch could turn into a permanent solution for those that want to keep their systems protected against this vulnerability.
