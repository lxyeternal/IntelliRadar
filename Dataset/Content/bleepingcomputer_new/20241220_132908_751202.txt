
	   



Today Apple released the GarageBand 10.1.5.1 and Logic Pro X 10.3 updates to fix a critical vulnerability in both program that could lead to remote code execution.

According to Apple's security bulletins, these updates resolve an issue where a maliciously crafted GarageBand project file can cause a memory corruption issue when opened by either GarageBand or Logic Pro X. This corruption could lead to code execution, which would allow an attacker to execute almost any command on the affected computer without the victim's knowledge or permission.
