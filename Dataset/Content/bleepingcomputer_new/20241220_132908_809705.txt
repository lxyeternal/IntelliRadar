
	   


Microsoft is working on including a new tenant-wide idle session timeout feature for Microsoft 365 web apps designed to prevent information exposure that might stem from unauthorized access to systems left unattended.

The new policies will replace and improve similar idle timeout settings already available for Outlook Web App (OWA), OneDrive, and SharePoint Online (SPO) users once released during the first quarter of 2020.

"Idle session timeout feature allows IT admins to configure a tenant-wide timeout value based on which users get automatically signed out after a period of inactivity on Microsoft 365 web apps," says a new entry added to the Microsoft 365 roadmap.

The Idle Session Timeout feature was previously made available as a preview for OWA, SPO, and OneDrive users during October 2017 to become generally available a year later, on July 2018.

Application-based timeout policies are currently disabled by default with "warning and timeout timespans, as well as enabling idle session timeout are administrator controlled."

The tenant-wide Microsoft 365 idle session timeout feature will most probably work just like the one already available on a per-app basis.

The new policies should automatically sign out any inactive sessions after a preset time range following a 15 seconds warning, as shown in the video demo embedded below.



More Microsoft 365 updates coming

Microsoft is also currently working on including a new Automated Incident Response playbook to Office 365 Advanced Threat Protection (ATP) to allow security operations teams to investigate and remediate hacked accounts automatically.

Redmond is also on extending the Office 365 Advanced Threat Protection (ATP) Safe Links protection capability to Office Online apps, with the new feature to arrive in October. ATP Safe Links provides "time-of-click verification of web addresses" for URLs discovered in Office documents and email messages.

Microsoft also plans to enhance the quarantined malware and phishing email notification system for Microsoft 365 admins in early October and is currently rolling out better manual threat hunting features for the Office 365 Threat Explorer.
