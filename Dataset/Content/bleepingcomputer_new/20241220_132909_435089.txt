
	   



A new variant of the Fantom Ransomware was discovered last week by MalwareHunterTeam that added some very interesting features. The new features include network share enumeration and encryption, randomly generated desktop wallpapers, and offline encryption. By far the most interesting feature, though, is the ransomware's ability to set a ransom amount and a payment email based upon the name of the file.

Using the filename to determine the Ransom Amount

Typically, a ransom payment amount is provided by a Command & Control server or is hardcoded into the executable. With this new variant of Fantom, the ransom amount is now determined by the name of the process. This allows the developer to create various distribution campaigns using the same exact sample, but request different ransom amounts depending on how the distributed file is named. For example, if the developer wanted to target home users, they may make the ransom amount lower than if they were targeting a particular business or organization simply by changing the filename.

When executed, the ransomware will examine the process name, which is the same as the filename, and check if it contains certain substrings. Depending on the matched substrings, it will set the ransom to a particular amount. This can be seen in the code snippet below.

Determining Ransom Amount from Filename

As you can see from the above picture, if the process name contains the string v01, the ransom value will be set to 1, while if it contains v06, it will be set to 6. The source code has ranges from v01 through v09 and v1 through v20, with the respective numbers being the ransom value. It is not known, though, what the difference is between v06 and v6.

The sample that we have seen being distributed is called backupv2.exe, so the ransom value is being set to 2 for the current distribution campaign.

Generating a payment email address from the Filename

This new variant also includes the ability to derive a payment email address from the process name using a regular expression.  By default, each Fantom executable will contain a default payment email address, which is currently restorefiles@protonmail.ch. When executed, Fantom will parse the process name through a regular expression to see if it can extract a different email address based on the name. 

If the regular expression matches the process name, certain characters will be extracted and turned into a different payment address that overrides the default one.

Putting it all Together

As this version no longer communicates with a Command & Control server, it will instead create a unique string called a "personal ID" that is included in a victim's ransom note and that must be sent to the ransomware developer's email address to get payment instructions. To generate this ID, the ransomware will create a string that consists of the ransom value, the unique AES encryption key for the victim, and the time of the infection. This string is then encrypted using a bundled RSA public encryption key and saved as the variable called encryptedPassword.


Generating the Personal ID

The enryptedPassword variable is then inserted into the victim's ransom note so that they can send it to the ransomware developer if they wish to pay the ransom.  The ransomware developer, can then decrypt this string with their master RSA key to determine the ransom amount, the victim's encryption key, and when they were first infected.

These new features allow the ransomware developer to provide offline decryption, while still maintaining a secure encryption method.  The use of filenames to determine ransom values and payment addresses also reduces complexity when it comes to distribution campaigns.

Other Notable Features

Other notable features found in this new version of Fantom include the enumeration and encryption of network shares. This is not unique by any means, but still strangely absent from many ransomware infections.

The other feature is the use of randomly generated Windows wallpapers using text and random pixels. An example of a randomly generated ransom note can be seen below.
