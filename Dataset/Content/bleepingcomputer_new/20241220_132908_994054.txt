The creators of privnote.com, a legitimate site that offers a self-destructive pastes service, were concerned that someone had created a fake version of their website to trick users into using it.

"Earlier this year, KrebsOnSecurity heard from the owners of Privnote.com, who complained that someone had set up a fake clone of their site that was fooling quite a few regular users of the service," investigative security reporter Brian Krebs reported.

As can be seen below, a site named Privnotes.com was created that impersonates the authentic privnote.com site.


Privnote.com impersonator
Source: Bleeping Computer

As if the two websites' exceedingly similar names and appearance weren't obvious, the Privnotes clone added ads in Google Search to have their result outrank the "organic" results.

That means any time a user would search for "privnote(s)" Google would show the (fake) Privnotes.com ad first, as shown below.


Source: Krebs on Security

The legitimate Privnote.com service encrypts all self-destructive pastes so that those messages become unalterable and readable to even the website itself.

However, the developers of Privnote.com discovered that their imposter not only disregards implementing encryption but also does something sinister.

Steals bitcoins by altering pasted addresses

With the help of security expert Allison Nixon, Krebs discovered that the Privnotes.com was set up to steal cryptocurrency payment requests sent via their platform.

When the contents of a paste include a BitCoin address, it alters the BitCoin address to one under the threat actor's control in an attempt to steal the cryptocurrency.

Moreover, to evade being caught, the first four characters of the altered BitCoin address are the same as the originally pasted address. 

Also to make this behavior is hard to spot, to the end-user, the website only alters BitCoin address if the paste is being accessed from a different IP address than that of the creator.

However, when tested by BleepingComputer using VPNs and individual Incognito sessions (to prevent tracking via cookies), it appeared as if the website had retracted the malicious behavior for the time being. The BitCoin addresses remained the same in our tests.

For example, as you can see, we sent a message containing the bitcoin address '3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy'.


Test of sending a bitcoin address in a note
Source: Bleeping Computer

On a different computer, this same bitcoin address was received by the recipient on a different IP address.


Viewing message from another IP address
Source: Bleeping Computer 

While both websites offer a "secure connection" using SSL/TLS, as evident from the padlock icon, Bleeping Computer noted the apparent differences between their certificates:


Legitimate PrivNote.com DigiCert certificate
Source: Bleeping Computer

The Privnotes.com imposter, though, is using a free certificate from Let's Encrypt.


Fake clone PrivNotes using a free Let’s Encrypt certificate
Source: Bleeping Computer

Using a Let’s Encrypt certificate isn’t an automatic indication that a website is malicious.

However, their free-as-in-free-lunch nature and a high chance of recognition by modern web browsers make Let's Encrypt an appealing choice for scammers setting up phishing sites.

This sophisticated scam is a reminder to both the end-users and website creators when sharing sensitive information via electronic means. In this case, users may not even have spotted that the Privenotes site they were on was a fake, and without any "encryption," they had assumed it would offer.

At the same time, as a commentator to Kreb's report highlighted, the incident is also a reminder to the owners of mission-critical websites to "squat" similar sounding domain names and their variants, before somebody else does. 

While domain squatting can be abused, the same practice can help significantly deter phishing attacks when used by the owners of the original domain. Big banks and financial services already squat similar looking domain names in an effort to protect their users.
