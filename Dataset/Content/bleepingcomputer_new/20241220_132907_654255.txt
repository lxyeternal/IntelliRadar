
	   


According to multiple user reports, the Windows Defender Antivirus, Microsoft Endpoint Protection and Microsoft Security Essentials antimalware solutions are crashing randomly with a 0x800106ba error code on computers running Windows 7, Windows 8.1, and Windows Server 2003, 2008 and 2012.

The error seems to stem from a buggy 1.289.1521.0 definition update for Microsoft's antimalware solutions issued on March 18 as suspected by Microsoft users on Reddit, Microsoft's TechNet, Twitter, and AskWoody.

Microsoft confirmed that this is a global issue and is working to develop a fix according to Windows users who filed support cases, with the problem to be fixed in the next definition update version (1.289.1573.0) expected to be available in a couple of hours.

The log generated when the malware service crashes lists "The handle is invalid" as the error description and "The filter driver was unloaded unexpectedly" as the reason behind it.

Microsoft Antimalware Real-Time Protection feature has encountered an error and failed.
Feature: On Access
Error Code: 0x80070006
Error description: The handle is invalid. 
Reason: The filter driver was unloaded unexpectedly.

A possible workaround for the issue until an official fix is released by Microsoft would be for users to rollback the installed signature definitions to the previous version by running the following commands from the Command Prompt—also disable updates to block the faulty one from being applied again:

cd \
cd C:\program files\Microsoft Security Client\ 
Mpcmdrun -RemoveDefinitions

Also, on Windows Server machines users can follow the following procedure to reportedly restore Microsoft Antimalware solution functionality:

Navigate to C:\ProgramData\Microsoft\Microsoft Antimalware\
Rename “Definitions Update” folder to “Definitions Update.old”
Restart the Microsoft Antimalware Service (MsMpSvc) on the server.
Selected “Update Definitions” after about 10 minutes of the server being operational to verify that the fix worked.

Update March 19, 18:54 EDT: A Microsoft spokesperson told BleepingComputer that:


We’ve resolved this issue, which appears to have been limited to Windows 7 and Windows Server 2008.
