
	   


Microsoft released the March 2019 Office Update today, which consists of 6 security updates and 28 non-security updates. A some of these updates resolve critical vulnerabilities, it is strongly advised that you install them as soon as possible.

Of the 6 security updates, 4 of them fix remote code execution vulnerabilities within SharePoint and the Microsoft Office Access Connectivity Engine. Remote code execution vulnerabilities are Critical as they could allow attackers to perform almost any command on an exploited computer.

Also included is an update for Microsoft Office 2016 that allows users to block Access 2016 from executing VBA code if it is identified as being from the Internet.
