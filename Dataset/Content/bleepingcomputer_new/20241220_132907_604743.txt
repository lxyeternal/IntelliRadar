
	   


Security researchers found malware hosted on the Google Sites platform for building websites. The threat is a dropper for an information stealer that sends data to a MySQL server controlled by the attacker.

Named LoadPCBanker, the malware is an executable disguised as a PDF file that holds guest house reservation information, and it is stored in the File Cabinet storage space for Google Sites.

The name of the extracted PDF is "PDF Reservations Details MANOEL CARVALHO hospedagem familiar detalhes PDF.exe," which indicates that the cybercriminals are targeting English and/or Portugese-speaking victims.

However, the samples were still present and can could be downloaded at the time of writing.



Running it through the VirusTotal scanning service, it was detected by 47 of the 66 antivirus engines listed on the platform.

"The threat actor used classic Google sites to create a website, then used the file cabinet template to upload the payload, and finally sent the resulting URL to the potential targets," Netskope says in a report shared with BleepingComputer.



When launched, the fake PDF file creates a folder and downloads libmySQL50.DLL, otlook.exe, and cliente.dll payloads from the file hosting website KingHost.

Otlook.exe is obviously named so to impersonate Microsoft's Outlook email client and it is an information stealer that can take screenshots, record data saved in the clipboard, and log key strokes.

It also functions as a downloader for a file that contains the credentials and connection details for the SQL database that receives the stolen information. The file is constantly updated with new access credentials.

Exfiltrating the data is possible with the help of the DLL component, which is a library that facilitates the connection with the database server.



A capture of the database shows two tables available: one with information about the infected machine and the other with the stolen clipboard data.




"During our analysis, we identified that the threat actor was particularly interested in surveilling a specific set of machines and capturing screenshots of the victims' machines that were compromised from this attack. We derived this because we noticed a lot of infected machine responses, but only a few were being actively surveilled. At the time of writing, the threat actor was actively monitoring 20 infected hosts."


The researchers believe that malware of the same kind has been around since early 2014. The recent campaigns have been active since February 2019.

It is unclear if the same actor is behind all the attacks or the malware code was shared with other cybercriminals.
