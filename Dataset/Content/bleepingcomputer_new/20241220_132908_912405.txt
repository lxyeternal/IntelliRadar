Of particular concern are the 45 Critical vulnerabilities found in Adobe Acrobat and Reader. As both programs are widely used, and these vulnerabilities could allow attackers to execute code on a vulnerable machine, it is strongly advised that they are updated as soon as possible.

APSB19-48 Security update available for Adobe Experience Manager

Adobe has released a security update for Adobe Experience Manager that resolves 12 vulnerabilities.

These vulnerabilities could lead to information disclosure, privilege escalation, and a remote code execution, which could allow an attacker to gain unauthorized access to AEM.

These vulnerabilities were fixed in the latest versions Adobe Experience Manager 6.3, 6.4, and 6.5

APSB19-49 Security update available for Adobe Acrobat and Reader

Adobe has released a security update for Adobe Acrobat and Reader that fixes a whopping 68 vulnerabilities. Of these vulnerabilities, 45 are classified as Critical as they allow arbitrary code execution on vulnerable computers.

As these vulnerabilities could easily be exploited by attackers, it is strongly advised that users update Adobe Acrobat and Reader as soon as possible.

These vulnerabilities are fixed in Acrobat DC Continuous 2019.021.20047, Acrobat Reader DC Continuous 2019.021.20047, Acrobat DC Classic 2017 2017.011.30150, Acrobat Reader DC Classic 2017 2017.011.30150, Acrobat DC Classic 2015 2015.006.30504, and Acrobat Reader DC Classic 2015 2015.006.30504

APSB19-50 Security updates available for Adobe Experience Manager Forms

Adobe has fixed a vulnerability in Adobe Experience Manager Forms for a cross-site scripting vulnerability that could result in sensitive information being disclosed to an attacker.

These vulnerabilities were fixed in the latest versions Adobe Experience Manager 6.3, 6.4, and 6.5

APSB19-51 Security update available for Adobe Download Manager

Adobe has released a security update for Adobe Download Manager that fixes a privilege escalation vulnerability caused by insecure file permissions.

Based on the description, this vulnerability probably allows users to perform DLL hijacking by replacing an Adobe DLL with a malicious version.

This issue is fixed in Adobe Download Manager 2.0.0.417.
