The updated  Microsoft Cloud Access Security Broker (CASB) now allows organizations to keep track of business-critical resources hosted on Microsoft Azure blobs, Amazon Web Services S3 buckets, or Google Cloud Platform storage buckets.

Even if your IT department hasn't deployed cloud services yet, your employees already have, and your organization is 100% responsible for the security and compliance of that data. This is known as "shadow IT", where an organization is using application services, but IT has not yet approved their use – and it creates a major challenge for IT and a major risk for the organization.


As further detailed in the Enterprise Mobility + Security blog post, "MCAS has extended its Shadow IT Discovery capabilities to detect resources that are hosted on IaaS and PaaS solutions across Microsoft Azure, Amazon Web Services (AWS), and Google Cloud Platform (GCP), with more being added soon." 


Cloud App Security portal 'Discovered resources' view

The new Shadow IT discovery capabilities can be accessed via the "Discovered resources" view added to the "Discover" menu of the Cloud App Security portal which allows one to view who accessed each of the monitored resources.

To get a quick overview of Shadow IT use over all monitored cloud solutions, organizations can generate Cloud Discovery executive reports to identify the top potential risks and to "plan a workflow to mitigate and manage risks until they're resolved."


Cloud App Security (Image: Microsoft)

"You can use this new capability to gain full visibility into the resources that exist within your organization, which users are accessing them, transactions, IP addresses, and how much traffic is being transmitted," says Microsoft Security Marketer Kim Kischel.

The data presented within the 'Discovered resources' Cloud App Security portal view is collected using the SaaS Shadow IT Discovery implementation, "where customers can choose between Microsoft Defender Advanced Threat Protection for endpoint-based data collection, a log collector or by integrating with their existing Secure Web Gateway."

Organizations can start a free Microsoft Cloud App Security trial here and, for those who are already using it, Microsoft provides detailed technical documentation to get them started with the newly added capabilities.
