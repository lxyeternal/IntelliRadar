
	   


Admins of websites with WP Live Chat Support for Wordpress installations should immediately update the plugin to version 8.0.33 or later to patch a critical authentication bypass which can be exploited by attackers without valid credentials.

This Wordpress plugin currently has an installation base of over 50,000 websites and it is designed to provide a free live chat that makes it possible to get in touch with website visitors to provide live support.

As discovered by Alert Logic's cybersecurity researchers, versions 8.0.32 and earlier of WP Live Chat plugin for WordPress allow unauthenticated users to access restricted REST API endpoints because of a critical authentication bypass flaw tracked as CVE-2019-12498.

Vulnerable REST API endpoints

The REST API endpoints of unpatched WP Live Chat Support installations are "vulnerable to abuse by unauthenticated remote attackers due to a flaw in the ‘wplc_api_permission_check()’ function" and this allows attackers to exfiltrate "chat logs and the ability to manipulate chat sessions." 

"The above series of ‘register_rest_route()’ calls define those REST API endpoints which should have access restrictions due to the nature of the functionality they expose," says the Alert Logic research team.

"Each restricted endpoint shares the same ‘permission_callback’ function, namely the ‘wplc_api_permission_check()’ function which will be explored shortly."

Potential attack risks

The exposed REST API endpoints could allow potential attackers to extract the full chat logs for all chats sessions logged on the website, to inject text into ongoing chat sessions, to edit injected messages, and to launch denial of service (DoS) attacks by "arbitrarily ending active chat sessions."

The Alert Logic researchers also provide mitigation for this critical authentication bypass flaw they found in the WP Live Chat Support for Wordpress designed to help admins who cannot update the plugin immediately in the form of "virtual patching using a WAF to filter traffic destined for the WP Live Chat Support REST endpoint."

No attackers attempts to exploit this authentication bypass issue have been observed by the Alert Logic researchers so far. The plugin's developer patched the vulnerability within three days after the initial disclosure from May 29.

Persistent XSS flaw in 8.0.26 and earlier actively exploited

A persistent cross-site scripting (XSS) vulnerability which could be abused without authentication was also discovered in WP Live Chat Support for Wordpress plugin versions 8.0.26 and earlier a month ago by researchers at Sucuri.

The flaw enabled hackers to automate attacks to cover a larger number of targets without having to authenticate. It also made it possible to inject malicious code in web apps and sites, and to compromise visitors' accounts or to expose them to modified page content.

Because of the low exploitation effort and a large number of potential victims, malicious actors wasted very little time to take advantage of the flaw given that two weeks later researchers at ZScaler's ThreatLabZ observed attackers who were actively exploiting it and injecting malicious JavaScript content into the compromised website that triggered "malicious redirection, pushing unwanted pop-ups and fake subscriptions."
