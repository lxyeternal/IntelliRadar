
	   


Microsoft released the August 2019 Microsoft Office security updates, bundling a total of 20 security updates and 4 cumulative updates across seven different products.

Given that some of these Microsoft Office security updates also resolve various critical vulnerabilities, users are strongly advised to install them as soon as possible.

To download security updates for their Microsoft Office installations, users have to click on the corresponding Knowledge Base article in the table below and then to scroll down to the "How to download and install the update" section to download the corresponding update packages.

Out of the 20 Office security updates released by Microsoft today, 15 of them patch remote code execution vulnerabilities (CVE-2019-1155, CVE-2019-1200, CVE-2019-1201, CVE-2019-1204, and CVE-2019-1205) within Office 2016, Office 2013, Office 2010, Outlook 2016, Outlook 2013, Outlook 2010, Word 2016, Word 2013, Word 2010, Office Online Server, Office Web Apps Server 2013, SharePoint Enterprise Server 2013, SharePoint Server 2010, and SharePoint Server 2010 Office Web Apps.

The now patched remote code execution security flaws are rated as Critical by Microsoft seeing that they could allow potential attackers to execute arbitrary code and/or commands after exploiting unpatched Windows computers.

Two of the other Office security patches issued by Microsoft also fix an information disclosure flaw tracked as CVE-2019-1202 that could enable locally authenticated attackers who successfully exploited the bug to potentially hijack the session of another user. This vulnerability impacts the SharePoint Foundation 2013 and the SharePoint Foundation 2010 software products.

Three more security updates are designed to fix cross-site-scripting (XSS) vulnerabilities (more info available in Microsoft's CVE-2019-1201, CVE-2019-1202, CVE-2019-1203, and CVE-2019-1205 advisories) affecting SharePoint Server 2019, SharePoint Enterprise Server 2016, and SharePoint Enterprise Server 2013.
