
	   


Intel today released a firmware update for multiple NUC Kit models to patch a high-severity issue that could be exploited to achieve privilege escalation, cause a denial-of-service (DoS) condition, or information disclosure.

NUC Kits are not the only small-form-factor computers from Intel requiring this update. A Compute Card and a Compute Stick run with the same BIOS and are equally affected by the bug.

Multiple NUCs impacted

Tracked as CVE-2019-11140, the vulnerability has a severity score of 7.5 out of 10 and it is due to insufficient validation.

High-severity issue in CPU utility

Another high-risk vulnerability the company fixed today is in the Processor Identification Utility for Windows, used for retrieving the specification of an installed CPU. It can show details about graphics, chipset, and the technologies supported by the processor.

Identified as CVE-2019-11163, the bug has a severity score of 8.2. Despite being slightly more severe, local access is necessary for exploitation, the effects being the same as from leveraging the bug in NUC's BIOS.

According to the notes from the company, the weakness is from "insufficient access control in a hardware abstraction driver," and it exists in software versions before 6.1.0731.

The Computing Improvement Program also had a high severity vulnerability (CVE-2019-11162) that could be exploited for privilege escalation, denial of service, and/or information disclosure. However, exploitation required authentication and local access.

RAID software update

An information disclosure vulnerability was discovered in Intel's web-based RAID management software. The calculated severity is medium (6.8), but it can be exploited over the network by an unauthenticated attacker.

All versions of  Raid Web Console 2 are affected by this vulnerability, which is tracked as CVE-2019-0173. The maker recommends removing this version of the software and move to RAID Web Console 3 version 7.009.011.000 or later.

Other vulnerabilities Intel fixed this months impact the following products (click on any of them to follow the security advisory from Intel):

Intel Authenticate - medium severity vulnerability (CVE-2019-11143) that may allow privilege escalation
	Intel Driver & Support Assistant - medium severity vulnerability (CVE-2019-11145) that may allow privilege escalation from local access
	Intel Remote Displays SDK- medium severity vulnerability (CVE-2019-11148) that could help increase privileges
