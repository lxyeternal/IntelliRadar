
	   


Over the past couple of days, a new installer for the Chromium-based Microsoft Edge Insider build was released, which may mean we are getting closer to the public preview. While we still cannot install the browser, we are getting closer and this article will discuss what we know about the setup and how it works.

After Neowin published screenshots of Microsoft Chromium-based Edge Insider build, the download link for the Microsoft Edge Insider setup executable was also leaked online. 

Like Chrome, the Microsoft's Edge Insider setup program utilizes an installer that connects to the Internet and downloads the full setup package for the Edge browser. The name of this Edge installer is MicrosoftEdgeSetup.exe and can be downloaded here.

Microsoft Edge Setup Executable

We can execute the Edge Insider setup program using the following command:

MicrosoftEdgeSetup.exe /install "appguid={65C35B14-6C1D-4122-AC46-7148CC9D6497}"


Once executed, the installer will displays its first screen that welcomes the user to the insider community while it extracts the MicrosoftEdgeUpdate executables.


Welcome screen of the Edge Insider Installer

These files will be extracted into C:\Users\[login_name]\AppData\Local\Microsoft\EdgeUpdate as shown in the following images.




Temporary Microsoft Edge Update Files

Executables in the above folder will then be launched and will connect to a Microsoft API server that returns the current version of the Microsoft Edge Insider build and the name of the full installer, which are version 75.0.105.0 and MicrosoftEdge_X64_75.0.105.0.exe. Version 75 is the current Chrome Canary build.

{"ContentId":{"Namespace":"Default","Name":"65C35B14-6C1D-4122-AC46-7148CC9D6497","Version":"75.0.105.0"},"Files":["MicrosoftEdge_X64_75.0.105.0.exe"]}


The installer will then connect to a different API URL in order to retrieve the URL that the installer will use to download the full browser setup program.  While performing these API requests, the installer will display the following screen stating it is "Connecting to the Internet...".


Connecting to the Microsoft API Servers

After the API returns the full URL for the main Edge Insider setup executable, the installer will attempt to connect to it and download the file. 


Attempting to Download Edge Insider Build

Currently, the installer will fail with a 0x800421f6 error as it is not able to connect to the URL returned by the API. We assume this is because it is currently blocked from being accessed publicly and is only available to those on Microsoft's network.


Installation Failed

So while we are not currently able to install the Microsoft Edge Insider preview, we are able to get information such as how the installation will work, the current version of the preview build, and the names of the executables.

We will be continuing to track Edge Insider's development process and will release new information as it becomes available.
