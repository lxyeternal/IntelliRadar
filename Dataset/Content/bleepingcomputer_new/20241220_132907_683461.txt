
	   


Microsoft released the June 2019 Office Updates today, which consist of 13 security updates and 13 non-security updates. Given that some of the Microsoft Office security updates issued today also resolve critical vulnerabilities, it is strongly advised to install them as soon as possible.

Out of the 13 Office security updates released by Microsoft today, nine fix remote code execution vulnerabilities within Word 2016, Word 2013, Office 2010, Word 2010, Office Online Server, SharePoint Foundation 2013, Project Server 2010, SharePoint Server 2010, and SharePoint Server 2010 Office Web Apps.

These patched remote code execution vulnerabilities are Critical since they could allow attackers to execute arbitrary code and commands after exploiting vulnerable computers.
