
	   



Microsoft released Security Advisory 3123040 yesterday to alert Windows users that they accidentally disclosed the private key for the *.xboxlive.com SSL certificate and to warn them to be careful about possible attacks. SSL certificates are used to encrypt communication between a web server and a web site so that another organization or person cannot eavesdrop on the connection. When an attacker has access to the private key of the certificate used to encrypt this data, they could attempt a man-in-the-middle attack to listen in on this encrypted connection. This means that any financial information, passwords, or other encrypted data would be accessible to them. Microsoft has already updated their Certificate Trust List and  has stated that they are "not currently aware of attacks related to this issue.". With that said, if you have the latest Windows updates installed, you should be safe from any potential attacks. 


Example of a Man-in-the-Middle Attack

For users of Windows 8, Windows 8.1, Windows RT, Windows RT 8.1, Windows Server 2012, Windows Server 2012 R2, Windows 10, and Windows 10 Version 1511, and for devices running Windows Phone 8, Windows Phone 8.1, and Windows 10 Mobile, you are safe as these versions of Windows contain an automatic updater for the certificate trust lists. Unfortunately, if you are a user of Windows Vista, Windows 7, Windows Server 2008, or Windows Server 2008 R2 and do not have the Automatic Updater of Certificate Trust Lists (KB2677070) installed, then you will need to add the certificate manually.

To see if you have the Automatic Updater installed, you can look in the event viewer and check to see if an update was pushed to your computer yesterday.  This can be done by searching for CAPI2 in the Application logs of Event Viewer.
