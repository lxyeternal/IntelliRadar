
	   
Adobe released security updates for Adobe Acrobat and Reader that resolve 92 security vulnerabilities. Out of the 92 patched vulnerabilities in Reader and Acrobat, 82 of them are considered critical as they could lead to remote code execution. Remote code execution is when an attacker exploits a vulnerability to execute commands on the remote computer without the knowledge of the owner.  The available Reader and Acrobat updates are listed in the table below.

The Coldfusion update patches 3 vulnerabilities that could lead to cross-site scripting attacks or Java deserialization.  It is advised that all Coldfusion admins schedule downtime to apply these updates as soon as possible. The available Coldfusion updates are listed in the table below.

Last, but not least, Adobe also released an advisory for a critical vulnerability (CVE-2016-4117) in Adobe Flash that could cause a crash and potentially allow an attacker to take control of the affected system.  This vulnerability affects all users of Adobe Flash Player 21.0.0.226 and earlier versions for Windows, Macintosh, Linux, and Chrome OS.  

Adobe is also aware that this exploit is currently being used by attackers and plans on releasing an update for this vulnerability during their monthly security update. This update could be released as early as May 12th.
