
	   


Microsoft is challenging the data science community to come up with AI models that can accurately predict whether a computer would become infected based on the device's configuration. The team who successfully predicts the most malware will win a prize of $25,000 USD.

As part of the competition, Microsoft has provided 9.4GB of anonymized data that has been gathered from 16.8 million devices. This data is broken up into two files called test.csv and train.csv and will be used by teams to build models that allow them to predict whether a particular machine's configuration will become infected or not.

The data in the train.csv file is used to train a team's model on how to predict if a computer will become infected. This file contains machine configuration information such as the country location, processor type, OS version, Windows Defender engine, whether the firewall, UAC, or Smartscreen is enabled, amount of ram, storage capacity, and more. It also contains a row called hasDetections that can either be set to 0 or 1 to indicate if that particular machine had infections detected on it.

Data Set used to Train the Model

The test.csv also contains machine configuration data, but it does not include the hasDetections row. This file will be fed into the team's model to predict whether each machine will become infected.

Teams can then submit their models up to two times to determine how well it identified the machines that would become infected. The Team with the highest score will win the competition, which ends on March 13th, 2018.

To take part in the competition, teams can signup at Kaggle.
