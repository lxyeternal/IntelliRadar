
	   
VMware has issued a security advisory for a Windows-based guest privilege escalation vulnerability that affects VMware ESXi, Fusion, Player, and Workstation. VMware's security advisory VMSA-2016-0001 explains that a vulnerability (CVE-2015-6933) in the Shared Folders features could allow an attacker to escalate their privileges so that they would have more access to the OS than they would normally.  A patch by VMware has subsequently been released to resolve this issue. VMware has stated that this vulnerability, though, would not affect the host the operating system and only the guest would be affected.

The patch applies to VMware Windows Workstation versions before 11.1.2, Player and Fusion versions prior to 7.1.2, and various ESXi versions depending on their patch level:

VMware ESXi 6.0 without patch ESXi600-201512102-SG
	VMware ESXi 5.5 without patch ESXi550-201512102-SG
	VMware ESXi 5.1 without patch ESXi510-201510102-SG
	VMware ESXi 5.0 without patch ESXi500-201510102-SG
