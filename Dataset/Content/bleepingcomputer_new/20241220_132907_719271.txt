
	   


A new modular backdoor malware strain capable of mining cryptocurrencies and of spreading to other machines on the local network with the help of SMB and UPnP plugins has been detected by Kaspersky security researchers.

The backdoor malware named Plurox was discovered by MalwareHunterTeam in late January and then by Kaspersky in February and it seems to be still in its testing phase given that it's source code and the communication channels it uses to contact its command-and-control (C&C) server are not yet encrypted in any way.

"The backdoor uses the TCP protocol to communicate with the C&C server; plugins are loaded and directly interfaced via two different ports, which are stitched into the body of Plurox; the C&C addresses are also hardcoded into the bot," says Kaspersky.

Plurox command list

As further unearthed by Kaspersky's research team, the backdoor comes with support for seven commands sent via the C&C server which allow malware operators to download and run files on compromised machines using WinAPI CreateProcess, update and control the bots, as well as download, control and manage plugins.

After successfully infecting a host, Plurox bots will collect system info and will receive one of eight mining plugins from the C&C server based on the infected computer hardware configuration.

"We counted eight mining modules in total, whose features can be guessed from their names: auto_proc, auto_cuda, auto_miner, auto_opencl_amd, auto_gpu_intel, auto_gpu_nvidia, auto_gpu_cuda, auto_gpu_amd," note the researchers.

Worm malware behavior

The SMB and UPnP plugins the malware uses to move laterally through the local network gives it very dangerous wormable capabilties which help it quickly spread to vulnerable hosts after getting an initial foothold into a network.

More to the point, with the help of the SMB plugin, Plurox will infect other machines on the LAN using the NSA-leaked EternalBlue exploit. The module this backdoor uses is almost identical to the one the Trickster malware uses, with only the payload being different and the debug lines missing.

"Based on this, we can assume that the analyzed samples were taken from the same source code (commented lines in the Trickster plugin are missing in the Plurox plugin), which means the respective creators of Plurox and Trickster may be linked," according to the Kaspersky researchers.


Plurox UPnP plugin

The backdoor's UPnP plugin, on the other hand, does not use an exploit to infiltrate other network hosts as it will try to "forward ports 135 (MS-RPC) and 445 (SMB) for the currently selected IP address on the router using the UPnP protocol."

If it successfully forwards the ports, the malware will let the C&C server know and delete the changes after waiting for five minutes, providing the attackers with enough time to exploit the active services using those active ports.

This malicious UPnP plugin is almost identical to another NSA exploit named EternalSilence with a small but important difference: the Plurox malware will forward port 135 instead of the 139 NSA used for their leaked hacking tool.

A full list of indicators of compromise (IOCs) including C&C server domains and IP addresses, as well as hashes for the Plurox "wormable backdoor cryptominer" malware and its modules are provided at the end Kaspersky's analysis.

Another modular malware with worm capabilities exploiting known vulnerabilities in servers running ElasticSearch, Hadoop, Redis, Spring, Weblogic, ThinkPHP, and SqlServer to spread between servers and mine for Monero cryptocurrency was discovered by 360 Total Security researchers in March.

Further back, during September 2018, Palo Alto Networks' Unit 42 spotted the Xbash botnet which also comes with self-spreading capabilities targeting Windows and Linux servers, and combining ransomware and cryptomining functions.

Update 6/22/19: Updated article to note that MalwareHunterTeam discovered this backdoor in later January 2019.
