September 26th 2016

New ransomware called Help_dcfile Discovered.

Malwarebytes security researcher S!Ri discovered a new ransomware that has been dubbed help_dcfile based on the ransom note that is created. When a victim is infected, their files will be encrypted with the .XXX extension. It will then create a ransom note called help_dcfile.txt on the victim's desktop that contains information on how to pay the ransom.

Help_dcfile will automatically launch on login from a Windows task and Run entry with the name enc. Both of these autostarts will launch the C:\Program Files (x86)\wsW1u4.exe file.



The Donald Trump Ransomware tries to Build Walls around your Files

With all the buzz around tonight's Presidential Debate between Hillary Clinton and Donald Trump, I decided to see if I could find any malware based around these polarizing candidates. Though I did not find anything related to Hillary Clinton, I did stumble upon a development version of the Donald Trump Ransomware.



Locky Ransomware now uses the .ODIN extension for Encrypted Files

Today a new Locky Ransomware variant was discovered by @dvk01uk that switches from the .ZEPTO extension to the .ODIN extension for encrypted files. It is important to note that if you are infected with this ransomware, you are not infected with the Odin Ransomware. You are instead infected by Locky, which is using the .ODIN extension.  There is a difference.



Decryptor for the DXXD Ransomware Available

A decryptor for the DXXD Ransomware was created by Michael Gillespie. For those who are affected by this ransomware, you can contact Michael via the BleepingComputer.com forums for private help. More information can be found in the DXXD Ransomware (dxxd) Help & Support Topic.

September 28th 2016

Introducing Her Royal Highness, the Princess Locker Ransomware

Today we bring you Princess Locker; the ransomware only royalty could love.  First discovered by SenseCy on darkweb forums and later by Michael Gillespie through his ID-Ransomware platform, Princess Locker encrypts a victim's data and then demands a hefty ransom amount of 3 bitcoins, or approximately $1,800 USD, to purchase a decryptor. If payment is not made in the specified timeframe, then the ransom payment doubles to 6 bitcoins.



Emsisoft Releases a decryptor for the Al-Namrood Ransomware

Fabian Wosar of Emsisoft has released a decryptor for the Al-Namrood Ransomware. The Al-Namrood ransomware is a fork of the Apocalypse ransomware. The group behind it primarily attacks servers that have remote desktop services enabled. Encrypted files are renamed to *.unavailable and for each file a ransom note is created with the name *.Read_Me.Txt. The ransomware asks the victim to contact "decryptioncompany@inbox.ru".

German version of the Razy Ransomware Discovered

MalwareHunterTeam has discovered a new version of the Razy Ransomware that targets German victims. According to MHT it is "Still just a junk."



September 29th 2016

TeamXRat: Brazilian cybercrime meets ransomware

Great article from Kaspersky about the TeamXrat ransomware.  From their article:


Brazilian cybercriminals are notorious for their ability to develop banking trojans but now they have started to focus their efforts in new areas, including ransomware. We discovered a new variant of a Brazilian-made ransomware, Trojan-Ransom.Win32.Xpan, that is being used to infect local companies and hospitals, directly affecting innocent people, encrypting their files using the extension “.___xratteamLucked” and asking to pay the ransom.




New ransomware called Nuke Discovered.

Malwarebytes security researcher S!Ri discovered a new ransomware called Nuke that encrypts victim's files using AES encryption and then scrambles the file names. When done it will display the !!_RECOVERY_instructions_!!.html and !!_RECOVERY_instructions_!!.txt ransom notes that instruct a victim to contact opengates@india.com for payment instructions.

The original filename, bitcoin address, and other information is added to the end of every encrypted file.



Apocalypse Dev takes his feud with Fabian Wosar to the BleepingComputer.com Forums

Ever since Fabian Wosar has been repeatedly cracking the Apocalypse ransomware variants, the ransomware developer has started leaving insults to Fabian in his program. It seems like the ransomware dev wants to really make his feud public, as he started posting insults and taunts to Fabian in the BC forums.
