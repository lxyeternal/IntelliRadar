## 🔑 关键字段详解

### 1. **包名和版本** ⭐⭐⭐

#### `package_name` - 字符串类型
```json
"package_name": "@add-wallet-exchange/set-imported-csv-message"
```
- **类型**：`String`
- **唯一性**：与 `package_manager` 组合唯一标识一个包
- **示例**：
  - `"malicious-request"`
  - `"@scope/package-name"`
  - `"org.evil:malicious-lib"` (Maven)

#### `package_versions` - 字符串数组类型 ⭐⭐⭐
```json
"package_versions": ["*"]
```
- **类型**：`Array<String>` （永远是字符串数组）
- **可能的值**：
  1. `["*"]` - 所有版本受影响（90.9%的情况）
  2. `["1.0.0", "2.0.0"]` - 具体版本列表（9.1%的情况）
  3. `[">=1.0.0", "<2.0.0"]` - 版本范围表达式

**真实数据分布**：
```
总威胁情报：40,624 条
├── 通配符版本 ["*"]：   36,928 条 (90.9%)
└── 具体版本列表：        3,696 条 (9.1%)
```

## 🔄 版本字段的聚合逻辑

### 场景1：通配符覆盖（最常见）
```
原始数据：
  源A: ["1.0.0", "1.0.1"]
  源B: ["*"]              ← 任何一个源报告所有版本
  源C: ["2.0.0"]

聚合结果：
  package_versions: ["*"]  ← 通配符优先！
```

### 场景2：具体版本合并
```
原始数据：
  源A: ["1.0.0", "1.0.1"]
  源B: ["1.0.1", "2.0.0"]
  源C: ["2.0.0", "3.0.0"]

聚合结果：
  package_versions: ["1.0.0", "1.0.1", "2.0.0", "3.0.0"]
  （去重 + 排序）
```

### 场景3：空值标准化
```
原始数据：
  源A: []
  源B: null
  源C: ""

聚合结果：
  package_versions: ["*"]  ← 默认为所有版本
```

## 💡 关键设计原则

### 1. **通配符优先原则**
```python
if any(version in ["*", ">=0", "[0,)", "all", ""] for version in all_versions):
    return ["*"]
```
**理由**：如果任何一个可信源报告所有版本受影响，应该采取最保守的策略。

### 2. **信息完整性原则**
```python
# 不丢失任何信息
attack_methods = merge_all_sources(["Attack Method", "behavior"])
attack_vectors = merge_all_sources(["Attack Vector", "overview"])
```
**理由**：威胁情报的价值在于完整性，所有源的信息都应该保留。

### 3. **溯源可追踪原则**
```json
{
  "credit": {
    "sources": [
      {"discoverer": "...", "data_source": "...", "source_link": "..."},
      {"discoverer": "...", "data_source": "...", "source_link": "..."}
    ]
  }
}
```
**理由**：每条威胁情报都能追溯到原始来源，便于验证和更新。

### 4. **置信度科学评估**
```python
quality_score = (high_confidence_sources / total_sources) × 0.7 
              + min(total_sources / 5, 1.0) × 0.3

if quality_score >= 0.8: level = "high"
elif quality_score >= 0.6: level = "medium"
else: level = "low"
```
**理由**：基于数据源质量和数量的双重评估，更科学。

### 5. **增量更新策略**
```python
if exists(package):
    if has_changes:
        update(keep created_at, update last_updated)
    else:
        skip
else:
    insert(set created_at and last_updated)
```
**理由**：支持持续更新，不丢失历史信息。
