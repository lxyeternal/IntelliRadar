
Our research indicates that the Analytics feature in Nexus Repository Manager is rarely used and in certain instances, scalability issues arise when it is turned on. Therefore, we have decided to phase out the Analytics feature in a future version of Nexus Repository Manager.

As of version NXRM 3.14.0, the feature will still be available. However, it will automatically be disabled if you are using clustering in Nexus Repository Manager Pro.
We have not determined when the feature will be removed entirely, however between now and then users should not start using it.
